# Menulis dan Ekspor Metadata

Kamu bisa menuliskan metadata ke file gambar atau video, atau mengekspor metadata ke file CSV untuk platform microstock di Image-Tea-nano.

Fitur ini bisa diakses melalui:

![Write and Export Toolbar](res/images/writing_metadata_menu.png)

- Menu **Metadata** lalu pilih **Write Metadata to Images**, **Write Metadata to Videos**, atau **Export Metadata to CSV**.
- Tombol di toolbar: 

![Write and Export Toolbar](res/images/writing_metadata.png)

Untuk menulis metadata:
- Pilih **Write Metadata to Images** untuk menyimpan metadata ke file gambar.
- Pilih **Write Metadata to Videos** untuk menyimpan metadata ke file video.
- Metadata akan langsung ditulis ke file aslinya.
- Proses menulis menggunakan sistem chunking (pemrosesan per batch) untuk menghindari crash pada file dalam jumlah besar.

Untuk mengatur chunk size:
- Pilih **Chunk Size Settings** dari menu Metadata untuk membuka dialog pengaturan.
- Chunk size menentukan berapa banyak file yang diproses dalam setiap batch.
- Chunk lebih kecil (10-20): Lebih stabil, penggunaan memori lebih rendah, lebih lambat.
- Chunk sedang (30-50): Performa dan stabilitas seimbang (direkomendasikan).
- Chunk lebih besar (60-100): Pemrosesan lebih cepat, penggunaan memori lebih tinggi.

Untuk ekspor metadata ke CSV:

![Write and Export Toolbar](res/images/writing_metadata_csv.png)

1. Pilih **Export Metadata to CSV** dari menu atau toolbar untuk membuka dialog ekspor.

2. Di dialog ekspor, gunakan checkbox untuk memilih platform yang ingin kamu ekspor. Tombol `Check All` / `Uncheck All` memudahkan pemilihan grup platform.

3. Setiap platform memiliki field nama file dasar (base filename) yang dapat kamu edit. Nama dasar ini akan diberi suffix indeks dan ekstensi, mis. `_001.CSV`.

	- Nama dasar default dibangun otomatis, mis. `Freepik_Image_Tea_Metadata_2025_December_12_` (platform + "Image_Tea_Metadata" + tanggal saat ini).
	- Suffix `_001.CSV` ditampilkan di kanan field dan menandakan format akhir file.
	- Jangan gunakan karakter ilegal untuk nama file: `/\\:*?"<>|`.

4. Pilih folder output dengan menempelkan path (tombol `Paste`) atau klik `Select Output` untuk memilih folder dengan dialog.

5. Centang `Open folder on export` jika kamu ingin folder hasil terbuka otomatis setelah ekspor selesai.

6. Tombol **Export** akan aktif hanya ketika:

	- Minimal satu platform dipilih,
	- Lokasi output valid dan dapat diakses,
	- Semua nama file dasar tidak kosong dan tidak mengandung karakter ilegal.

7. Saat proses berjalan akan muncul progress dialog. Untuk setiap platform yang dipilih, aplikasi akan membuat satu file CSV berisi metadata sesuai format platform tersebut.

8. Setelah selesai, file CSV tersimpan di folder output. Kamu dapat mengganti nama file CSV secara manual jika diperlukan.

Catatan:

- Pengaturan platform yang dipilih biasanya disimpan dan dimuat kembali saat membuka dialog berikutnya.
- Ekspor menggunakan data metadata yang ada di database aplikasi (semua file yang terdaftar). Proses dapat memakan waktu tergantung jumlah file yang diekspor.

Fitur ini memudahkan persiapan metadata untuk diunggah ke berbagai platform microstock dengan kontrol nama file, validasi, dan opsi output.
