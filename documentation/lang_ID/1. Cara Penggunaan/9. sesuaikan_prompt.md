# Sesuaikan Prompt

Image‑Tea‑nano memungkinkan kamu mengubah template prompt yang dipakai saat AI membuat metadata. Editor menyediakan tab terpisah untuk setiap bagian prompt sehingga kamu bisa mengatur aturan dan panduan dengan rinci.

![Edit Prompt](res/images/edit_prompts.png)

Cara menggunakan editor prompt:

1. Buka editor dari menu utama (**Edit Prompt**) atau melalui toolbar (**Prompt**). Dialog `Edit Prompt` berisi beberapa tab: **Title**, **Description**, **Keywords**, **General Guides**, **Strict Don'ts**, dan **Negative Prompt**.

	![Edit Prompt](res/images/prompt_editor.png)

2. Pada tab **Title** dan **Description** kamu dapat menulis persyaratan (requirements) yang akan menjadi bagian dari prompt. Field berjenis plain text (tidak rich text) dan mendukung pemisahan baris.

3. Tab **Keywords** memungkinkan menentukan aturan untuk kata kunci (jumlah, format), sedangkan **General Guides** dan **Strict Don'ts** berisi panduan umum dan larangan yang harus diikuti oleh AI.

4. Tab **Negative Prompt** digunakan untuk menyatakan apa yang harus dihindari saat menghasilkan metadata.

5. Setelah mengedit, gunakan tombol **Save** untuk menyimpan perubahan ke konfigurasi aplikasi. Tombol **Cancel** membatalkan perubahan.


Prompt Placeholders
Prompt menggunakan placeholder (variabel) yang akan digantikan otomatis saat generate metadata. Placeholder yang tersedia:

- `_MIN_LEN_`: Minimum title length
- `_MAX_LEN_`: Maximum title length
- `_MAX_DESC_LEN_`: Maximum description length
- `_TAGS_COUNT_`: Required number of tags
- `_TIMESTAMP_`: Unique timestamp for each request
- `_TOKEN_`: Unique token for each request

Catatan penting:

- Editor menyimpan isian ke file konfigurasi aplikasi; perubahan bersifat persisten dan akan dipakai oleh fitur generate metadata.
- Masukkan instruksi yang jelas pada **Title** (contoh: ringkas, sertakan subjek, hindari kata umum) seperti terlihat pada contoh template di dialog.
- Hindari memasukkan markup atau karakter yang tidak diperlukan—field disimpan sebagai plain text.

Dengan menyesuaikan prompt kamu bisa mengarahkan gaya, panjang, dan struktur metadata (judul, deskripsi, kata kunci) sehingga hasil AI lebih sesuai kebutuhanmu.

## Pengelolaan Preset

Dialog Edit Prompt menyediakan fitur pengelolaan preset yang memungkinkan kamu membuat, menyimpan, dan beralih antara konfigurasi prompt yang berbeda.

### Menggunakan Preset

- **Preset Selector**: Di bagian bawah dialog Edit Prompt, gunakan dropdown **Preset** untuk melihat dan memilih preset yang tersedia.
- **Active Preset**: Preset yang sedang dipilih menentukan template prompt mana yang dimuat ke field editor.
- **Quick Switch**: Kamu juga dapat beralih preset langsung dari toolbar utama menggunakan kontrol parameter **Preset**—ini langsung memperbarui semua template prompt tanpa membuka dialog.

### Mengelola Preset

Dialog Edit Prompt menyediakan tombol untuk mengelola preset:

- **Add Preset** (+): Membuat preset baru dengan konten editor saat ini. Kamu akan diminta memasukkan nama untuk preset baru.
- **Delete Preset** (trash): Menghapus preset yang sedang dipilih. Preset "Default" tidak dapat dihapus.
- **Rename Preset** (pen): Mengubah nama preset yang sedang dipilih. Preset "Default" tidak dapat diubah namanya.
- **Duplicate Preset** (copy): Membuat salinan preset saat ini dengan akhiran "_copy" (atau nomor jika duplikat sudah ada).

### Alur Kerja Preset

1. Mulai dengan preset (mis. "Default").
2. Edit field prompt di tab dialog sesuai kebutuhanmu.
3. Klik **Add Preset** (+) dan beri nama deskriptif (mis. "Stock Photography", "Illustration Focused").
4. Preset baru disimpan dengan prompt kustommu.
5. Gunakan dropdown **Preset** (di dialog atau toolbar) untuk beralih antar preset secara instan.

Catatan:

- Menyimpan dialog (tombol **Save**) akan menyimpan baik preset saat ini maupun konfigurasi prompt utama.
- Kontrol **Preset** di toolbar selalu mencerminkan preset yang sedang aktif dan langsung diperbarui ketika diubah.

## Custom Prompt (aturan per-permintaan)

![Edit Prompt](res/images/custom_prompt.png)
- Akses: buka **Prompt → Custom Prompt** dari menu utama, atau klik tombol **Custom Prompt** pada toolbar.
- Tujuan: gunakan Custom Prompt ketika kamu ingin menambahkan instruksi khusus yang bersifat sementara atau untuk satu permintaan, tanpa mengubah template prompt utama.
- Perilaku: tulis aturan khusus pada kotak teks lalu klik **Save**. Nilai disimpan ke konfigurasi aplikasi sebagai custom prompt untuk permintaan tersebut.
- Efek: jika diisi, helper AI akan memasukkan isi Custom Prompt sebagai instruksi wajib saat membuat metadata; ini menambah instruksi ke template, bukan mengganti atau mengubah template.
- Menghapus: kosongkan kotak teks lalu klik **Save** untuk menghapus aturan khusus, atau klik **Cancel** untuk membatalkan perubahan.

## Cadangkan & Pulihkan (Import / Export)

- Gunakan **Export** untuk membuat file cadangan konfigurasi dari field prompt saat ini.
- Nama file export: nama default berisi tanggal/waktu (mis. `Image_Tea_Prompt_Backup_YYYYMMDD_HHMMSS`); kamu bisa memilih lokasi lain saat menyimpan.
- Isi export: file backup berformat JSON dengan kunci top-level `prompt` yang berisi field editor (`title_requirements`, `description_requirements`, `keywords_requirements`, `general_guides`, `strict_donts`, `negative_prompt`).
- Perilaku import: **Import** akan memuat isi file cadangan konfigurasi ke field editor; kamu harus klik **Save** pada dialog untuk menyimpan perubahan ke konfigurasi aplikasi.
- Catatan: file yang diimpor divalidasi agar memiliki objek `prompt`; jika terjadi error saat import/export, akan ditampilkan dialog peringatan. Export default mengusulkan direktori home, tetapi kamu bisa memilih lokasi lain.
