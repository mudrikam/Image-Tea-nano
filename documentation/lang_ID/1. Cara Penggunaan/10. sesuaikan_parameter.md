# Sesuaikan Parameter

Saat membuat metadata dengan AI di Image‑Tea‑nano, gunakan kontrol parameter di toolbar untuk mengatur perilaku generator. Perubahan parameter disimpan langsung ke konfigurasi aplikasi dan berlaku segera.

![Sesuaikan Parameter](res/images/adjust_parameter.png)

Penjelasan parameter (perintah pasti):

- **Min Title**: Aplikasi akan meminta model menghasilkan judul dengan panjang minimal sebesar nilai ini.
- **Max Title**: Aplikasi akan meminta model menghasilkan judul dengan panjang maksimal sebesar nilai ini.
- **Max Desc**: Aplikasi akan meminta model menghasilkan deskripsi dengan panjang maksimal sebesar nilai ini.
- **Tag Count**: Aplikasi akan meminta model menghasilkan tepat sebanyak nilai ini kata kunci/tag untuk setiap file.
- **Batch Size**: Menetapkan jumlah file yang akan dikirim dalam satu permintaan batch ke API. Nilai maksimum adalah 20.
- **Quality**: Menetapkan kualitas kompresi (1–100) untuk file gambar cache yang dikirim ke API.
  - `100` berarti kualitas asli (tanpa kompresi).
  - Nilai lebih rendah menghasilkan ukuran file cache lebih kecil dan penggunaan data yang lebih efisien; nilai lebih tinggi mempertahankan detail gambar.
  - Nilai yang direkomendasikan adalah `70–80`.
  - Penjelasan penting: pengaturan ini hanya memengaruhi ukuran dan detail visual file gambar yang dikirim ke layanan AI. Pengaturan kompresi **tidak** mengubah jumlah token yang dihitung oleh API untuk prompt atau respons teks. Jumlah token dihitung berdasarkan konten teks (prompt dan jawaban model), bukan ukuran berkas gambar. Kompresi yang sangat rendah akan mengurangi detail visual sehingga model akan menerima informasi visual yang berbeda dan dapat menghasilkan output teks yang berbeda, namun hal ini tetap tidak memengaruhi jumlah token yang digunakan dalam permintaan API.
- **Delay (s)**: Menetapkan jeda antar batch.
  - `No Delay` = 0 detik.
  - `Random` = interval acak antara 1–5 detik.
  - Masukan angka akan diperlakukan sebagai jumlah detik tunggal antara batch.
- **Proxy**: Mengatur pembuatan proxy video untuk file yang dikirim ke layanan AI.
  - `Off`: Tidak membuat proxy; file video asli digunakan.
  - `Auto`: Buat proxy dengan preset yang dipilih otomatis berdasarkan resolusi input (>=1920 → High, >=1280 → Medium, lainnya → Low).
  - `High` / `Medium` / `Low`: Gunakan preset tetap (resolusi, bitrate, CRF) untuk mengurangi ukuran unggahan dan mempercepat pemrosesan.
  - Proxy mengubah detail visual yang diterima model dan dapat memengaruhi metadata yang dihasilkan, namun tidak mengubah jumlah token teks pada permintaan API.

Mengubah preset proxy

Kamu dapat mengubah nilai preset (`Label`, `Resolution`, `Bitrate`, `CRF`) untuk preset `Low` / `Medium` / `High` melalui Editor Preset Video Proxy. Buka melalui menu aplikasi: Prompt → Video Proxy Settings.

![Editor Preset Proxy Video](res/images/video_proxy_preset_editor.png)

Penjelasan field dan aturan:
- **Label**: Nama singkat yang mudah dibaca untuk preset (hanya untuk tampilan). Gunakan teks biasa, singkat, dan hindari pemecahan baris.
- **Resolution**: Format `scale` untuk FFmpeg. Gunakan `WIDTH:-2` untuk menjaga aspek rasio (direkomendasikan), atau `WIDTH:HEIGHT` untuk ukuran pasti. Contoh: `1920:-2` (target 1080p), `854:480` (480p). Jangan gunakan tanda koma atau satuan.
- **Bitrate**: Bitrate target dengan akhiran `k` (mis. `2500k`, `1000k`). Jangan gunakan spasi. Kamu juga dapat memakai `M` untuk megabit (mis. `2M`), tetapi `k` umum digunakan.
- **CRF**: Bilangan bulat 0–51 (nilai CRF FFmpeg). Nilai lebih rendah: kualitas lebih tinggi (file lebih besar). Nilai umum: `18` (kualitas tinggi), `23` (sedang), `28` (rendah).

Catatan:
- Editor menyimpan nilai ke konfigurasi aplikasi ketika kamu klik Save. Perubahan berlaku untuk operasi pembuatan proxy berikutnya.
- Gunakan mode `Auto` di toolbar Prompt untuk membiarkan aplikasi memilih `Low`/`Medium`/`High` berdasarkan resolusi berkas input.
- Hindari format tidak valid (mis. `bitrate` tanpa satuan atau `resolution` yang salah) karena dapat membuat FFmpeg gagal atau menghasilkan output yang tidak diinginkan.

Perilaku penyimpanan dan validasi:

- Setiap perubahan parameter disimpan ke konfigurasi aplikasi secara real‑time.
- Kontrol memiliki batasan nilai (mis. `Batch Size` max 20; `Compression` 1–100) yang mencegah input tidak valid.

Gunakan nilai ini untuk memastikan metadata yang dihasilkan sesuai panjang, jumlah tag, dan penggunaan data yang diinginkan. Perubahan berlaku langsung dan memengaruhi permintaan berikutnya ke layanan AI.
