# Generate Metadata Otomatis

Untuk membuat metadata secara otomatis dari file yang sudah diimpor di Image-Tea-nano, pastikan kamu sudah menambahkan API key.

Langkah-langkah:

![Generate Metadata](generate_metadata_button.png)

1. Klik tombol **Generate Metadata**. Tombol akan berubah menjadi **Stop Processes**, yang artinya Image-Tea sedang bekerja mengirimkan file ke API untuk dianalisis. Catatan: Image-Tea tidak menggenerate metadata secara lokal, semua proses dilakukan melalui API.

2. Saat proses berjalan, item pada tabel utama akan berwarna **kuning** sebagai status processing. Setelah selesai, item yang berhasil akan berubah **hijau**. Jika gagal, item akan berubah **merah**. Tidak perlu khawatir jika ada yang gagal, karena kamu bisa mengulangi proses generate untuk file yang gagal setelah semua selesai.

3. Di atas tombol **Generate Metadata** terdapat dropdown dengan pilihan:  

   ![Generate metadata options](res/images/generate_metadata_options.png)

- **All Files**: Menghasilkan metadata untuk semua file di tabel. Gunakan ini saat ingin memproses seluruh koleksi.
- **Selected Only**: Menghasilkan metadata hanya untuk file yang kamu pilih di tabel. Berguna untuk pengujian atau subset tertentu.
- **Failed Only**: Menghasilkan metadata hanya untuk file yang sebelumnya gagal pada proses terakhir. Cocok untuk mengulang file bermasalah.
- **Drafts Only**: Mulai menghasilkan metadata dari file pertama yang berstatus draft dan teruskan ke file berikutnya. Gunakan untuk memproses file yang belum pernah digenerate sebelumnya.
- **Resume From Stopped**: Lanjutkan proses generate dari file pertama yang berstatus stopped. Digunakan untuk melanjutkan proses yang sempat dihentikan tanpa memproses ulang file sebelumnya.
- **All (Rolling API Keys)**: Coba semua API key yang tersedia secara otomatis; jika satu key gagal, sistem beralih ke key berikutnya dan melanjutkan. Berguna jika kamu memiliki beberapa API key agar proses tetap berjalan meski terjadi error pada suatu key.
- **Failed Only (Rolling API Keys)**: Ulangi hanya file yang sebelumnya gagal, namun secara otomatis berpindah ke API key lain ketika satu key gagal sehingga percobaan ulang dapat menggunakan key lain.
- **Selected Only (Rolling API Keys)**: Proses hanya file yang kamu pilih dan otomatis berpindah antar API key jika key saat ini gagal, sehingga set yang dipilih dicoba ulang menggunakan key lain bila diperlukan.
- **Drafts Only (Rolling API Keys)**: Mulai dari file draft pertama dan teruskan sambil menggunakan rolling API keys untuk memulihkan kegagalan key selama proses.

   Gunakan pilihan ini untuk menargetkan file tertentu, mengulang kegagalan, melanjutkan proses yang terhenti, atau menjalankan batch besar sambil memanfaatkan beberapa API key.

Setelah proses selesai, metadata yang dihasilkan hanya tersimpan di database Image-Tea-nano.  
Metadata **belum ditulis ke file asli**, jadi bisa hilang jika kamu melakukan clear atau membersihkan database.  
Untuk menyimpan metadata ke file asli, gunakan fitur tulis metadata.
