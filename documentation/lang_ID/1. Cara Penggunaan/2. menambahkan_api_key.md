# Menambahkan API Key

![Add API Key dialog](res/images/adding_api_key.png)

Image‑Tea‑nano memerlukan API key agar fitur AI dapat digunakan. Berikut cara menambahkan dan menguji API key langsung dari dialog:

1. Buka menu **API** → **Add API Key**, atau klik tombol API Key di toolbar. Dialog **Add API Key** akan muncul.
2. Pilih **Service** dari dropdown (mis. `Gemini`, `OpenAI`, `OpenRouter`, atau `Groq`).
3. Pada dropdown **Model** pilih model yang ingin dipakai. Untuk menambah model custom, klik ikon roda gigi di samping dropdown untuk membuka **Model Manager**.

	![Selecting model](res/images/adding_api_key_selecting_model.png)

4. Di **Model Manager** klik tombol `+` untuk menambahkan model id baru. Masukkan nama model lalu klik `Save`.

	**Catatan penting untuk setiap service:**
	- **Gemini**: Pilih layanan `Gemini` (kolom kiri), lalu tambahkan model seperti `gemini-2.5-flash`, `gemini-2.0-flash-lite`
	- **OpenAI**: Pilih layanan `OpenAI` (kolom kiri), lalu tambahkan model official OpenAI seperti `gpt-4.1`, `gpt-5-mini`
	- **OpenRouter**: Pilih layanan `OpenRouter` (kolom kiri), lalu tambahkan model dengan format lengkap seperti `google/gemini-2.5-flash`, `openai/gpt-4.1`, `anthropic/claude-3.5-sonnet`
	- **Groq**: Pilih layanan `Groq` (kolom kiri), lalu tambahkan model seperti `llama-3.3-70b-versatile`

	![Model Manager](res/images/adding_api_model_manager.png)

	![Add Model](res/images/adding_api_model.png)

5. Kembali ke dialog **Add API Key**, paste API key ke field **API Key** (atau gunakan tombol paste). Kolom **Note** bersifat opsional—tambahkan keterangan jika perlu.
6. Gunakan tombol **Test and Save** untuk menguji koneksi dan menyimpan API key jika tes berhasil. Kamu juga dapat:

 - Menjalankan **Test All** untuk menguji semua API key yang tersimpan.
 - Mengekspor atau mengimpor daftar API key dengan **Export CSV** / **Import CSV**.
 - Menghapus entri dengan tombol **Delete** pada baris masing‑masing.
 - Menjalankan test per‑entri dengan tombol `▶` di kolom Actions.

**Catatan untuk setiap service:**

**Gemini (Google AI Studio):**
 - Pilih `Gemini` sebagai Service
 - Gunakan API key dari Google AI Studio (gratis tersedia)
 - Format model: `gemini-2.5-flash`, `gemini-2.0-flash-lite`

**OpenAI (Official):**
 - Pilih `OpenAI` sebagai Service
 - Gunakan API key resmi dari platform.openai.com
 - Format model: `gpt-4.1`, `gpt-5`, `gpt-5-mini`

**OpenRouter (Multi-Provider Gateway):**
 - Pilih `OpenRouter` sebagai Service (bukan OpenAI!)
 - Gunakan API key dari openrouter.ai (format: `sk-or-...`)
 - Format model: `google/gemini-2.5-flash`, `openai/gpt-4.1`, `anthropic/claude-3.5-sonnet`
 - OpenRouter menyediakan akses ke berbagai AI provider dalam satu API

**Groq (Fast Inference):**
 - Pilih `Groq` sebagai Service
 - Gunakan API key dari groq.com
 - Format model: `llama-3.3-70b-versatile`, dll.

Setelah tersimpan dan lulus pengujian, API key siap digunakan di Image‑Tea‑nano.

OpenRouter — memilih model yang tepat

Saat menggunakan OpenRouter, pilih model id persis seperti yang ditampilkan di halaman model OpenRouter, dan pastikan model mendukung tipe input yang kamu butuhkan:

- Buka halaman Models di OpenRouter dan cari model yang diinginkan. Perhatikan model id yang tertera di bawah nama model (misalnya: `google/gemini-2.5-flash`).

- Model yang sudah kamu tambahkan melalui **Model Manager** akan muncul di dropdown **Model** di Image‑Tea‑nano — pilih model yang diinginkan dari daftar tersebut.
	![Selecting model](res/images/adding_api_key_selecting_model.png)

	![OpenRouter model list](res/images/openrouter_model_page.png)

- Pastikan bagian Input Modalities pada model menyertakan `Image` (dan `Video` jika diperlukan). Jika Image/Video tidak tercantum, model tersebut tidak menerima input tersebut.
- Periksa juga informasi harga yang muncul pada kartu model — OpenRouter menampilkan harga per‑M token untuk input/output. Harga berbeda antar model; catat sebelum menggunakan (contoh pada halaman: `$0.30/M input tokens`, `$2.50/M output tokens`).

- Untuk menyalin model id, klik ikon salin (copy) di dekat model id pada halaman model lalu paste id tersebut persis ke Model Manager.

	![OpenRouter model id and copy button](res/images/openrouter_model_name.png)

Contoh alur singkat:

1. Cari/browse model di OpenRouter, pilih model yang menampilkan `Image` (dan `Video` bila perlu) di Input Modalities.
2. Catat harga per‑M token yang tertera untuk estimasi biaya.
3. Klik ikon salin untuk menyalin model id (contoh: `google/gemini-2.5-flash`).
4. Di Image‑Tea‑nano buka **Model Manager**, pilih layanan `OpenRouter` (kolom kiri), klik `+`, paste model id yang disalin lalu `Save`.
5. Di dialog **Add API Key** pilih `OpenRouter` sebagai Service, pilih model yang baru ditambahkan, paste API key OpenRouter (format: `sk-or-...`), lalu klik **Test and Save**.

Langkah ini membantu mencegah pemilihan model yang tidak mendukung image/video dan memastikan kamu melihat harga token untuk model yang dipilih.

Catatan tanggung jawab — biaya dan pemilihan model

- Memilih model yang salah (misalnya model yang tidak mendukung `Image`/`Video`) atau menggunakan model dengan harga per‑M token lebih tinggi dapat menyebabkan biaya tak terduga. Selalu periksa Input Modalities dan informasi harga sebelum menjalankan permintaan besar.
- Penggunaan token dan penagihan ditentukan oleh model dan penyedia layanan pihak ketiga — pengembang Image‑Tea‑nano tidak bertanggung jawab atas biaya yang timbul dari penggunaan model atau API key pihak ketiga. Lakukan uji coba dengan permintaan kecil dan pantau penggunaan untuk menghindari kejutan.
