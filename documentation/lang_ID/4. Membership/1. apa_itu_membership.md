# Apa itu Image Tea Membership?

Image Tea Membership adalah sistem akses berbasis langganan yang memungkinkan kamu menggunakan fitur pembuatan metadata AI di Image Tea tanpa perlu memiliki API Key sendiri.

Saat kamu menjadi member, Image Tea menggunakan API AI bersama yang disediakan oleh admin. Artinya, kamu bisa langsung mulai membuat metadata tanpa perlu melalui proses mendapatkan dan mengelola API Key sendiri.

## Untuk Siapa Membership Ini?

Membership cocok untuk pengguna yang:

- Tidak ingin repot dengan proses teknis mendapatkan API Key
- Lebih suka layanan yang sudah dikelola, termasuk akses AI-nya
- Ingin pengalaman langsung pakai tanpa konfigurasi tambahan

## Apa yang Didapat dari Membership?

- Akses ke fitur pembuatan metadata AI di Image Tea menggunakan API yang sudah disediakan
- Batas penggunaan (kuota) yang menentukan berapa banyak file yang bisa kamu proses
- Tetap bisa menggunakan API Key pribadi kamu secara terpisah dari membership

## Batas Penggunaan

Setiap akun member memiliki batas penggunaan, yaitu jumlah total file yang boleh kamu proses menggunakan API membership. Setelah batas ini tercapai, proses pembuatan metadata akan berhenti sampai kuota kamu diperbarui oleh admin.

Kamu bisa melihat penggunaan saat ini kapan saja melalui menu **Member** di menu bar.

## Device Lock

Setiap license key terkunci pada satu perangkat. Setelah kamu login di suatu perangkat, lisensi tersebut akan terikat ke perangkat itu. Jika kamu mencoba login di perangkat lain menggunakan license key yang sama, login akan diblokir.

Jika kamu perlu menggunakan akun di perangkat berbeda, hubungi admin untuk meminta reset perangkat.

## Penggunaan Tanpa Membership

Jika kamu memiliki API Key sendiri, kamu tetap bisa menggunakannya tanpa bergantung pada status membership. Membership dan API Key pribadi sepenuhnya independen satu sama lain.
