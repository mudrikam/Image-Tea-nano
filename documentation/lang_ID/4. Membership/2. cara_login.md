# Cara Login sebagai Member

Setelah kamu memiliki akun member dari admin, kamu bisa login ke Image Tea untuk mengaktifkan akses membership kamu.

## Langkah-Langkah Login

1. Buka Image Tea.
2. Klik menu **Member** di menu bar.
3. Klik **Login**.
4. Dialog login akan muncul. Masukkan **Email** dan **License Key** kamu.
5. Klik tombol **Login**.

Jika kredensial kamu benar, Image Tea akan mengonfirmasi bahwa kamu sudah berhasil login. Status membership kamu akan terlihat di aplikasi.

## Setelah Login

Setelah login, menu Member akan berubah menampilkan dua pilihan:

- **Check Limit** - Lihat penggunaan saat ini dan sisa kuota kamu
- **Logout** - Keluar dari akun member kamu

## Kesalahan Login

Jika login gagal, periksa hal-hal berikut:

- Pastikan email dan license key kamu benar (keduanya bersifat case-sensitive, huruf besar dan kecil dibedakan)
- Pastikan kamu terhubung ke internet
- Hubungi admin jika kamu yakin kredensial kamu benar tapi login tetap gagal

## Tetap Login

Image Tea mengingat sesi login kamu selama aplikasi berjalan. Jika kamu menutup dan membuka ulang aplikasi, kamu perlu login kembali.
