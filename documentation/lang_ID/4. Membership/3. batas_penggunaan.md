# Cek Batas Penggunaan

Setiap akun member memiliki batas penggunaan, yaitu jumlah file yang bisa kamu proses menggunakan API membership. Setelah batas ini tercapai, pembuatan metadata AI akan dihentikan sementara untuk akun kamu.

## Cara Memeriksa Penggunaan Kamu

1. Pastikan kamu sudah login sebagai member.
2. Klik menu **Member** di menu bar.
3. Klik **Check Limit**.

Dialog akan muncul dan menampilkan:

- **Used** - Berapa banyak file yang sudah kamu proses
- **Limit** - Total kuota yang diizinkan (menampilkan "Unlimited" jika tidak ada batasan)

## Apa yang Terjadi Ketika Batas Tercapai?

Ketika penggunaan kamu sudah mencapai batas, dialog peringatan akan muncul sebelum Image Tea memproses file apa pun. Pembuatan metadata menggunakan API membership akan diblokir sampai kuota kamu diperbarui oleh admin.

Kamu akan melihat pesan yang memberi tahu bahwa batas penggunaan kamu telah tercapai.

## Apa yang Bisa Dilakukan Saat Batas Tercapai?

- **Hubungi admin** untuk meminta pembaruan atau penambahan kuota
- **Gunakan API Key pribadi kamu** jika kamu sudah mendaftarkannya di Image Tea. API Key pribadi tidak bergantung pada batas membership

## Setelah Kuota Diperbarui

Setelah admin memperbarui kuota kamu, kamu tidak perlu logout lalu login ulang. Image Tea akan otomatis memeriksa ulang kuota terbaru kamu saat kamu mencoba untuk mulai generate.
