# Cara Logout

Jika kamu ingin keluar dari akun member, kamu bisa melakukannya kapan saja.

## Langkah-Langkah Logout

1. Klik menu **Member** di menu bar.
2. Klik **Logout**.

Kamu akan langsung logout. Menu Member akan kembali menampilkan hanya pilihan **Login**.

## Kapan Sebaiknya Logout?

- Jika kamu menggunakan komputer bersama dan ingin melindungi akun kamu
- Jika kamu ingin beralih ke akun member yang berbeda
- Jika kamu sudah selesai menggunakan fitur membership dan hanya ingin menggunakan API Key pribadi

## Setelah Logout

- Pembuatan metadata menggunakan membership tidak akan tersedia lagi
- Jika kamu memiliki API Key pribadi yang sudah dikonfigurasi di Image Tea, API Key tersebut akan tetap berjalan normal
- Kamu bisa login kembali kapan saja dengan mengklik **Member** lalu **Login**
