# Donasi

Terima kasih atas dukungan dan apresiasi kamu terhadap pengembangan Image-Tea-nano.  
Jika kamu ingin memberikan donasi, silakan gunakan QRIS berikut:

![Donasi](qris.jpeg)

Setiap donasi sangat berarti dan akan digunakan untuk mendukung pengembangan aplikasi ini.

Lokasi donasi di aplikasi:
- Pada menu aplikasi: buka **Help** → pilih **Donate**.
- Atau gunakan tombol **Donate** di toolbar aplikasi.

Kami harap kamu sudah merasakan manfaat dari aplikasi sebelum mendonasikan. Masukan dan umpan balik setelah penggunaan membantu kami memperbaiki proyek dan memastikan donasi digunakan untuk fitur yang benar-benar berguna.
