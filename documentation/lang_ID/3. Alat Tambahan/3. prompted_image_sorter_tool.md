# Prompted Image Sorter Tool

Tool ini secara otomatis mengurutkan gambar ke dalam folder berdasarkan klasifikasi AI tentang seberapa baik setiap gambar sesuai dengan kriteria prompt yang kamu definisikan.

## Cara Kerja

1. **Pemilihan Sumber**: Pilih folder yang berisi gambar yang akan diurutkan
2. **Definisi Prompt**: Tentukan kriteria dalam bahasa natural (misalnya "gambar dengan orang", "pemandangan alam", "warna biru")
3. **Klasifikasi AI**: Tool menganalisis setiap gambar dan mengklasifikasinya sebagai "Match" atau "No Match" berdasarkan promptmu
4. **Pengurutan Otomatis**: Gambar yang cocok dipindahkan ke subfolder, gambar yang tidak cocok tetap di lokasi asal

## Cara Menggunakan

1. **Pilih Folder Sumber**: Klik "Browse" untuk memilih folder yang berisi gambar yang akan diurutkan

2. **Masukkan Prompt**: Ketik kriteria pengurutan di kolom prompt. Contoh:
   - "Gambar yang mengandung orang atau wajah"
   - "Pemandangan alam dengan pohon"
   - "Gambar dengan langit biru"
   - "Foto produk dengan latar belakang putih"

3. **Folder Output**: Pilih tempat menyimpan gambar yang cocok (default: subfolder bernama sesuai prompt)

4. **Mulai Pengurutan**: Klik "Run Sorter" untuk memulai proses pengurutan

## Elemen Antarmuka

- **Source Folder**: Folder yang berisi gambar untuk dianalisis
- **Prompt**: Kriteria klasifikasimu dalam bahasa natural
- **Output Folder**: Tempat gambar yang cocok akan dipindahkan
- **Results Table**: Menampilkan setiap gambar dengan status cocok (Match/No Match)
- **Progress Bar**: Menunjukkan kemajuan pengurutan

## Opsi Tambahan

- **Buat Folder Baru**: Klik ikon folder+ untuk membuat subfolder baru di lokasi output
- **Buka Output**: Membuka folder output setelah pengurutan selesai
- **Retry Failed**: Mencoba klasifikasi ulang untuk gambar yang gagal

## Catatan

- Memerlukan login member untuk digunakan
- Gambar yang cocok dengan prompt dipindahkan ke folder output
- Gambar yang tidak cocok tetap di folder sumber
- Tool mempertahankan nama file asli saat memindahkan gambar
