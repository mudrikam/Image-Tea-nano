# Batch Image Resizer Tool

## Ikhtisar

Batch Image Resizer memungkinkan Anda mengubah ukuran banyak gambar sekaligus ke dimensi yang ditentukan, cocok untuk persiapan gambar khusus Envato Elements atau platform lain dengan persyaratan ukuran tertentu.

## Fitur

- **Resize Batch**: Ubah ukuran banyak gambar sekaligus
- **Pilihan Dimensi**: Tentukan target tinggi atau lebar dalam piksel
- **Aspect Ratio**: Mempertahankan rasio aspek selama resize
- **Non-blocking**: Berjalan terpisah tanpa mengganggu interface utama
- **Integrasi Database**: Muat gambar langsung dari database Image Tea

## Cara Penggunaan

### 1. Memilih Gambar Sumber

- **Browse Folder**: Klik ikon folder untuk memilih folder berisi gambar
- **Drag & Drop**: Seret dan lepas gambar langsung ke input field
- **Paste Path**: Tempel path dari clipboard menggunakan tombol paste

### 2. Mengatur Parameter Resize

- **Mode Resize**: Pilih "Height" atau "Width" sebagai acuan ukuran
- **Nilai Ukuran**: Masukkan ukuran target dalam piksel (misal: 1500, 1820)
- Gambar akan diresize secara proporsional

### 3. Memproses Gambar

- Klik tombol "RESIZE" untuk memulai proses batch
- Progress bar menampilkan progres saat ini
- Tabel file menampilkan status setiap gambar (Ready, Resizing, Completed)

## Persyaratan

- **File Sumber**: Gambar dengan format JPG, JPEG, PNG, BMP, TIFF, GIF, WEBP
- **Python Imaging Library**: Memerlukan Pillow (PIL) untuk resize gambar

## Catatan

- Format output selalu PNG dengan kualitas tinggi
- Nama file asli dipertahankan di output
- Folder output otomatis dibuat sebagai subfolder "RESIZED"
