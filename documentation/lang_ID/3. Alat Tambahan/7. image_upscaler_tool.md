# Image Upscaler Tool

Tool ini membantu kamu meningkatkan resolusi gambar menggunakan RealESRGAN. Kamu bisa upscale gambar dalam batch dengan berbagai model AI dan pengaturan kualitas.

## Cara Menggunakan

1. **Load Gambar**: Pilih sumber gambar yang ingin di-upscale.
   - Klik "Load Database" untuk memuat semua gambar dari database aplikasi.
   - Klik "Load Folder" untuk memilih folder yang berisi gambar.
   - Klik "Load File" untuk memilih satu gambar saja.

2. **Atur Pengaturan**:
   - **Model**: Pilih model AI yang akan digunakan untuk upscaling.
   - **Scale**: Pilih faktor perbesaran (2x, 3x, atau 4x).
   - **Batch**: Tentukan jumlah gambar yang diproses sekaligus (lebih tinggi = lebih cepat tapi butuh lebih banyak RAM).
   - **Format**: Pilih format output (PNG, JPG, atau WEBP).

3. **Set Folder Output**: Klik ikon folder untuk memilih tempat menyimpan hasil upscaling. Jika kosong, hasil akan disimpan di folder default.

4. **Jalankan Upscaling**: Klik tombol "RUN UPSCALE" untuk memulai proses. Tool akan memproses semua gambar dan menampilkan progress di bar progress.

## Fitur Utama

### Load dan Manage Gambar
- **Load Database**: Muat semua gambar dari database Image-Tea.
- **Load Folder**: Pilih folder untuk memuat semua gambar di dalamnya.
- **Load File**: Tambah satu gambar ke daftar.
- **Clear**: Hapus semua gambar dari daftar.

### Pengaturan Output
- **Output Folder**: Tentukan folder untuk menyimpan hasil.
- **Browse**: Jelajahi dan pilih folder output.
- **Paste**: Tempel path folder dari clipboard.
- **Clear**: Hapus path folder output.

### Model dan Scale
- Model otomatis terdeteksi dari folder models.
- Scale akan otomatis terkunci jika model sudah menyertakan faktor scale (misalnya model-x4).
- Batch size memengaruhi kecepatan dan penggunaan memori.

### Pengelola Model
- Buka Pengelola Model dengan mengklik **ikon roda gigi** di sebelah pemilih Model. Di sana kamu dapat melihat semua model upscaling dan melakukan tindakan: tambah, edit, hapus, ekspor, atau refresh.
- Tambah / Import: Klik **Add** atau **Import** untuk membuka dialog. Isi nama model, pilih tipe (NCNN / PTH / ONNX), pilih skala (2x/3x/4x), tambahkan deskripsi bila mau, dan pilih file model yang diperlukan. NCNN membutuhkan dua file (parameter + bobot); PTH dan ONNX membutuhkan satu file model. Dialog melakukan validasi dasar (nama wajib, file wajib saat menambah). Model yang berhasil diimpor akan disalin ke folder model aplikasi dan langsung tersedia di daftar.
- Edit: Pilih model lalu klik **Edit** untuk mengubah properti yang bisa diubah (misalnya skala dan deskripsi). Nama, tipe, dan file model tidak dapat diubah melalui dialog edit.
- Hapus: Pilih model dan klik **Delete** lalu konfirmasi. Kamu akan ditanya apakah ingin juga menghapus file model; memilih Ya akan menghapus file dari penyimpanan aplikasi.
- Ekspor: Pilih model lalu klik **Export** untuk menyalin model ke folder pilihanmu.
- Refresh & Buka folder: Klik **Refresh** untuk memindai ulang folder model dan memperbarui daftar. Gunakan **Open Models Folder** untuk membuka folder tempat model disimpan.
- Dependensi runtime: Pengelola menampilkan status dukungan PTH dan ONNX serta menyediakan tombol install/uninstall. Jika kamu menjalankan upscaler dengan model PTH/ONNX sementara dependensi belum terpasang, upscaler akan menanyakan apakah kamu ingin memasangnya dan dapat menjalankan installer.

## Status dan Progress

- **Files**: Menampilkan jumlah gambar yang dimuat.
- **Images**: Menampilkan progress pemrosesan gambar (diproses/total).
- **Elapsed**: Waktu yang sudah berlalu sejak mulai.
- **ETA**: Perkiraan waktu selesai.
- **Remaining**: Jumlah gambar yang masih belum diproses.
- **Status**: Status proses saat ini (Idle/Running).

## Log dan Monitoring

- **Process Logs**: Menampilkan detail proses upscaling, error, dan informasi penting.
- **Progress Bar**: Menunjukkan persentase penyelesaian.
- **Icon Status**: Ikon centang (hijau) untuk berhasil, ikon X (merah) untuk gagal.

## Kontrol Proses

- **RUN UPSCALE**: Mulai proses upscaling.
- **STOP**: Hentikan proses yang sedang berjalan.

## Tips Penggunaan

- Pastikan folder models RealESRGAN sudah terinstall dengan benar.
- Gunakan batch size yang sesuai dengan kapasitas RAM komputer kamu.
- PNG memberikan kualitas terbaik tapi file size lebih besar.
- JPG lebih kecil tapi bisa ada kompresi artefak.
- WEBP memberikan keseimbangan antara kualitas dan ukuran file.

Tool ini akan otomatis mendeteksi dan menggunakan hardware acceleration jika tersedia. Pastikan driver GPU terbaru untuk performa optimal.</content>
