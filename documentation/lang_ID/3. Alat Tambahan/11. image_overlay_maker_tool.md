# Image Overlay Maker Tool

Tool ini menerapkan gambar overlay PNG ke banyak gambar dasar secara batch, sempurna untuk menambahkan watermark, tekstur, atau elemen desain ke koleksi gambarmu.

## Cara Kerja

1. **Pemilihan Sumber**: Pilih folder gambar atau pilih file gambar individu
2. **Pemilihan Overlay**: Pilih file overlay PNG dengan transparansi
3. **Folder Output**: Pilih tempat menyimpan gambar yang telah diproses
4. **Pemrosesan Batch**: Tool ini menerapkan overlay ke semua gambar yang dipilih secara otomatis

## Cara Menggunakan

### Langkah 1: Pilih Gambar Sumber
- Klik **Browse** di sebelah Source untuk memilih folder, atau
- Klik **Files** untuk memilih gambar individu
- Kamu juga bisa drag and drop folder atau file langsung ke kolom input

### Langkah 2: Pilih Gambar Overlay
- Klik **Browse** di sebelah Overlay untuk memilih file PNG dengan transparansi
- Overlay akan diubah ukurannya untuk cocok dengan dimensi setiap gambar dasar

### Langkah 3: Pilih Lokasi Output
- Folder output dihasilkan otomatis sebagai subfolder bernama "OVERLAY_OUTPUT"
- Kamu bisa menyesuaikannya dengan mengklik **Browse** di sebelah Output

### Langkah 4: Proses Gambar
- Klik **Process Images** untuk memulai operasi batch
- Progress bar menampilkan status saat ini
- Saat selesai, kamu bisa memilih untuk membuka folder output

## Elemen Antarmuka

- **Source Input**: Jalur folder atau jumlah file untuk gambar yang dipilih
- **Overlay Input**: Jalur ke file overlay PNG
- **Output Input**: Folder tujuan untuk gambar yang diproses
- **File Table**: Menampilkan semua gambar yang dimuat dengan nama file dan jalur
- **Stats Bar**: Menampilkan jumlah file dan status pemrosesan
- **Process Button**: Memulai/menjeda pemrosesan batch

## Opsi Tambahan

- **Tombol Paste**: Tempel jalur dari clipboard dengan cepat
- **Tombol Open**: Buka lokasi file di file explorer sistem kamu
- **Tombol Clear**: Hapus semua file dari daftar
- **Drag & Drop**: Drop folder atau file langsung ke kolom input

## Catatan

- Gambar overlay sebaiknya format PNG dengan transparansi untuk hasil terbaik
- Overlay diperluas untuk cocok dengan dimensi setiap gambar dasar
- Pemrosesan menggunakan alpha compositing untuk blending yang halus
- Nama file asli gambar dipertahankan di output
