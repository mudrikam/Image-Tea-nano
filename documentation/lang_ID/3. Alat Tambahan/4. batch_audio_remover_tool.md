# Batch Audio Remover Tool

Tool ini membantu kamu menghapus audio dari video secara batch. Kamu bisa memproses banyak video sekaligus dan menyimpan hasilnya ke folder tujuan.

## Cara Menggunakan

1. **Load Data Video**: Klik "Load from Database" untuk ambil video dari database yang ada, atau "Select Source" untuk pilih folder yang berisi video.

2. **Pilih Folder Tujuan**: Klik "Select Destination" untuk pilih folder penyimpanan video hasil proses.

3. **Opsional - Scan Destination**: Klik "Scan Destination" untuk cek file yang sudah ada di folder tujuan.

4. **Opsional - Check GPU**: Klik "Check GPU" untuk cek dukungan GPU untuk akselerasi hardware.

5. **Mulai Proses**: Klik "Start Process" untuk mulai hapus audio dari semua video. Kamu bisa lihat progress di bar progress dan stats di bawah.

6. **Pantau Progress**: Tabel kiri menampilkan file source dengan status, tabel kanan menampilkan file destination dengan status. Stats menunjukkan total, success, failed, dll.

## Tombol Utama

- **Load from Database**: Ambil semua video dari database aplikasi.
- **Select Source**: Pilih folder yang berisi video untuk diproses.
- **Select Destination**: Pilih folder untuk menyimpan video hasil proses.
- **Scan Destination**: Scan folder tujuan untuk cek file existing.
- **Check GPU**: Cek apakah GPU mendukung akselerasi.
- **Clear All**: Reset tool dan hapus semua data.

## Tabel File

- **Source Files**: Daftar video yang akan diproses dengan status masing-masing.
- **Destination Files**: Daftar video hasil proses dengan status.

## Stats dan Progress

- **Total**: Jumlah total video.
- **Success**: Video yang berhasil diproses.
- **Failed**: Video yang gagal diproses.
- **Stopped**: Video yang dihentikan.
- **Remaining**: Video yang belum diproses.
- **Progress**: Persentase kemajuan.
- **Elapsed**: Waktu yang sudah berlalu.
- **ETA**: Estimasi waktu selesai.
- **Speed**: Kecepatan pemrosesan (file per detik).

Tool ini akan menyimpan video tanpa audio ke folder tujuan dengan nama file sama. Pastikan folder tujuan punya cukup ruang penyimpanan.
