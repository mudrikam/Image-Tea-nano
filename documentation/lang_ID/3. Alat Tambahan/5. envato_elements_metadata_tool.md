# Envato Mockup Metadata Generator

Tool ini membuat metadata mockup Envato Elements dan dapat mengirim metadata serta file konten ke ekstensi browser Envato yang sudah terhubung.

## Persyaratan

- Gemini API key yang valid di Image Tea.
- Ekstensi browser Envato sudah dipasang dan terhubung.
- Halaman submission item Envato Elements sedang terbuka.
- Folder sumber berisi minimal satu PSD, satu gambar preview (`.png`, `.jpg`, atau `.jpeg`), dan satu cover dengan nama file berakhiran `_cover`.
- Satu file PDF guide.

## Membuat Metadata

1. Buka tool dari Image Tea dan pilih Gemini API key di **Configuration**.
2. Masukkan gambar mockup dengan drag ke area gambar, klik **Open**, atau klik **Paste**.
3. Klik **Process Image** untuk membuat metadata.
4. Periksa dan edit field berikut:
   - **Title**: 30-100 karakter.
   - **Tagline**: Maksimal 100 karakter.
   - **DPI, Width, Height**: Spesifikasi teknis.
   - **Tags**: Kata kunci, biasanya 15 tag.
   - **Items**: Jumlah item mockup.
   - **Description**: Deskripsi listing lengkap.

## Menyiapkan Content Files

1. Buka tab **Content Files**.
2. Drop atau pilih folder sumber.
3. Drop atau pilih file PDF guide.
4. Pastikan empat indikator siap: **PSD**, **Preview**, **Cover**, dan **PDF**.
5. Klik **Process Files**. Tool membuat `Main File.zip` di dalam folder sumber. Jika archive sudah ada dan semua file siap, archive tidak dibuat ulang.

Cover dicari secara rekursif dari nama file gambar yang berakhiran `_cover`, misalnya `1_cover.png`. Gambar preview adalah file gambar yang tidak memakai akhiran `_cover`.

## Mengirim ke Envato

1. Buka halaman submission item Envato di browser dan hubungkan ekstensi.
2. Biarkan halaman Envato tetap aktif selama proses pengiriman.
3. Kembali ke Image Tea dan pastikan **Send Files** sudah aktif. Tombol tetap disable sampai ekstensi terhubung dan keempat status Content Files siap.
4. Klik **Send Files** satu kali.
5. Ekstensi mengisi metadata, memilih `RGB` dan `px`, lalu mengupload cover yang terdeteksi.
6. Gambar preview diupload satu per satu. Ekstensi menunggu sampai setiap preview muncul di daftar preview Envato dan selesai dimuat sebelum mengupload preview berikutnya.
7. Setelah semua preview siap, ekstensi menampilkan countdown lalu memilih `Main File.zip` melalui input file ZIP.

Jangan klik **Send Files** lagi saat log ekstensi masih berjalan. Urutan upload ini diperlukan karena Envato dapat gagal jika preview dan ZIP utama diupload bersamaan.

## Preview dan JSON

- Panel **Results** menampilkan listing yang sudah dirender tanpa gambar sumber.
- Markdown pada description ditampilkan sebagai heading, paragraf, list, dan catatan.
- Gunakan **Copy JSON Metadata** untuk menyalin `title`, `tagline`, `description`, dan `tags` jika tidak membutuhkan automation browser.

## Troubleshooting

- Jika **Send Files** disable, lengkapi status PSD, Preview, Cover, dan PDF lalu hubungkan ekstensi.
- Jika ekstensi tidak menerima command, buka side panel ekstensi, klik **Connect**, dan pastikan tab submission Envato aktif.
- Jika ekstensi browser baru saja diperbarui, reload ekstensi dari halaman ekstensi browser sebelum mencoba lagi.
- Jangan memulai pengiriman baru saat preview masih diupload. Tunggu sampai countdown dan log pemilihan ZIP selesai.

## Opsi Tambahan

- **Always on Top** menjaga dialog tetap berada di atas window lain.
- **Settings** mengubah batas dan nilai default konfigurasi.
