# Envato Mockup Metadata Generator

Tool ini membantu kamu membuat metadata untuk mockup Envato Elements secara otomatis. Kamu bisa upload gambar mockup dan tool akan generate title, tagline, tags, dan description yang sesuai standar Envato Elements.

## Cara Menggunakan

1. **Pilih API Key**: Di bagian API Configuration, pilih api key Gemini yang valid dari dropdown.

2. **Load Gambar**: 
   - Drag & drop gambar mockup ke area "Drag & Drop Image Here".
   - Atau klik "Open" untuk pilih file gambar.
   - Atau klik "Paste" untuk paste gambar dari clipboard.

3. **Proses Gambar**: Klik "Process Image" untuk mulai generate metadata. Tool akan analisis gambar menggunakan AI dan isi field metadata secara otomatis.

4. **Edit Metadata**: Sesuaikan hasil generate di field-field berikut:
   - **Title**: Judul mockup (30-100 karakter).
   - **Tagline**: Deskripsi singkat (maks 100 karakter).
   - **DPI, Width, Height**: Spesifikasi teknis gambar.
   - **Tags**: Kata kunci (harus 15 tags).
   - **Items**: Jumlah item dalam mockup.
   - **Description**: Deskripsi lengkap.

5. **Copy Metadata**: Klik ikon copy di sebelah kanan setiap field untuk copy ke clipboard.

6. **Preview dan JSON Automation**:
   - Panel kanan menampilkan listing Envato yang sudah dirender tanpa gambar sumber.
   - Markdown dari template description dirender sebagai heading, paragraf, list, dan catatan.
   - Klik **Copy JSON Metadata** untuk menyalin payload final empat field: `title`, `tagline`, `description`, dan `tags`.
   - Description yang disalin sudah berisi features yang digabung dan nilai teknis yang sudah diganti; tidak perlu placeholder atau pemrosesan lanjutan.

## Opsi Tambahan

- **Always on Top**: Centang agar dialog tetap di atas jendela lain.
- **Settings**: Klik untuk ubah konfigurasi limits dan defaults.

## Status dan Progress

- **Progress Bar**: Tunjukkan progress pemrosesan gambar.
- **Status Label**: Berikan informasi tentang status saat ini (Ready, Processing, dll).

Tool ini menggunakan AI untuk analisis gambar dan generate metadata yang relevan. Pastikan gambar mockup berkualitas baik untuk hasil terbaik.
