# Action Sequencer Tool

Tool ini membantu kamu menjalankan sequence action pada file menggunakan Adobe Photoshop atau Illustrator. Kamu bisa membuat preset yang berisi langkah-langkah action, lalu menerapkannya pada satu file atau banyak file sekaligus.

## Cara Menggunakan

1. **Pilih Platform**: Pilih platform yang ingin digunakan (Photoshop atau Illustrator) dari dropdown di bagian atas.

2. **Pilih Preset**: Klik preset yang sudah dibuat dari daftar preset. Setiap preset berisi urutan action yang akan dijalankan.

3. **Load File**: 
   - Klik "Load from Database" untuk memuat semua file dari database aplikasi.
   - Atau klik "Select Source" untuk memilih folder yang berisi file.
   - Atau klik "Select File" untuk memilih satu file saja.

4. **Set Output Path**: Klik ikon folder di sebelah kanan untuk memilih folder tempat menyimpan hasil output.

5. **Jalankan Sequence**: Klik tombol "Run Sequences" untuk memulai proses. Tool akan membuka aplikasi Adobe dan menjalankan action sesuai preset yang dipilih.

## Mode Processing

- **Batch Mode**: Memproses banyak file sekaligus. Cocok untuk preset dengan tipe "Batch".
- **Single Mode**: Memproses satu file saja. Cocok untuk preset dengan tipe "Single".

## Fitur Utama

### Preset Management
- **Add Preset**: Buat preset baru dengan klik tombol "+" di tab Presets.
- **Edit Preset**: Klik kanan pada preset untuk mengedit nama dan pengaturan.
- **Remove Preset**: Klik kanan pada preset untuk menghapus (akan menghapus semua step di dalamnya).

### Step Management
- **Add Step**: Klik tombol "+" di tab Steps untuk menambah action ke preset.
- **Edit Step**: Klik kanan pada step untuk mengedit pengaturan action.
- **Delete Step**: Klik kanan pada step untuk menghapus dari preset.
- **Reorder Steps**: Drag and drop step untuk mengubah urutan eksekusi.

### Action Management
- **Action Sets**: Kelola kumpulan action di tab Actions.
- **Add Action**: Buat action baru dengan parameter khusus.
- **Edit Action**: Ubah pengaturan action yang sudah ada.

## Status dan Progress

- **Files Count**: Menampilkan jumlah file yang akan diproses.
- **Steps Count**: Menampilkan jumlah step dalam preset yang dipilih.
- **Progress Bar**: Menunjukkan kemajuan pemrosesan file.
- **Status Label**: Memberikan informasi tentang status proses saat ini.

## Kontrol Proses

- **Run Sequences**: Mulai menjalankan sequence action.
- **Stop Process**: Hentikan proses yang sedang berjalan.
- **Continue Process**: Lanjutkan proses yang dihentikan (jika dalam mode pause).
- **Reset Tool**: Hapus semua data yang dimuat dan kembalikan ke kondisi awal.

## Pengaturan

Klik tombol "Settings" untuk mengatur:
- **Platform Paths**: Lokasi executable Photoshop/Illustrator.
- **Output Settings**: Prefix, suffix, dan opsi file watcher.
- **Watch Timeout**: Waktu tunggu untuk mendeteksi file output.

## Tips Penggunaan

- Pastikan executable path Adobe aplikasi sudah dikonfigurasi dengan benar.
- Gunakan file watcher untuk memastikan semua output terdeteksi.
- Untuk batch processing, pastikan folder output memiliki cukup ruang penyimpanan.
- Jika proses terhenti, kamu bisa melanjutkan dari file terakhir yang diproses.

Tool ini akan otomatis membersihkan file temporary JSX saat ditutup. Pastikan koneksi dengan Adobe aplikasi berjalan lancar untuk hasil terbaik.
