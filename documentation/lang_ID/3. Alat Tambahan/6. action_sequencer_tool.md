# Action Sequencer Tool

Tool ini membantu kamu menjalankan sequence action pada file menggunakan Adobe Photoshop atau Illustrator. Kamu bisa membuat preset yang berisi langkah-langkah action, lalu menerapkannya pada satu file atau banyak file sekaligus.

## Cara Menggunakan

1. **Tambahkan Platform**: Tambahkan platform ke Action Sequencer dengan memilih platform (mis. Photoshop atau Illustrator), isi **Exe Path** dengan path executable aplikasi, beri catatan jika perlu, lalu klik tombol **+ Add** di Action Settings.

	![Action Settings](res/images/action_sequencer_settings.png)

2. **Tambahkan Action Set**: Tambahkan Action Set ke Action Sequencer dengan memilih tab **Action Sets** atau area Presets lalu klik tombol **+ Add**. **Sebelum klik** **+ Add**, pastikan pilihan **Platform** di bagian atas Action Sequencer sesuai dengan platform yang kamu tambahkan di Langkah 1 (Settings → Platform). Pastikan **nama** Action Set sama dengan nama Action Set di Photoshop agar sequencer dapat memanggil action yang benar. Isi **Description** bila perlu, lalu klik **Save**.

	![Action Sets](res/images/action_sequencer_adding_action_sets.png)

	*Di daftar Action Sets, kamu dapat melihat set yang sudah ada; klik **+ Add** untuk membuat set baru.*

	![Add New Action Set](res/images/action_sequencer_adding_action_sets_new_set.png)

	*Dialog **Add New Action Set**: isi **Set Name** (harus sama dengan Action Set di Photoshop) dan optional **Description**, lalu klik **Save**.*

	![Action Set di Photoshop](res/images/action_sequencer_adding_action_sets_on_photoshop.png)

	*Panel Actions di Photoshop: pastikan Action Set dan nama action yang akan dipanggil ada di Photoshop.*

3. **Tambahkan Action**: Pilih Action Set yang tadi kamu buat, kemudian di bagian kanan klik **Add New Action**. Pada dialog **Add New Action** pilih tipe **Action** sesuai kebutuhan, lalu isi field **Name** (contoh: `makeSmartObject`) — pastikan nama sama persis dengan nama action di Photoshop agar sequencer dapat memanggilnya. Berikan **Icon** dan **Color** untuk memudahkan identifikasi, dan atur opsi lain (Delay, Export, dll.) bila diperlukan. Setelah selesai, klik **Save**.

	![Add Action](res/images/action_sequencer_adding_action.png)

	*Gunakan area **Add New Action** untuk menambahkan action baru pada Action Set yang dipilih; area ini menunjukkan lokasi di mana action baru akan muncul.*

	![Add Action Example](res/images/action_sequencer_add_action_example.png)

	*Di dialog **Add New Action**: pilih **Type**, isi **Name** (harus persis sama dengan nama action di Photoshop), pilih **Icon** dan **Color** untuk identifikasi, atur **Delay** atau opsi **Export** bila diperlukan, lalu klik **Save**.*

4. **Tambahkan Preset**: *Preset* adalah kumpulan urutan langkah action (workflow) yang sudah kamu susun, dan dapat dijalankan kembali. Saat membuat preset, isi **Preset Name** dengan nama yang deskriptif, pilih **Preset Type** (`Batch` untuk banyak file, `Single` untuk dokumen aktif), dan masukkan **Description** bila perlu.

	![Presets list](res/images/action_sequencer_adding_presets.png)

	*Preset baru akan muncul di daftar Presets — gunakan nama yang mudah dikenali.*

	![Add New Preset](res/images/action_sequencer_add_new_preset.png)

	*Dialog **Add New Preset**: isi **Preset Name**, pilih **Preset Type** dan tambahkan **Description** bila perlu, lalu klik **Save**.*

5. **Tambahkan Step ke Preset**: Pilih preset yang sudah dibuat dari daftar Presets untuk mengedit workflow‑nya. Di panel sebelah kanan klik **Select Action** (atau area **+ Add**) untuk membuka dialog **Select Action to Add**, lalu pilih action dari Action Set yang sudah kamu buat sebelumnya. Pilih action (mis. `makeSmartObject`) lalu klik **Add Action** untuk menyisipkannya ke daftar langkah preset. Workflow akan menjalankan action sesuai urutan — ubah urutan atau edit langkah bila diperlukan.

	![Select Action to Add](res/images/action_sequencer_add_step_to_preset.png)

	*Di dialog **Select Action to Add**: pilih action dari daftar Action Sets di kiri lalu klik **Add Action** untuk menambahkannya ke workflow preset yang aktif.*

6. **Load File**: 
   - Klik "Load from Database" untuk memuat semua file dari database aplikasi.
   - Atau klik "Select Source" untuk memilih folder yang berisi file.
   - Atau klik "Select File" untuk memilih satu file saja.

7. **Set Output Path**: Klik ikon folder di sebelah kanan untuk memilih folder tempat menyimpan hasil output.

8. **Run Sequence**: Klik tombol "Run Sequences" untuk memulai proses. Tool akan membuka aplikasi Adobe dan menjalankan action sesuai preset yang dipilih.

## Mode Processing

- **Batch Mode**: Memproses banyak file sekaligus. Cocok untuk preset dengan tipe "Batch".
- **Single Mode**: Memproses satu file saja. Cocok untuk preset dengan tipe "Single".

## Fitur Utama

### Preset Management
- **Add Preset**: Buat preset baru dengan klik tombol "+" di tab Presets.
- **Edit Preset**: Klik kanan pada preset untuk mengedit nama dan pengaturan.
- **Remove Preset**: Klik kanan pada preset untuk menghapus (akan menghapus semua step di dalamnya).

### Step Management
- **Add Step**: Klik tombol "+" di tab Steps untuk menambah action ke preset.
- **Edit Step**: Klik kanan pada step untuk mengedit pengaturan action.
- **Delete Step**: Klik kanan pada step untuk menghapus dari preset.
- **Reorder Steps**: Drag and drop step untuk mengubah urutan eksekusi.

### Action Management
- **Action Sets**: Kelola kumpulan action di tab Actions.
- **Add Action**: Buat action baru dengan parameter khusus.
- **Edit Action**: Ubah pengaturan action yang sudah ada.

## Status dan Progress

- **Files Count**: Menampilkan jumlah file yang akan diproses.
- **Steps Count**: Menampilkan jumlah step dalam preset yang dipilih.
- **Progress Bar**: Menunjukkan kemajuan pemrosesan file.
- **Status Label**: Memberikan informasi tentang status proses saat ini.

## Kontrol Proses

- **Run Sequences**: Mulai menjalankan sequence action.
- **Stop Process**: Hentikan proses yang sedang berjalan.
- **Continue Process**: Lanjutkan proses yang dihentikan (jika dalam mode pause).
- **Reset Tool**: Hapus semua data yang dimuat dan kembalikan ke kondisi awal.

## Pengaturan

Klik tombol "Settings" untuk mengatur:
- **Platform Paths**: Lokasi executable Photoshop/Illustrator.
- **Output Settings**: Prefix, suffix, dan opsi file watcher.
- **Watch Timeout**: Waktu tunggu untuk mendeteksi file output.

## Tips Penggunaan

- Pastikan executable path Adobe aplikasi sudah dikonfigurasi dengan benar.
- Gunakan file watcher untuk memastikan semua output terdeteksi.
- Untuk batch processing, pastikan folder output memiliki cukup ruang penyimpanan.
- Jika proses terhenti, kamu bisa melanjutkan dari file terakhir yang diproses.

Tool ini akan otomatis membersihkan file temporary JSX saat ditutup. Pastikan koneksi dengan Adobe aplikasi berjalan lancar untuk hasil terbaik.
