# Vibe Video Generator

Vibe Video Generator adalah alat berbasis AI yang memungkinkan kamu membuat skrip animasi video menggunakan TypeScript dan React (didukung oleh Remotion), membuat skrip secara otomatis dari deskripsi teks, melihat pratinjau langsung di dalam aplikasi, dan merendernya menjadi file video nyata — semuanya dalam satu tempat.

> **Alat ini membutuhkan login Member.** Kamu harus sudah login untuk mengaksesnya.

---

## Gambaran Antarmuka

Jendela dibagi menjadi tiga area utama:

- **Menu bar** (atas) — menu File untuk membuat koleksi dan skrip
- **Panel kiri** — pohon koleksi untuk mengorganisir skrip-skrip kamu
- **Panel kanan** — area bertab: editor TypeScript, Pratinjau, Output, dan Pengaturan Render
- **Bar bawah** — kontrol render cepat dan tombol Render Video

---

## Panel Koleksi (Kiri)

Panel ini menampilkan semua koleksi skrip kamu dalam struktur pohon. Bayangkan koleksi sebagai folder untuk mengorganisir skrip-skrip kamu.

- **Klik koleksi** untuk membuka atau menutupnya dan melihat skrip di dalamnya
- **Klik skrip** untuk membukanya di editor TypeScript
- **Klik kanan pada koleksi** untuk mendapatkan menu dengan pilihan:
  - *New Collection* — buat koleksi baru di level utama
  - *New Subfolder* — buat sub-koleksi di dalam koleksi yang dipilih
  - *New Script* — buat skrip baru di dalam koleksi yang dipilih
  - *Edit* — ubah nama, ikon, atau warna koleksi
  - *Delete* — hapus permanen koleksi beserta semua skrip di dalamnya
- **Klik kanan pada skrip** untuk mendapatkan:
  - *Edit* — buka editor skrip
  - *Delete* — hapus permanen skrip tersebut

---

## Menu File

Terletak di menu bar bagian atas jendela.

- **New Collection** (`Ctrl+Shift+N`) — membuka dialog untuk membuat koleksi baru. Kamu bisa mengatur nama, deskripsi, ikon, dan warna koleksi.
- **New Script** (`Ctrl+N`) — membuka dialog Skrip Baru untuk koleksi yang sedang dipilih. Jika belum ada koleksi yang dipilih, kamu akan diminta memilih koleksi terlebih dahulu.

---

## Dialog New Script / Edit Script

Dialog ini terbuka saat kamu membuat atau mengedit skrip. Ada dua tab:

### Tab Generate with AI

Gunakan tab ini untuk membuat skrip secara otomatis dari deskripsi teks.

1. **Kotak deskripsi** — ketik seperti apa video yang kamu inginkan. Kamu bisa mendeskripsikannya sejelas mungkin. Contoh:
   - *"Hitungan mundur dari 10 ke 0 dengan latar belakang merah bercahaya"*
   - *"Kata SALE muncul dengan efek bounce, lalu bergeser keluar ke kanan"*
2. **Refine Prompt** — jika deskripsimu masih kasar, klik tombol ini. AI akan mengembangkannya menjadi prompt yang lebih detail dan terstruktur secara otomatis.
3. **Generate Script** — mengirim deskripsimu ke AI dan menghasilkan skrip animasi TypeScript. Hasilnya otomatis muncul di tab TypeScript.

### Tab TypeScript

Menampilkan kode TypeScript/React yang sudah dihasilkan atau ditulis secara manual. Kamu bisa langsung mengedit kodenya di sini sebelum menyimpan.

- **Script Name** — wajib diisi. Nama ini akan menjadi nama file saat di-render.
- **Description** — opsional, catatan singkat tentang isi skrip.
- Tombol **Save / Create** — menyimpan skrip ke koleksi yang dipilih.

---

## Tab TypeScript (Editor Utama)

Menampilkan kode skrip yang sedang dipilih dengan penyorotan sintaks lengkap.

- Untuk mengedit skrip, klik kanan di panel kiri dan pilih **Edit**, atau buat baru melalui menu File.
- **Refine with AI** — kotak teks dan tombol di bagian bawah editor. Ketik instruksi (misalnya *"buat teksnya jadi merah"* atau *"tambahkan efek fade-out di akhir"*) lalu klik Refine. AI akan menerapkan perubahan pada kode yang sudah ada dengan edit yang minimal dan tepat sasaran.

---

## Tab Preview

Memungkinkan kamu melihat pratinjau animasi langsung di dalam aplikasi menggunakan browser tersemat yang ditenagai Remotion Studio.

- **Start Preview** — memulai server pratinjau lokal dan memuat skrip yang sedang aktif. Mungkin butuh beberapa detik saat pertama kali distart.
- **Stop** — menghentikan server pratinjau.
- **Reload** — menyegarkan pratinjau untuk mencerminkan perubahan kode terbaru.
- **Open in Browser** — membuka pratinjau Remotion Studio di browser bawaanmu untuk tampilan yang lebih besar.

> Skrip harus sudah dipilih dan terbuka di editor TypeScript sebelum kamu bisa memulai pratinjau.

---

## Tab Output

Mengatur di mana dan bagaimana video hasil render akan disimpan.

- **Filename** — nama file output (tanpa ekstensi). Otomatis terisi dari nama skrip saat kamu memilih sebuah skrip.
- **Output** — folder tempat video akan disimpan. Gunakan tombol **Browse** untuk memilih folder, tombol **Paste** untuk menempelkan path dari clipboard, atau tombol **Open** untuk membuka folder saat ini di Explorer.
- **Format** — format file output. Pilihan: `mp4`, `webm`, `mov`, `gif`, `png`, `jpg`, `mp3`, `wav`, `aac`.
- **Overwrite existing file** — jika dicentang, file yang sudah ada dengan nama yang sama akan ditimpa.
- **Output as image sequence** — merender setiap frame sebagai gambar terpisah, bukan file video.
- **Mute audio** — merender video tanpa audio.
- **Enforce silent audio track** — memaksa track audio kosong tetap disertakan meski skrip tidak memiliki audio.

## Tab Render Settings

Pengaturan detail tentang cara video di-render.

### Preset

Dropdown pilihan cepat untuk memuat sekumpulan pengaturan yang sudah ditetapkan:

| Preset | Resolusi | FPS |
|---|---|---|
| 720p30 | 1280 × 720 | 30 |
| 1080p60 | 1920 × 1080 | 60 |
| 2K60 | 2560 × 1440 | 60 |
| 4K60 | 3840 × 2160 | 60 |

- **Save** — menyimpan pengaturan saat ini sebagai preset Custom.
- **Reset** — mengembalikan ke pengaturan 1080p60.

### Pengaturan Video

- **Width / Height** — resolusi output dalam piksel.
- **FPS** — jumlah frame per detik.
- **Duration** — durasi total video dalam detik.
- **Codec** — codec video yang digunakan (misalnya `h264`, `h265`, `vp8`, `vp9`).
- **Pixel Format** — format encoding piksel (misalnya `yuv420p`).
- **Scale** — faktor skala yang diterapkan setelah render.
- **Image Format** — format frame perantara saat render berlangsung (`jpeg` atau `png`).

### Pengaturan Audio

- **Audio Codec** — codec yang digunakan untuk encoding audio.
- **Audio Bitrate** — kualitas audio dalam kbps.

### Pengaturan Performa

Mengontrol jumlah thread CPU yang digunakan saat render. Nilai lebih tinggi lebih cepat tapi menggunakan lebih banyak resource.

## Bar Bawah (Kontrol Render Cepat)

Terletak di bagian paling bawah jendela. Mencerminkan beberapa field dari tab Output dan Render Settings agar lebih praktis tanpa perlu berpindah tab.

- **Preset** — ganti preset render dengan cepat.
- **Filename** — nama file output. Tersinkronisasi dengan tab Output.
- **Output** — path folder output. Tersinkronisasi dengan tab Output.
- Tombol **Browse** — pilih folder output.
- **Progress bar** — menampilkan progres render dan pesan status.
- **Render Video** — memulai proses render. Skrip yang saat ini terbuka di editor TypeScript akan di-render menggunakan pengaturan output yang sudah dikonfigurasi.

## Tutorial Singkat: Dari Ide ke Video

1. **Buka alat ini** dari menu Tools. Login diperlukan.
2. **Buat koleksi** via File > New Collection (atau `Ctrl+Shift+N`). Beri nama misalnya *Video Saya*.
3. **Buat skrip** via File > New Script (`Ctrl+N`) dengan koleksi tersebut terpilih.
4. Di tab **Generate with AI**, ketik apa yang kamu inginkan — misalnya *"Judul bercahaya bertuliskan HALO DUNIA, latar belakang gelap, efek fade in"*.
5. Opsional, klik **Refine Prompt** agar AI memperbaiki dan memperdalam deskripsimu.
6. Klik **Generate Script**. Kode TypeScript akan muncul di tab TypeScript.
7. Klik **Save** atau **Create** untuk menyimpan skrip.
8. Pilih skrip di panel kiri. Pindah ke tab **Preview** dan klik **Start Preview** untuk melihat hasilnya.
9. Jika sudah puas, buka tab **Output** dan atur folder serta nama file output.
10. Klik **Render Video** di bagian bawah. Perhatikan progress bar. Setelah selesai, akan muncul dialog dengan opsi untuk membuka lokasi file hasil render.

---

## Perbaikan Error Otomatis oleh AI

Jika render gagal karena ada error di kode, dialog **Render Failed** akan muncul dengan detail error dan tombol **Fix Errors**. Mengkliknya akan mengirim skrip beserta errornya ke AI, yang secara otomatis akan memperbaiki kode tersebut. Jika perbaikan AI juga gagal, akan ada opsi untuk mencoba lagi.
