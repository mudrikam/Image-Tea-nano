# Folder Comparator

## Overview

Tool Folder Comparator memungkinkan Anda membandingkan dua folder berdasarkan nama file dan menyalin file yang hilang dari sumber ke tujuan.

## Fitur

- **Perbandingan Folder**: Membandingkan file berdasarkan nama file (dengan pencocokan ekstensi)
- **Pertimbangkan Ukuran File**: Membandingkan file berdasarkan nama DAN ukuran untuk mendeteksi perbedaan
- **Filter Ekstensi**: Hanya bandingkan tipe file tertentu
- **Pencocokan Cerdas**: Menggunakan pencocian stem untuk menemukan file dengan nama sama tetapi ekstensi berbeda
- **Indikator Visual**: Warna hijau untuk file yang cocok, merah untuk file yang hilang/berbeda
- **Salin File yang Hilang**: Salin file yang ada di sumber tetapi tidak di tujuan
- **Seret & Lepas**: Seret folder langsung ke tabel sumber atau tujuan
- **Pengaturan Bertahan**: Mengingat folder sumber dan tujuan terakhir

## Cara Menggunakan

### 1. Memuat Folder Sumber

- **Browse**: Klik ikon folder untuk memilih folder sumber
- **Paste**: Tempel jalur folder dari clipboard
- **Seret & Lepas**: Seret folder ke tabel File Sumber

### 2. Memuat Folder Tujuan

- **Browse**: Klik ikon folder untuk memilih folder tujuan
- **Paste**: Tempel jalur folder dari clipboard
- **Seret & Lepas**: Seret folder ke tabel File Tujuan

### 3. Opsi Filter

#### Pertimbangkan Ukuran File
- Centang "Consider File Size" untuk membandingkan file berdasarkan nama DAN ukuran
- File dengan nama sama tetapi ukuran berbeda akan ditandai sebagai hilang
- Berguna saat ingin mendeteksi versi file yang telah diperbarui

#### Filter Ekstensi
- Centang "Filter Extensions" untuk hanya membandingkan tipe file tertentu
- Pilih preset ekstensi dari dropdown:
  - Gambar: `.jpg, .jpeg, .png, .gif, .bmp`
  - Desain: `.psd, .ai, .eps`
  - Video: `.mp4, .avi, .mov, .mkv`
  - Dokumen: `.pdf, .docx, .xlsx`
  - Audio: `.mp3, .wav, .flac`
  - Custom: Untuk konfigurasi manual

### 4. Membandingkan

- File akan dibandingkan otomatis saat kedua folder dimuat
- **Jumlah hilang** menunjukkan berapa file yang perlu disalin
- Saat "Consider File Size" diaktifkan, file dengan ukuran berbeda akan ditandai sebagai hilang
- File sumber muncul hijau jika ada di tujuan, merah jika hilang
- File tujuan muncul hijau jika ada di sumber, merah jika ekstra

### 5. Menyalin File yang Hilang

- Klik "COPY MISSING" untuk menyalin semua file yang hilang dari sumber ke tujuan
- Progress bar menunjukkan kemajuan penyalinan
- Setelah selesai, Anda bisa memilih untuk membuka folder tujuan

### 6. Rescan

- Klik "Rescan" untuk memuat ulang isi kedua folder tanpa menghapus pengaturan
- Berguna ketika file telah ditambahkan atau dihapus secara eksternal

### 7. Menghapus

- Tombol "Clear" mengatur ulang semua kolom dan tabel
- Tombol "X" individual menghapus hanya sumber atau tujuan
