# Tool Background Remover

## Ikhtisar

Background Remover menghapus latar belakang gambar dengan AI menggunakan model ONNX melalui `rembg`. Tool ini dapat memproses banyak gambar dalam satu proses dan secara default menghasilkan PNG transparan.

## Fitur

- **Penghapusan Latar Belakang dengan AI**: Menghapus latar belakang menggunakan model ONNX melalui rembg
- **Pemrosesan Batch**: Memproses banyak file gambar dalam satu proses
- **Pilihan Model**: Menggunakan `isnet-general-use`, `u2net`, `u2netp`, `u2net_human_seg`, atau `u2net_cloth_seg`
- **Penyesuaian Mask**: Mengatur level black, mid, dan white untuk memperbaiki transparansi
- **Auto Crop**: Memotong tepi transparan di sekitar subjek secara otomatis
- **Ekspor Opsional**: Menyimpan mask, membuat JPG dengan latar solid, atau mengekspor salinan JPG

## Cara Kerja

1. **Pemilihan Sumber**: Memuat gambar dari database Image Tea, memilih file/folder melalui browse, atau menyeret file ke tabel
2. **Pemrosesan Model**: Model ONNX yang dipilih mendeteksi foreground dan membuat data transparansi
3. **Penyempurnaan Mask**: Level transparansi disesuaikan dan subjek dapat dipotong otomatis
4. **Pembuatan Output**: PNG transparan disimpan, dengan mask dan JPG sebagai output tambahan jika dipilih

## Cara Penggunaan

### 1. Memilih Gambar Sumber

- Klik **Load Database** untuk memuat file gambar dari database Image Tea
- Tambahkan file atau folder dengan menyeretnya ke tabel file, atau gunakan kontrol browse pada bagian sumber
- Gunakan **Clear Source**, **Clear All**, **Clear Completed**, atau **Clear Failed** untuk mengatur antrean

### 2. Mengatur Output dan Model

- Pilih folder output. Jika dikosongkan, tool akan membuat folder `PNG` di sebelah file sumber
- Pilih model. Model default adalah `isnet-general-use`; model lain yang tersedia antara lain `u2net`, `u2netp`, `u2net_human_seg`, dan `u2net_cloth_seg`
- Model akan diunduh atau disiapkan saat diperlukan

### 3. Menyesuaikan Mask

- Gunakan **Adjust Mask** dan handle level black, mid, serta white untuk memperbaiki transparansi
- Klik **Reset Levels** untuk mengembalikan nilai default 20, 128, dan 235

### 4. Memproses Gambar

- Atur opsi output, lalu klik **START**
- Pilih **All** untuk memproses seluruh antrean atau **Failed Only** untuk mencoba ulang file yang gagal

## Elemen Interface

- **Source**: Path folder sumber atau file gambar
- **Output**: Folder tujuan untuk file hasil
- **Model**: Model ONNX yang digunakan untuk menghapus latar belakang
- **Adjust Mask**: Mengaktifkan preview dan penyesuaian level mask
- **Auto Crop**: Memotong tepi transparan di sekitar subjek terdeteksi
- **Solid BG**: Membuat JPG tambahan dengan warna latar solid yang dipilih
- **Save Mask**: Menyimpan mask sebagai PNG
- **JPG Export**: Membuat salinan JPG dengan kualitas 1 sampai 100
- **File Table**: Menampilkan file yang dimuat dan status prosesnya
- **Progress Bar**: Menampilkan progres pemrosesan

## Opsi Tambahan

- **Margin**: Menyisakan piksel tambahan di sekitar subjek saat auto-crop
- **Mode**: Memproses semua file dalam antrean atau hanya mencoba ulang file yang gagal
- **Clear Completed**: Menghapus file yang selesai dari antrean
- **Clear Failed**: Menghapus file yang gagal dari antrean

## Persyaratan

- **File Input**: `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tiff`, `.tif`, `.avif`, `.heic`, atau `.heif`
- **Runtime**: Dependensi rembg dan ONNX Runtime terpasang melalui Tools Manager Image Tea
- **Model**: Model ONNX disiapkan atau diunduh saat dibutuhkan

## Catatan

- Hasil utama disimpan sebagai PNG transparan
- JPG tidak dapat menyimpan transparansi, sehingga area transparan akan diratakan
- ONNX Runtime menggunakan provider GPU yang tersedia jika memungkinkan dan beralih ke CPU sebagai fallback
- Proses pertama dapat lebih lama karena model yang dipilih perlu disiapkan
- Jika inisialisasi model atau runtime gagal, pasang atau perbaiki dependensi Background Remover melalui Tools Manager Image Tea, lalu coba ulang file yang gagal
- Gunakan gambar sumber yang jelas dan pencahayaan baik agar tepi subjek lebih akurat. Rambut halus, kaca, bayangan, dan subjek dengan kontras rendah mungkin memerlukan penyesuaian level mask
