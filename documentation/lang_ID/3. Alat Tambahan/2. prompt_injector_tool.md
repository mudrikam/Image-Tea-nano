# Prompt Injector Tool

Tool ini membantu kamu mengotomatisasi proses memasukkan prompt ke aplikasi lain secara berulang. Kamu bisa setup titik klik di layar dan urutan aksi untuk paste prompt, klik tombol, dan refresh secara otomatis.

## Cara Menggunakan

1. **Setup Titik Klik**: Tool akan munculkan 5 titik berwarna di layar. Geser titik-titik ini ke posisi yang tepat di aplikasi target:
   - **Point 1 (merah)**: Tempat untuk paste prompt (klik, select all, paste).
   - **Point 2 (hijau)**: Tempat klik untuk submit atau confirm.
   - **Point 3 (biru)**: Tempat klik untuk download atau action akhir.
   - **Point 4 (orange)**: Action tambahan opsional.
   - **Point 5 (magenta)**: Tempat klik untuk refresh, dijalankan setiap N prompt.

2. **Atur Delay**: Set delay untuk setiap titik dalam detik. Ini waktu tunggu sebelum aksi di titik tersebut. Kamu juga bisa tambah random extra delay untuk variasi.

3. **Load Data**: Klik "Load CSV/TXT" untuk muat file prompt dari CSV atau TXT, atau "Load Prompt" untuk ambil prompt dari database yang sudah dihasilkan sebelumnya.

4. **Jalankan Automasi**: Klik "Run Action" untuk mulai. Tool akan klik titik-titik sesuai urutan, paste prompt, dan tunggu delay yang diset. Progress ditampilkan di bar progress.

5. **Kontrol Selama Jalannya**: Gunakan "Pause" untuk jeda sementara, "Stop" untuk hentikan total, atau "Reset Points" untuk reset posisi titik.

## Penjelasan Titik

- **Point 1**: Pindah kursor ke sini, klik, lakukan Ctrl+A, set clipboard ke prompt saat ini, lalu Ctrl+V untuk paste.
- **Point 2**: Pindah kursor ke sini dan klik, biasanya untuk confirm atau lanjut UI.
- **Point 3**: Pindah kursor ke sini dan klik, sering untuk download atau action final.
- **Point 4**: Action ekstra setelah Point 3.
- **Point 5**: Trigger refresh. Setiap N prompt, kursor pindah ke sini, klik, tunggu delay, lalu lanjut. Titik lain pause selama refresh.

## Opsi Delay

- **Delay per Titik**: Waktu tunggu sebelum aksi di titik tersebut.
- **Random Extra Delay**: Delay acak tambahan (0 untuk disable).
- **Trigger Point 5 Every**: Berapa prompt sekali Point 5 dijalankan.

## Load Data

- **Load CSV/TXT**: Muat file. TXT: setiap baris non-kosong jadi satu prompt.
- **Load Prompt**: Ambil prompt dari database.
- **Clear**: Hapus data yang dimuat.

## Progress dan Status

- **Progress Bar**: Tunjukkan prompt yang sudah diproses vs total.
- **Label**: Tunjukkan file saat ini dan posisi prompt di dalam file.
- **Countdown**: Tunjukkan waktu tunggu sebelum aksi berikutnya.

Tool ini akan tetap di atas jendela lain dan bisa di-drag. Pastikan aplikasi target tidak berubah posisi selama automasi berjalan.
