# Prompt Injector v2

**Prompt Injector v2** mengotomatiskan tugas copy‑paste dan kombinasi keyboard di aplikasi apa pun. Kamu mengonfigurasi daftar *poin* (posisi layar) dan setiap poin memiliki jenis aksi yang berbeda; setiap prompt yang dimuat menjalankan semua poin tersebut secara berurutan.

---

## Mulai Cepat

1. Klik **Add New Point** untuk membuat poin pertama.
2. Isi nama, tipe, ikon, warna, ukuran, dan delay, lalu klik **OK**.
3. Sebuah lingkaran warna muncul di layar. Seret ke lokasi target di aplikasi lain.
4. Ulangi untuk sebanyak poin yang diperlukan.
5. Muat prompt lewat **Load CSV/TXT** atau **Load Prompt** (database).
6. Klik **Run Action**.

---

## Poin

Setiap poin mewakili satu langkah dalam urutan otomatisasi. Poin disimpan di database sehingga pengaturan tersimpan.

### Kolom Poin

| Kolom | Keterangan |
|---|---|
| Name | Label nama poin (mis. "Paste Prompt", "Tombol OK"). |
| Type | Jenis aksi yang dijalankan (lihat *Point Types*). |
| Icon | Ikon yang tampil pada penanda layar. Pilih lewat icon picker. |
| Color | Warna penanda dan latar baris pada daftar. |
| Size | Diameter penanda (16–96 px). |
| Delay | Detik menunggu *sebelum* aksi dijalankan. Untuk tipe **monitor**, ini adalah waktu tunggu maksimum. |
| Shortcut | Hanya untuk tipe **key_action**. Kombinasi tombol keyboard, contohnya `ctrl+enter`. |
| Enabled | Matikan untuk melewati poin tanpa menghapusnya. |

### Jenis Poin

| Tipe | Deskripsi |
|---|---|
| **paste** | Pindah ke titik, klik, Ctrl+A, lalu paste teks prompt (Ctrl+V). |
| **key_action** | Pindah ke titik, lalu jalankan shortcut keyboard yang tersimpan. |
| **move** | Hanya memindahkan kursor ke titik tanpa klik. |
| **click** | Pindah ke titik dan lakukan klik kiri. |
| **monitor** | Ambil warna pixel di titik dan tunggu sampai berubah sebelum lanjut. Delay adalah timeout maksimal. |

---

## Menentukan Posisi

- Poin aktif menampilkan lingkaran semi‑transparan di layar.
- **Seret** lingkaran untuk mengarahkan ke lokasi tepat. Ikon berubah menjadi crosshair saat menyeret.
- Posisi disimpan ke database saat tombol dilepas.
- Gunakan **Reset Points** untuk memindahkan semua poin kembali ke pusat layar utama.

---

## Mengaktifkan / Menonaktifkan

Centang/ulam ceklis pada baris poin untuk mengaktifkan atau menonaktifkan. Poin yang dinonaktifkan disembunyikan dan dilewati selama otomatisasi; perubahan tersimpan segera.

---

## Memuat Prompt

### Load CSV/TXT

Mendukung file `.csv` dan `.txt`. TXT: setiap baris non‑kosong menjadi sebuah prompt. Bisa memuat beberapa file; isinya digabung sesuai urutan.

Kamu juga bisa **seret dan lepas** file CSV/TXT ke jendela Prompt Injector v2.

### Load Prompt (Database)

Memuat semua prompt dari database Image Tea yang belum ditandai sebagai "copied".

---

## Kontrol Run

| Tombol | Fungsi |
|---|---|
| **Run Action** | Mulai otomatisasi. Semua poin aktif dijalankan berurutan untuk setiap prompt. |
| **Pause** / **Resume** | Jeda atau lanjut otomatisasi. Menekan <kbd>Esc</kbd> juga toggle pause. |
| **Stop** | Hentikan otomatisasi segera. |
| **Reset Points** | Pindahkan kembali semua penanda ke tengah layar utama. |
| **Clear Points** | Menghapus semua poin dari database. Tindakan ini tidak dapat dibatalkan. |

---

## Delay Acak Tambahan

Kolom **Random extra delay (s)** menambahkan waktu tunggu acak di atas delay dasar setiap poin. Set `0` untuk menonaktifkan. Berguna agar aksi tampak lebih alami dan menghindari pembatasan kecepatan.

---

## Progres & Statistik

- Progress bar menunjukkan `selesai / total` prompt.
- Statistik diperbarui tiap detik: ETA, sisa waktu, waktu berjalan, % progres, dan kecepatan (prompt/menit).

---

## Pengaturan

Yang disimpan otomatis:

- Nilai random extra delay
- Jalur file CSV/TXT terakhir (dimuat lagi bila file masih ada)

Posisi, delay, ikon, tipe, dan status aktif poin disimpan di database.

---

## Catatan

- Otomatisasi menggunakan `pyautogui` untuk kontrol mouse/keyboard. Pastikan aplikasi target terlihat dan dapat diakses.
- Memindahkan mouse ke pojok kiri atas layar memicu fail‑safe `pyautogui` dan menghentikan otomatisasi.
- Pada macOS mungkin diperlukan izin screen recording agar `pyautogui` bekerja.
- Tipe poin **monitor** mengharuskan pixel target terlihat saat otomatisasi dimulai, karena warna awal diambil sekali.
