# Prompt Generator Tool

Tool ini membuat prompt AI secara otomatis, baik dari gambar referensi di database/folder kamu, maupun dari parameter kreatif yang kamu tentukan sendiri. Prompt yang dihasilkan bisa dipakai untuk membuat gambar atau video baru dengan AI.

## Tampilan Antarmuka

Dialog dibagi menjadi dua panel:

- **Panel kiri** - pengaturan generasi, dengan dua tab: **By Reference** dan **By Parameters**
- **Panel kanan** - hasil dan log, dengan tiga tab: **Table**, **Logs**, dan **Configure Instructions**

Tombol **Generate** di bagian bawah otomatis menyesuaikan labelnya tergantung tab mana yang aktif.

---

## Tab By Reference

Membuat prompt dengan menganalisis gambar referensi nyata.

- **Source**: Pilih sumber gambar referensi:
  - *Load from Database* - menggunakan gambar yang sudah diimpor ke Image-Tea
  - *Loaded Folder* - menggunakan gambar dari folder yang kamu pilih sendiri
- **Load Folder**: Muncul saat *Loaded Folder* dipilih. Membuka dialog pilih folder, dimulai dari direktori home kamu.
- **Type**: Jenis prompt yang dihasilkan (Image Generation atau Video Generation).
- **Ratio**: Rasio aspek yang disertakan dalam prompt (misalnya 16:9, 1:1, 9:16).
- **Length**: Target panjang karakter untuk setiap prompt.
- **Per File (max 20)**: Jumlah prompt yang dihasilkan per gambar referensi.
- **Variation**: Seberapa berbeda tiap prompt satu sama lain (1 = sangat mirip, 10 = sangat berbeda).
- **Delay**: Jeda antar pemrosesan gambar. *No Delay* = langsung, *Random* = 1-5 detik acak, atau ketik angka detik sendiri.

---

## Tab By Parameters

Membuat prompt murni dari parameter kreatif - tanpa gambar referensi.

- **Type**: Image Generation atau Video Generation.
- **Language**: Bahasa output prompt yang dihasilkan (default: English).
- **Ratio**: Rasio aspek.
- **Length**: Target panjang karakter per prompt.
- **Per Batch (max 20)**: Berapa banyak prompt yang dibuat dalam satu permintaan AI.
- **Requests**: Berapa kali permintaan diulang. Total prompt = Per Batch x Requests.
- **Variation**: Tingkat variasi antar prompt.
- **Mode**: Mengontrol bagaimana Theme, Mood, Color, Art Style, dan Background diterapkan:
  - *User Defined* - kamu pilih nilainya sendiri; nilainya tetap untuk setiap request.
  - *Random Parameters* - sebelum setiap request, tool otomatis mengacak Theme, Mood, Color Palette, Art Style. Dengan 4 requests kamu mendapat 4 kombinasi parameter berbeda, masing-masing diacak secara independen.
- **Theme**: Tema visual atau narasi keseluruhan (misalnya Nature, Sci-Fi, Gothic). Bisa diedit - ketik nilai sendiri.
- **Mood**: Nuansa emosional (misalnya Ethereal, Dramatic, Playful). Bisa diedit.
- **Color Palette**: Skema warna untuk prompt (misalnya Warm tones, Neon, Duotone). Bisa diedit.
- **Art Style**: Gaya visual (misalnya Watercolor, Flat Vector, Pixel Art, 3D Render). Bisa diedit.
- **Background**: Latar belakang scene (misalnya Bokeh Blur, Marble Surface, Starry Night). Bisa diedit. Gunakan tombol palet untuk memilih warna HEX kustom.
- **Human Model**: Apakah ada orang di gambar, dan tipe orangnya.
- **Custom Instruction**: Instruksi teks bebas opsional yang ditambahkan ke setiap request.

Semua combo yang bisa diedit memiliki tombol **+** untuk menyimpan nilai yang diketik secara permanen ke daftar.

## Stats Bar

Ditampilkan di atas tombol Generate:

- **Type** - mode generasi yang aktif
- **Generated** - total prompt yang ada di database saat ini
- **Est. total** - estimasi jumlah akhir saat generasi selesai
- **Elapsed** - waktu sejak generasi dimulai
- **ETA** - estimasi waktu selesai
- **Remaining** - jumlah prompt yang masih perlu dibuat

---

## Tab Table

Menunjukkan semua prompt yang dihasilkan dengan pagination.

- **Per Page**: Ubah berapa baris yang ditampilkan per halaman.
- **Prev / Next / Page Spinner**: Navigasi halaman.
- **Tombol Copy** (tiap baris): Menyalin prompt dan menandainya sebagai sudah dicopy (disorot).
- **Double-click**: Buka editor inline untuk mengubah prompt.
- **Middle-click**: Copy prompt ke clipboard.
- **Ctrl+C**: Copy prompt yang dipilih.
- **Right-click**: Menu konteks - Copy, Edit, atau Delete prompt.

### Tombol Toolbar

- **Refresh**: Muat ulang tabel dari database.
- **Clear All**: Hapus semua prompt yang dihasilkan.
- **Clear Copied**: Hapus hanya prompt yang sudah ditandai sebagai dicopy.
- **Export CSV**: Simpan semua prompt ke file CSV.
- **Import CSV**: Impor prompt dari file CSV.

---

## Tab Logs

Menunjukkan log bertimestamp dari setiap event generasi, error, dan pembaruan progress. Gunakan **Clear** untuk mengosongkan log.

---

## Tab Configure Instructions

Lanjutan: edit instruksi dan persyaratan AI yang dikirim bersama setiap permintaan generasi prompt.

- **Instructions**: Edit teks instruksi sistem untuk Image Generation dan Video Generation secara terpisah.
- **Requirements**: Tambah, edit, atau hapus persyaratan spesifik untuk setiap tipe.
- **Variation Levels**: Edit deskripsi untuk setiap tingkat variasi (1-10).
- Klik **Save** untuk menyimpan perubahan ke file konfigurasi.

---

## Tips

- Gunakan mode **Random Parameters** dengan **Requests** yang banyak untuk menjelajahi berbagai gaya prompt dalam satu kali jalan.
- Sumber **Loaded Folder** memungkinkan kamu menggunakan gambar dari luar Image-Tea tanpa perlu mengimpornya terlebih dahulu.
- Prompt yang disorot di tabel sudah pernah dicopy - gunakan **Clear Copied** agar daftar tetap bersih.
- Pastikan API key valid dan koneksi internet stabil untuk hasil terbaik.
