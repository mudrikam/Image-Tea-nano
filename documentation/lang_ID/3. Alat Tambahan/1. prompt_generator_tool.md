# Prompt Generator Tool

Tool ini membantu kamu membuat prompt secara otomatis berdasarkan gambar yang ada di database. Prompt yang dihasilkan bisa digunakan untuk membuat gambar atau video baru dengan AI.

## Cara Menggunakan

1. **Pilih API Key**: Pastikan kamu sudah memilih api key yang valid di bagian atas dialog. Tool ini menggunakan api key untuk mengakses layanan AI.

2. **Atur Opsi Generasi**:
   - **Type**: Pilih jenis prompt yang ingin dihasilkan (misalnya untuk gambar atau video).
   - **Ratio**: Pilih rasio aspek gambar (seperti 16:9 untuk layar lebar, 1:1 untuk kotak, atau 9:16 untuk potret).
   - **Length**: Atur panjang maksimal prompt dalam token/kata.
   - **Prompts per File**: Tentukan berapa banyak prompt yang dihasilkan per gambar.
   - **Variation**: Kontrol seberapa berbeda prompt satu dengan yang lain (1 = sangat mirip, 10 = sangat berbeda).
   - **Delay**: Atur jeda waktu antara pemrosesan gambar (No Delay = tanpa jeda, Random = acak 1-5 detik, atau angka khusus dalam detik).

3. **Klik "Generate Prompts"**: Tool akan memproses semua gambar di database dan membuat prompt untuk masing-masing. Kamu bisa lihat progress di bar progress dan status di label bawah.

4. **Lihat Hasil**: Prompt yang dihasilkan muncul di tabel. Setiap baris menampilkan teks prompt, jumlah karakter, waktu dibuat, dan tombol copy.

## Fitur Tambahan

- **Edit Prompt**: Klik untuk mengubah konfigurasi prompt generator.
- **Refresh**: Perbarui tabel prompt.
- **Clear All**: Hapus semua prompt yang sudah dihasilkan.
- **Clear Copied**: Hapus prompt yang sudah dicopy.
- **Export CSV**: Simpan prompt ke file CSV.
- **Import CSV**: Impor prompt dari file CSV.

## Interaksi dengan Tabel

- **Double-click**: Edit prompt yang dipilih.
- **Middle-click**: Copy prompt ke clipboard.
- **Ctrl+C**: Copy prompt yang dipilih.
- **Right-click**: Buka menu konteks untuk opsi copy.

## Pagination

Jika prompt banyak, gunakan kontrol pagination di bawah tabel untuk navigasi halaman. Kamu bisa ubah jumlah prompt per halaman.

## Status dan Progress

- **Stats**: Lihat jumlah prompt, total file, dan progress generasi.
- **Progress Bar**: Tunjukkan kemajuan pemrosesan.
- **Status Label**: Berikan informasi tentang apa yang sedang terjadi (misalnya "Ready to generate" atau "Generating prompts...").

Tool ini akan berhenti otomatis jika ada error atau kamu klik stop. Pastikan api key valid dan koneksi internet stabil untuk hasil terbaik.
