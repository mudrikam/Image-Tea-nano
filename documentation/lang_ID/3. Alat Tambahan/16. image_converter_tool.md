# Image Converter Tool

## Ikhtisar

Image Converter memungkinkan Anda mengubah format banyak gambar sekaligus ke berbagai format termasuk PNG, JPG, BMP, TIFF, dan WEBP.

## Fitur

- **Konversi Batch**: Ubah format banyak gambar sekaligus
- **Dukungan Format**: Format input dan output PNG, JPG, BMP, TIFF, WEBP
- **Kontrol Kualitas**: Sesuaikan kualitas output untuk format JPG (1-100)
- **Pengaturan DPI**: Set DPI untuk gambar output (1-1200)
- **Non-blocking**: Berjalan terpisah tanpa mengganggu interface utama
- **Integrasi Database**: Muat gambar langsung dari database Image Tea

## Cara Penggunaan

### 1. Memuat Gambar

- **Load from Database**: Klik "Load Database" untuk memuat semua file gambar dari database Image Tea
- **Browse Folder**: Klik ikon folder untuk memilih folder berisi gambar
- **Drag & Drop**: Seret dan lepas file gambar/folder langsung ke tabel file
- **Paste Path**: Tempel path file atau folder dari clipboard menggunakan tombol paste

### 2. Setting Output

- **Output Folder**: Pilih atau masukkan folder output tempat gambar yang dikonversi akan disimpan
- **Output Format**: Pilih dari PNG, JPG, BMP, TIFF, atau WEBP menggunakan dropdown
- **Quality Slider**: Sesuaikan kualitas JPG (1-100). Hanya aktif saat format JPG dipilih
- **DPI Spinbox**: Set nilai DPI untuk gambar output

### 3. Mengkonversi

- Klik tombol "CONVERT" untuk memulai konversi
- Progress bar menampilkan progres konversi
- Tabel file menampilkan status setiap file (Ready, Converting, Completed, Failed)
- Klik "STOP" untuk membatalkan proses konversi

## Persyaratan

- **File Sumber**: Harus file gambar dengan ekstensi: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff`, `.tif`, `.gif`, `.webp`, `.ico`, `.psd`
- **Python Imaging Library**: Memerlukan Pillow (PIL) untuk konversi gambar
- Tidak memerlukan tools eksternal

## Catatan

- Untuk output JPG/BMP, gambar dengan transparansi akan ditatap ke latar belakang putih
- Nama file asli dipertahankan di output
- Ekstensi format output akan otomatis diterapkan pada file yang dikonversi
