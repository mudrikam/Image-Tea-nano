# Tool Microstock Holiday Calendar

Tool Holiday Calendar memungkinkan kamu menelusuri hari libur nasional dari berbagai negara di seluruh dunia. Tool ini berguna untuk merencanakan konten di sekitar hari libur dan peristiwa budaya yang relevan dengan pasar microstock yang kamu tuju.

## Sebelum Mulai

Untuk menggunakan tool ini, kamu memerlukan API key dari Calendarific. Ada dua cara untuk mendapatkannya:

**Pilihan 1 - Jadi Member (Direkomendasikan)**
Jika kamu adalah member Image Tea, API key sudah disediakan otomatis oleh Desainia Studio. Kamu tidak perlu melakukan konfigurasi apapun. Cukup login sebagai member, lalu buka tool ini.

**Pilihan 2 - Gunakan API Key Sendiri**
Daftarkan API key gratis di [calendarific.com](https://calendarific.com/account/dashboard), lalu tempel di tab **Configuration** di dalam tool.

Jika tidak ada API key yang dikonfigurasi, tool akan menampilkan dialog yang mengarahkan kamu ke salah satu pilihan di atas saat mencoba memuat data hari libur.

---

## Tampilan Antarmuka

Dialog dibagi menjadi tiga area utama:

- **Sidebar kiri** - navigasi tahun dan bulan
- **Panel tengah** - daftar hari libur atau tampilan kalender, dengan filter bar di bagian atas
- **Panel kanan** - panel detail hari libur (bisa disembunyikan)

Di bagian bawah terdapat panel **Logs** yang bisa disembunyikan, menampilkan aktivitas API dan cache secara real time.

Panel tengah memiliki tiga tab:

- **Holidays** - tampilan utama untuk menelusuri dan memfilter hari libur
- **Search** - cari platform microstock menggunakan kata kunci dari hari libur
- **Configuration** - pengaturan API key dan cache

---

## Sidebar

Sidebar berisi spinner tahun dan daftar bulan.

- **Spinner tahun** - ubah tahun untuk menelusuri hari libur di tahun berbeda
- **Daftar bulan** - klik sebuah bulan untuk memuat hari libur pada bulan tersebut. Setiap bulan menampilkan badge jumlah yang menunjukkan berapa banyak hari libur di negara dan tahun yang dipilih
- Klik bulan yang sama lagi untuk memuat ulang datanya

---

## Filter Bar

Terletak di bagian atas tab Holidays:

- **Dropdown negara** - pilih negara yang ingin kamu lihat hari liburnya. Dropdown ini diisi dari daftar negara Calendarific setelah API call pertama
- **Kolom pencarian** - filter daftar hari libur berdasarkan nama secara real time
- **Toggle tampilan** - beralih antara tampilan List dan Calendar
- **Tombol Refresh** - menghapus cache untuk pilihan saat ini dan mengambil ulang data dari API

---

## Tampilan List

Menampilkan hari libur dalam daftar yang bisa di-scroll. Setiap entri menunjukkan:

- Nama hari libur
- Tanggal dan hari dalam seminggu
- Tipe hari libur (nasional, keagamaan, observansi, dll.)
- Bendera negara dan informasi wilayah jika berlaku

Klik hari libur mana saja untuk membuka detailnya di **Panel Detail** di sebelah kanan.

---

## Tampilan Kalender

Menampilkan bulan yang sedang dipilih dalam grid kalender. Hari yang memiliki hari libur diberi highlight. Klik tanggal tertentu untuk melihat hari libur yang jatuh pada hari itu di Panel Detail.

---

## Panel Detail

Muncul di sisi kanan saat kamu memilih sebuah hari libur. Menampilkan:

- Nama lengkap hari libur
- Tanggal, hari, dan tipe
- Deskripsi
- Provinsi atau wilayah yang merayakannya (jika berlaku)
- Tombol **Search on Platform** yang membawa nama hari libur ke tab Search untuk riset kata kunci microstock

---

## Tab Search

Digunakan untuk meneliti hari libur yang dipilih di berbagai platform microstock. Nama hari libur sudah otomatis diisi sebagai kata kunci. Beralih antar platform yang tersedia menggunakan tombol tab di bagian atas.

---

## Tab Configuration

Kelola API key dan pengaturan cache di sini.

- **API Key** - tempel API key Calendarific kamu. Tombol mata untuk toggle visibilitas. Jika kamu login sebagai member dengan key yang sudah dikonfigurasi, kolom ini dinonaktifkan dan sebuah notifikasi ditampilkan sebagai gantinya
- **Base URL** - endpoint API Calendarific. Biarkan default kecuali kamu tahu apa yang kamu lakukan
- **Default Country** - negara yang dimuat secara default saat tool dibuka (contoh: `US`, `ID`, `WORLD`)
- **Cache Expiry** - berapa hari data hari libur yang sudah di-cache disimpan sebelum diambil ulang dari API (default: 30 hari)
- **Use SQLite cache** - menyimpan semua data hari libur yang sudah diambil secara lokal agar tidak perlu diambil ulang setiap kali tool dibuka. Disarankan tetap diaktifkan untuk menghemat kredit API
- **Clear All Cache** - menghapus semua data hari libur yang tersimpan lokal. Gunakan ini jika data terlihat tidak up-to-date
- **Save Configuration** - menyimpan semua pengaturan di atas

---

## Tampilan WORLD

Memilih **WORLD** sebagai negara akan mengambil hari libur dari sekumpulan negara besar secara bersamaan dan menggabungkan hasilnya menjadi satu daftar. Karena Calendarific mengenakan biaya per negara per permintaan, tampilan WORLD melakukan beberapa API call sekaligus (satu per negara). Hasilnya di-cache selama 30 hari secara default, sehingga tampilan-tampilan berikutnya tidak memerlukan kredit API tambahan.

---

## Panel Logs

Panel yang bisa disembunyikan di bagian bawah dialog menampilkan entri log secara real time:

- **INFO** - aktivitas umum
- **API** - permintaan API yang keluar
- **CACHE** - hit dan penyimpanan dari cache lokal
- **SUCCESS** - pengambilan data yang berhasil
- **WARNING** - masalah non-kritis
- **ERROR** - permintaan gagal atau konfigurasi tidak lengkap

Klik label **Logs** untuk membuka atau menutup panel.
