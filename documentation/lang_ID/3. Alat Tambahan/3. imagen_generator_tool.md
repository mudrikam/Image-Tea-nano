# Imagen Generator Tool

Tool ini membantu kamu membuat gambar secara otomatis dari prompt yang ada di database menggunakan Imagen API.

## Cara Menggunakan

1. **Pilih API Key**: Pastikan kamu sudah memilih api key yang valid untuk Imagen di bagian atas dialog.

2. **Atur Opsi Generasi**:
   - **Model**: Pilih model Imagen yang ingin digunakan.
   - **Number of Images**: Tentukan berapa gambar yang dihasilkan per prompt (1-4).
   - **Mode**: Pilih "Generate All" untuk proses semua prompt, atau "Continue from Stopped" untuk lanjut dari yang terhenti.
   - **Aspect Ratio**: Pilih rasio aspek gambar (seperti 1:1 untuk kotak, 16:9 untuk horizontal).
   - **Resolution**: Pilih resolusi eksplisit (opsional, untuk model OpenRouter).
   - **Image Size**: Pilih ukuran gambar (1K atau 2K).
   - **Output Format**: Pilih format output (PNG atau JPG).
   - **Delay Interval**: Atur jeda waktu antara batch (Random = 1-5 detik, atau angka khusus).
   - **Output Folder**: Pilih folder untuk menyimpan gambar yang dihasilkan. Klik browse untuk pilih folder atau paste untuk tempel path dari clipboard.

3. **Klik "Run Prompt"**: Tool akan mulai generate gambar dari prompt yang ada. Kamu bisa lihat progress di bar progress dan status di label bawah.

4. **Pantau Progress**: Tabel menampilkan prompt dengan status masing-masing. Kolom status menunjukkan apakah pending, generating, completed, atau error.

## Fitur Tambahan

- **Configure Models**: Klik ikon gear untuk atur model Imagen yang tersedia.
- **Clear All**: Hapus semua status generasi dari database.
- **Export CSV**: Simpan prompt dengan status generasi ke file CSV.

## Interaksi dengan Tabel

- **Double-click**: Edit prompt yang dipilih.
- **Right-click**: Buka menu konteks untuk opsi copy atau edit.

## Pagination

Jika prompt banyak, gunakan kontrol pagination di bawah tabel untuk navigasi halaman. Kamu bisa ubah jumlah prompt per halaman.

## Status dan Progress

- **Stats**: Lihat total prompt, yang completed, pending, gambar yang dihasilkan, remaining, dan status saat ini.
- **Progress Bar**: Tunjukkan kemajuan generasi.
- **Status Label**: Berikan informasi tentang apa yang sedang terjadi (misalnya "Ready to generate" atau "Generating images...").

Tool ini akan berhenti otomatis jika ada error. Pastikan api key valid, folder output ada, dan koneksi internet stabil untuk hasil terbaik.
