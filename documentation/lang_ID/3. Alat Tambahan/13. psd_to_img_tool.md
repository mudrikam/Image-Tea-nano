# PSD to IMG Converter

## Ikhtisar

Alat PSD to IMG Converter memungkinkan Anda mengkonversi file Photoshop PSD ke berbagai format gambar termasuk JPG, PNG, BMP, TIFF, dan WEBP.

## Fitur

- **Konversi PSD**: Ubah file Photoshop PSD ke berbagai format gambar
- **Pemrosesan Batch**: Konversi beberapa file sekaligus
- **Kontrol Kualitas**: Sesuaikan kualitas output untuk format JPG (1-100)
- **Non-blocking**: Berjalan terpisah tanpa mengganggu interface Image Tea utama
- **Integrasi Database**: Muat file PSD langsung dari database Image Tea

## Cara Penggunaan

### 1. Memuat File PSD

- **Muat dari Database**: Klik "Load Database" untuk memuat semua file PSD dari database Image Tea
- **Browse File**: Klik ikon folder untuk browse dan pilih file PSD tunggal
- **Paste Path**: Tempel path file dari clipboard menggunakan tombol paste

### 2. Mengatur Output

- **Folder Output**: Pilih atau masukkan folder output tempat gambar hasil konversi akan disimpan
- **Format Output**: Pilih dari PNG, JPG, BMP, TIFF, atau WEBP menggunakan dropdown
- **Slider Kualitas**: Sesuaikan kualitas JPG (1-100). Hanya aktif ketika format JPG dipilih

### 3. Mengkonversi

- Klik tombol "CONVERT" untuk memulai konversi
- Progress bar menampilkan progres konversi
- Tabel file menampilkan status setiap file (Ready, Converting, Completed, Failed)

## Persyaratan

- **File Sumber**: Harus file Photoshop PSD (`.psd` extension)
- **Python Imaging Library**: Memerlukan Pillow (PIL) untuk konversi gambar
- Tidak memerlukan alat eksternal

## Catatan

- File non-PSD akan ditolak dengan pesan peringatan
- Alat ini membuat versi RGB dari file PSD (flattened)
- File output mempertahankan nama dasar yang sama dengan file sumber
