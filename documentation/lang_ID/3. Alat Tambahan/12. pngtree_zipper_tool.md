# Pngtree Zipper Tool

Tool ini membantu Anda membuat arsip ZIP untuk pengiriman aset ke Pngtree. Anda dapat memproses berkas secara batch dengan drag dan drop ke dalam tool.

## Cara Pakai

1. **Tambahkan Berkas**: Drag dan drop berkas yang didukung (PSD, AI, EPS, PNG, JPG) ke area drop, atau gunakan opsi menu:
   - **Import files** - Pilih berkas individu
   - **Select Folder** - Impor semua berkas yang didukung dari folder
   - **Load from Database** - Muat berkas dari database Image Tea
   - **Load from Database** button - Tombol cepat untuk memuat dari database

2. **Pilih Direktori Output**: Pilih lokasi untuk menyimpan berkas ZIP:
   - Klik tombol **Select Output** untuk memilih folder
   - Atau tool akan menggunakan folder sumber jika semua berkas berasal dari folder yang sama

3. **Jalankan Batch Zip**: Klik **Run batch zip** untuk memulai proses. Berkas dengan nama yang sama (ekstensi berbeda) akan dikelompokkan menjadi satu arsip ZIP.

4. **Pantau Progres**: Lihat bilah progres yang menampilkan progres keseluruhan dan per-berkas.

## Jenis Berkas yang Didukung

- `.psd` - Berkas Photoshop
- `.ai` - Berkas Illustrator
- `.eps` - Berkas EPS
- `.png` - Gambar PNG
- `.jpg` - Gambar JPEG

## Tombol Utama

| Tombol | Fungsi |
|--------|--------|
| Select Output | Pilih folder output untuk arsip ZIP |
| Open Output | Buka folder output setelah proses selesai |
| Reset | Bersihkan semua berkas dan statistik |
| Load from Database | Muat berkas yang didukung dari database |
| WhatsApp | Gabung grup WhatsApp Desainia |
| Run batch zip | Mulai proses pembuatan ZIP |

## Logika Pengelompokan Berkas

Berkas dikelompokkan berdasarkan nama filenya. Contohnya:
- `file1.psd` + `file1.png` → `file1.zip`
- `file2.ai` + `file2.eps` + `file2.jpg` → `file2.zip`

Setiap berkas ZIP berisi semua berkas dari grup yang sama dengan nama file dasar yang sama.

## Catatan

- Pastikan folder output memiliki cukup ruang disk
- Tool secara otomatis mendeteksi dan mengabaikan berkas duplikat
- Gunakan **Clear data** dari menu File untuk mengatur ulang state tool
