# Video Upscaler Tool

Tool ini membantu kamu meningkatkan resolusi video menggunakan RealESRGAN. Video akan diproses frame per frame untuk hasil terbaik, kemudian digabung kembali menjadi video.

## Cara Menggunakan

1. **Load Video**: Pilih sumber video yang ingin di-upscale.
   - Klik "Load Database" untuk memuat semua video dari database aplikasi.
   - Klik "Load Folder" untuk memilih folder yang berisi video.
   - Klik "Load File" untuk memilih satu video saja.

2. **Atur Pengaturan**:
   - **Model**: Pilih model AI yang akan digunakan untuk upscaling.
   - **Scale**: Pilih faktor perbesaran (2x, 3x, atau 4x).
   - **Batch**: Tentukan jumlah frame yang diproses sekaligus (lebih tinggi = lebih cepat tapi butuh lebih banyak RAM).
   - **Encoder**: Pilih encoder video untuk penggabungan (CPU atau GPU).
   - **Decoder**: Pilih hardware acceleration untuk ekstraksi frame.

3. **Set Folder Output**: Klik ikon folder untuk memilih tempat menyimpan hasil upscaling. Jika kosong, hasil akan disimpan di folder default.

4. **Jalankan Upscaling**: Klik tombol "RUN UPSCALE" untuk memulai proses. Tool akan mengekstrak frame, upscale setiap frame, lalu menggabungkan kembali.

## Fitur Utama

### Load dan Manage Video
- **Load Database**: Muat semua video dari database Image-Tea.
- **Load Folder**: Pilih folder untuk memuat semua video di dalamnya.
- **Load File**: Tambah satu video ke daftar.
- **Clear**: Hapus semua video dari daftar.

### Pengaturan Output
- **Output Folder**: Tentukan folder untuk menyimpan hasil.
- **Browse**: Jelajahi dan pilih folder output.
- **Paste**: Tempel path folder dari clipboard.
- **Clear**: Hapus path folder output.

### Encoder dan Decoder
- **Encoder**: Pilih hardware encoder untuk video output (NVIDIA NVENC, AMD AMF, Intel QSV, atau CPU).
- **Decoder**: Pilih hardware acceleration untuk ekstraksi frame (CUDA, QSV, DirectX, atau CPU).

### Tint Adjustment
- **Tint R/G/B**: 3 spinner untuk mengatur penyesuaian warna RGB (range: -50 sampai +50).
- **Default**: R=2, G=-5, B=0 (mengurangi greenish tint yang umum terjadi).
- **Auto-save**: Nilai otomatis tersimpan ke config setiap kali diubah.
- **Cara pakai**: Sesuaikan nilai untuk memperbaiki color cast atau tint yang tidak diinginkan pada video:
  - Nilai negatif mengurangi channel tersebut
  - Nilai positif menambah channel tersebut
  - Contoh: Jika hasil terlalu hijau, kurangi G (set ke -15 atau -20)
  - Contoh: Untuk shift ke magenta, gunakan R=10, G=-20, B=10
- **Tips**: Mulai dengan nilai kecil (±5 sampai ±15) dan test dulu dengan 1 video pendek.
- **Remove Audio**: Centang untuk menghapus track audio dari video output.

### Pengelola Model
- Buka Pengelola Model dengan mengklik **ikon roda gigi** di sebelah pemilih Model. Di sana tampil semua model upscaling dan alat untuk menambah, mengedit, menghapus, mengekspor, dan me-refresh daftar.
- Tambah / Import: Klik **Add** atau **Import** untuk membuka dialog. Isikan nama model, pilih tipe (NCNN / PTH / ONNX), set skala (2x/3x/4x), isi deskripsi bila perlu, dan pilih file model yang diperlukan. NCNN memakai dua file (parameter + bobot); PTH dan ONNX memakai satu file. Dialog melakukan validasi dan akan menyalin file ke folder model aplikasi saat impor berhasil.
- Edit: Pilih model lalu klik **Edit** untuk mengubah properti yang bisa diubah (mis. skala, deskripsi). Nama, tipe, dan file model tidak bisa diganti lewat edit.
- Hapus: Pilih model dan klik **Delete**. Kamu akan diminta mengonfirmasi apakah ingin juga menghapus file model; memilih Ya akan menghapus file-file tersebut.
- Ekspor: Gunakan **Export** untuk menyalin file model keluar ke folder pilihan.
- Refresh & Buka folder: Klik **Refresh** untuk memindai ulang dan perbarui daftar. **Open Models Folder** membuka folder model di file manager.
- Dependensi: Pengelola menunjukkan apakah dukungan PTH / ONNX tersedia dan menyediakan tombol installer. Jika kamu menjalankan upscaler dengan model PTH/ONNX tanpa dependensi, aplikasi akan menawarkan pemasangan sebelum melanjutkan.

## Proses Upscaling

Tool bekerja dalam 3 fase:

1. **PHASE 1: Extract Frames** - Mengekstrak semua frame dari video menjadi gambar PNG.
2. **PHASE 2: Upscale Frames** - Memproses setiap frame menggunakan RealESRGAN.
3. **PHASE 3: Merge to Video** - Menggabungkan frame yang sudah di-upscale kembali menjadi video.

## Status dan Progress

- **Files**: Menampilkan jumlah video yang dimuat.
- **Frames**: Menampilkan progress pemrosesan frame (diproses/total).
- **Elapsed**: Waktu yang sudah berlalu sejak mulai.
- **ETA**: Perkiraan waktu selesai.
- **Remaining**: Jumlah frame yang masih belum diproses.
- **Status**: Status proses saat ini (Idle/Running).

## Log dan Monitoring

- **Process Logs**: Menampilkan detail setiap fase proses, error, dan informasi penting.
- **Progress Bar**: Menunjukkan persentase penyelesaian keseluruhan.
- **Icon Status**: Ikon centang (hijau) untuk berhasil, ikon X (merah) untuk gagal.

## Kontrol Proses

- **RUN UPSCALE**: Mulai proses upscaling video.
- **STOP**: Hentikan proses yang sedang berjalan.

## Tips Penggunaan

- Video upscaling membutuhkan waktu lama karena memproses frame per frame.
- Pastikan ada cukup ruang penyimpanan untuk frame temporary.
- Gunakan GPU encoder jika tersedia untuk penggabungan yang lebih cepat.
- Hardware acceleration decoder mempercepat ekstraksi frame.
- Batch size yang lebih tinggi mempercepat proses tapi butuh lebih banyak VRAM.

Tool ini akan otomatis membersihkan file temporary setelah selesai. Pastikan FFmpeg dan RealESRGAN sudah terinstall dengan benar untuk hasil optimal.
