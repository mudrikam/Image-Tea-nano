# Tentang Image-Tea-nano

Image-Tea-nano adalah aplikasi generator metadata yang ringan, 
simpel, dan jujur.  
Fokus utama aplikasi ini adalah kemudahan penggunaan dan 
kejujuran dalam proses generate metadata, tanpa fitur berlebihan.

Aplikasi ini dikembangkan oleh Studio Desainia untuk memenuhi 
kebutuhan internal studio, dan dibagikan secara terbuka dengan 
harapan dapat bermanfaat untuk orang banyak.

Proyek ini dikembangkan menggunakan Python dengan framework GUI PySide6 dan menggunakan `qtawesome` untuk ikon. Pustaka runtime lainnya dan daftar dependensi dapat dilihat di file `requirements.txt` pada repositori.

- Open source, komunitas, dan mudah digunakan.
- Tidak menyimpan data pribadi pengguna.
- Semua proses berjalan secara lokal di komputer kamu.

## Ekstensi File yang Didukung

Image Tea mendukung ekstensi file berikut (ini adalah format umum gambar dan video yang didukung image tea):

- Gambar: .jpg, .jpeg, .png, .tiff, .webp, .eps, .svg, .pdf, .psd
- Video: .mp4, .mpeg, .mov, .avi, .flv, .mpg, .webm, .wmv, .3gp, .3gpp
- Tambahan (vektor & dokumen): .svg, .eps, .pdf

Teks bawaan pada UI apabila belum ada file adalah: "Drag and drop images or videos here".

## Tools yang Didukung

Image Tea dapat memanfaatkan beberapa alat bantu yang berada di folder `tools/` jika tersedia:

- `exiftool`: untuk operasi metadata baca/tulis lanjutan.
- `ghostscript`: untuk penanganan konversi PostScript/PDF dan operasi raster terkait.
- `cairo`: untuk beberapa tugas rendering gambar pada build Windows.

Alat-alat ini bersifat opsional tetapi meningkatkan kemampuan pemrosesan dan kompatibilitas untuk format vektor/dokumen serta beberapa alur kerja gambar.
