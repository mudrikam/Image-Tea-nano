
# Cara Instal Image-Tea-nano (Semua Sistem Operasi)

Ikuti langkah-langkah berikut untuk menginstal dan menjalankan Image-Tea-nano di Windows, Linux, atau macOS:

## 1. Unduh Git (opsional, untuk clone repo)
- Kunjungi [https://git-scm.com/downloads](https://git-scm.com/downloads) dan unduh Git sesuai sistem operasi kamu.
- Instal Git sesuai petunjuk di website.

## 2. Dapatkan Image-Tea-nano

Kamu bisa memilih salah satu metode berikut:

### Metode A: Clone Repository (untuk pengguna menengah/mahir)
1. Buka terminal (Command Prompt/PowerShell di Windows, Terminal di Linux/macOS).
2. Arahkan ke folder tujuan, misal:
   - Windows: `cd D:\Project` atau `cd %USERPROFILE%\Desktop`
   - Linux/macOS: `cd ~/Project` atau `cd ~/Desktop`
3. Jalankan:
   `git clone https://github.com/mudrikam/Image-Tea-nano.git`
4. Masuk ke folder hasil clone:
   `cd Image-Tea-nano`

### Metode B: Download ZIP/Installer/Portable (Direkomendasikan untuk semua pengguna)
1. Kunjungi [https://github.com/mudrikam/Image-Tea-nano](https://github.com/mudrikam/Image-Tea-nano) atau halaman releases installer: [https://github.com/mudrikam/Image-Tea-Installer/releases](https://github.com/mudrikam/Image-Tea-Installer/releases)
2. Pilih dan unduh file ZIP, installer, atau portable yang sesuai dengan sistem operasi kamu (Windows, Linux, atau macOS). Cek bagian *Assets* pada rilis untuk file yang tepat.
3. Ekstrak file ZIP (atau jalankan installer/portable) ke folder pilihan kamu (disarankan bukan di drive C: untuk Windows, gunakan folder di drive lain atau di home directory untuk Linux/macOS).

## 3. Jalankan Aplikasi

### Windows
- Buka folder hasil ekstrak atau instalasi.
- Jalankan `Launcher.bat` dengan klik dua kali, atau jalankan dari Command Prompt:
  `Launcher.bat`

### Linux/macOS
- Buka terminal dan navigasi ke folder hasil ekstrak/instalasi:
  `cd /path/ke/Image-Tea-nano`
- Pastikan file `Launcher.sh` sudah bisa dieksekusi. Jika belum, jalankan:
  `chmod +x Launcher.sh`
- Jalankan aplikasi dengan perintah:
  `./Launcher.sh`

### Catatan Penting
- Pada pertama kali dijalankan, aplikasi akan otomatis mengunduh dan menginstal dependensi yang diperlukan (pastikan koneksi internet stabil).
- Jika terjadi kegagalan instalasi/dependensi, hapus seluruh folder instalasi lalu ulangi proses dari awal dengan folder baru.
- Tidak perlu menginstal Python atau library secara manual.
- Untuk update aplikasi, gunakan fitur Update di menu aplikasi. Jika gagal update, ulangi proses instalasi dari awal.

## Troubleshooting & Bantuan
- Pastikan koneksi internet stabil saat instalasi dan penggunaan pertama.
- Jika ada masalah, hapus folder instalasi dan ulangi proses dari awal.
