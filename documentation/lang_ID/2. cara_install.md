# Cara Instal Image-Tea-nano

Ikuti langkah-langkah berikut untuk menginstal Image-Tea-nano di Windows:

1. **Unduh Git**
   - Kunjungi [https://git-scm.com/download/win](https://git-scm.com/download/win) dan unduh Git untuk Windows.
   - Jalankan installer dan selesaikan proses instalasi.

2. **Clone Repository**
   - Buka Command Prompt atau PowerShell.
   - Arahkan ke folder tempat kamu ingin menyimpan proyek, misalnya:  
     `cd D:\Project`  
     atau ke Desktop:  
     `cd %USERPROFILE%\Desktop`
   - Jalankan perintah:  
     `git clone https://github.com/mudrikam/Image-Tea-nano.git`
   - Setelah proses clone selesai, masuk ke folder hasil clone:  
     `cd Image-Tea-nano`

## Metode Instalasi Alternatif

### Metode 1: Menggunakan Installer (Direkomendasikan untuk Pemula)

1. **Unduh Installer**
   - Kunjungi halaman releases: [https://github.com/mudrikam/Image-Tea-nano/releases](https://github.com/mudrikam/Image-Tea-nano/releases)
   - Unduh file `Image_Tea_Installer_x64.exe` terbaru.

2. **Siapkan Folder Instalasi**
   - Buat folder baru, misalnya "Image Tea", di lokasi pilihan kamu (sebaiknya bukan di drive C: untuk menghindari masalah izin di masa depan, misalnya di drive lain).
   - Pindahkan file `Image_Tea_Installer_x64.exe` yang diunduh ke folder ini.

3. **Jalankan Installer**
   - Klik dua kali file `Image_Tea_Installer_x64.exe` di folder "Image Tea".
   - Ikuti wizard instalasi untuk menyelesaikan pengaturan.

4. **Jalankan Aplikasi**
   - Buka folder tempat kamu menjalankan installer (misalnya folder "Image Tea").
   - Temukan `Image Tea.exe` lalu klik dua kali untuk menjalankan aplikasi.
   - (Opsional) Klik kanan `Image Tea.exe` → Send to → Desktop untuk membuat shortcut agar lebih mudah diakses.
   - Catatan: Aplikasi berjalan dari folder tempat installer berada — tidak terpasang ke Start Menu sistem.

### Metode 2: Unduh ZIP

1. **Unduh File ZIP**
   - Kunjungi repositori GitHub: [https://github.com/mudrikam/Image-Tea-nano](https://github.com/mudrikam/Image-Tea-nano)
   - Klik tombol **Code** yang hijau.
   - Pilih **Download ZIP**.

2. **Ekstrak ZIP**
   - Ekstrak file ZIP yang diunduh ke folder pilihan kamu.

3. **Jalankan Aplikasi**

![Run Image Tea](res\images\image_tea_exe.png)

   - Navigasi ke folder yang diekstrak.
   - Klik dua kali **Image Tea.exe** untuk memulai aplikasi.
   - Aplikasi akan otomatis mengunduh dan menginstal dependensi saat pertama kali dijalankan.

4. **Selesai**
   - Setelah proses selesai, aplikasi siap digunakan.
   - Jika mengalami masalah, pastikan koneksi internet stabil.

**Catatan:**
- Kamu tidak perlu menginstal Python atau library secara manual; cukup jalankan Image Tea.exe.
- Untuk memperbarui aplikasi, gunakan file **Image Tea Updater.exe**.
