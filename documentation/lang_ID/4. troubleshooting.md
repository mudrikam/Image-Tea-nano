 # Troubleshooting — Image-Tea-nano

 Halaman ini berisi daftar masalah umum dan solusi yang disarankan. Jika sebuah langkah meminta menghapus file atau mengubah izin, ikuti instruksi dengan hati-hati.

 ## Masalah Umum & Cara Mengatasi

 1. Image Tea tidak berjalan setelah instalasi / aplikasi menunggu lama namun tidak jalan
    - Penyebab kemungkinan: beberapa dependency belum terpasang dengan sempurna.
    - Solusi: Tutup aplikasi. Di folder tempat kamu meletakkan atau menjalankan installer, hapus semua file dan folder kecuali file installer yang kamu unduh (misalnya `Image_Tea_Installer_x64.exe` pada Windows x64).
      Jalankan kembali installer yang kamu unduh (pada Windows, klik dua kali file .exe) untuk mencoba menginstal ulang dependency yang hilang.
    - Jika installer masih gagal, coba jalankan installer sebagai administrator (klik kanan → "Run as administrator"). Jika pembaruan aplikasi gagal, gunakan opsi Update di aplikasi (toolbar atau menu **Help**) untuk mencoba ulang; tutup dan buka kembali aplikasi lalu coba lagi, atau jalankan aplikasi sebagai administrator. Jika masalah berlanjut, buka issue di GitHub dan sertakan log serta langkah yang sudah kamu coba.

 2. Update gagal atau updater tidak merespon
    - Solusi: Gunakan opsi Update di aplikasi (toolbar atau menu **Help**) untuk mencoba ulang. Jika masih gagal, tutup dan buka kembali aplikasi lalu coba lagi; jika masalah izin muncul, jalankan aplikasi sebagai administrator dan coba lagi. Jika pembaruan tetap gagal, buka issue di repositori GitHub dan sertakan pesan error atau log serta langkah yang sudah kamu coba.

 3. Aplikasi memberi pesan paket Python yang hilang
    - Solusi: Periksa `requirements.txt` di root proyek untuk daftar paket yang dibutuhkan. Jika kamu menginstal secara manual, pasang paket yang hilang menggunakan pip pada environment Python yang digunakan aplikasi.

 4. Antivirus atau Windows Defender memblokir aplikasi atau installer
    - Solusi: Izinkan atau whitelist installer dan `Image Tea.exe` pada program antivirusmu sementara. Jalankan ulang installer.

 5. Startup lambat atau pengunduhan dependency lama
    - Solusi: Pastikan koneksi internet kamu stabil. Beberapa file besar atau dependency mungkin memerlukan waktu saat pertama kali diunduh.

 6. Error lain / log
    - Solusi: Jika aplikasi menampilkan dialog error, catat pesan yang muncul dan cari di dokumentasi proyek atau buat issue di GitHub dengan teks error tersebut. Sertakan screenshot bila perlu.

 ## Kapan meminta bantuan
 - Jika langkah-langkah di atas tidak memperbaiki masalah, buka issue di repositori GitHub dan sertakan:
   - Detail sistem operasi (versi Windows)
   - Pesan error lengkap atau screenshot
   - Langkah yang sudah dicoba (mis. jalankan installer ulang, jalankan sebagai admin, whitelist antivirus)

 Langkah troubleshooting ini dimaksudkan untuk membantu pengguna menangani masalah setup yang umum. Hati-hati saat menghapus file dan simpan salinan data penting seperti API key.
