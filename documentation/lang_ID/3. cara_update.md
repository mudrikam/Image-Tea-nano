# Cara Update Image-Tea-nano

![Update Image Tea](res/images/update_app_toolbar.png)

Untuk memperbarui Image-Tea-nano ke versi terbaru, ikuti langkah berikut:

1. **Buka Aplikasi**
   - Jalankan aplikasi Image Tea.exe seperti biasa.

2. **Cek Notifikasi Update**
   - Jika update tersedia, akan muncul notifikasi di statusbar aplikasi.
   - Kamu juga bisa memilih menu **Update** di toolbar atau melalui menu **Help** di menu bar.

3. **Lakukan Update**
   - Klik notifikasi update di statusbar, atau pilih menu **Update**.
   - Ikuti petunjuk yang muncul di aplikasi untuk menyelesaikan proses update.

Jika tersedia update baru, aplikasi secara otomatis memeriksa repository dan menampilkan notifikasi singkat di pojok kanan bawah yang berfungsi untuk melakukan update cepat (Quick Update). Kamu dapat klik tombol `Update Now` langsung dari notifikasi untuk memulai pembaruan cepat.

Untuk melihat rincian lengkap (release notes, versi, dan opsi lanjutan), buka dialog Update Notice. Dialog ini biasanya muncul otomatis setelah pemeriksaan update selesai, atau dapat dibuka dari menu **Help** → **Version**. Dialog ini menampilkan:

 - Judul versi terbaru (mis. "Latest: v1.0.31").
 - Versi saat ini yang terpasang (Current version).
 - Waktu pengecekan (Checked at) yang menunjukkan kapan aplikasi terakhir memeriksa update.
 - Area "Release notes" yang menampilkan changelog dan catatan rilis.
 - Tombol aksi: `Update Now` untuk langsung mengunduh dan memasang update, `Remind Me Later` untuk mendapatkan pengingat di lain waktu, dan opsi `Skip this version` untuk melewatkan versi tersebut.
 - Tombol tambahan pada dialog seperti `Found a Bug` atau `Community` yang membuka link terkait.

Contoh tampilan Update Notice:

![Update Notice](res/images/update_app_notice.png)

Pada dialog Update Notice, klik `Update Now` untuk memulai proses pembaruan otomatis (aplikasi akan mengunduh dan menerapkan pembaruan secara otomatis). Jika memilih `Remind Me Later`, aplikasi akan menunda pemberitahuan sesuai interval pengingat. Opsi `Skip this version` akan menonaktifkan pemberitahuan untuk versi itu sampai ada rilis berikutnya.

### Jika update otomatis gagal

- Jika update otomatis tidak berhasil, buka dialog Update Notice (melalui toolbar atau **Help → Version**) dan klik `Update Now` untuk mencoba ulang.
- Jika masih gagal, tutup dan buka kembali aplikasi lalu coba lagi; jika terjadi masalah izin, jalankan aplikasi sebagai administrator dan coba update kembali.
- Jika pembaruan tetap gagal, buka issue di repositori GitHub dan sertakan pesan error atau log serta langkah yang sudah kamu coba. Ini membantu kami menyelidiki dan memperbaiki masalah.

   ![Update Notice](res/images/update_app_notice.png)

4. **Tunggu Proses Selesai**
   - Aplikasi akan mengunduh dan memasang update secara otomatis.
   - Setelah selesai, aplikasi akan siap digunakan dengan versi terbaru.

**Catatan Penting:**
- Backup API key dan data penting sebelum update jika diperlukan.
- Jika update gagal, pastikan koneksi internet stabil.
- Jika ada kendala, silakan tanyakan di grup WhatsApp komunitas.

Panduan ini hanya untuk Windows. Untuk sistem operasi lain, silakan tanyakan di grup WhatsApp komunitas.
