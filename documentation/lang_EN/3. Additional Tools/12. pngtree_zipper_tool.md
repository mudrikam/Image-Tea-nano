# Pngtree Zipper Tool

This tool helps you create ZIP archives for Pngtree asset submissions. You can batch process multiple files by dragging and dropping them into the tool.

## How to Use

1. **Add Files**: Drag and drop supported files (PSD, AI, EPS, PNG, JPG) onto the drop area, or use the menu options:
   - **Import files** - Select individual files
   - **Select Folder** - Import all supported files from a folder
   - **Load from Database** - Load files from the Image Tea database
   - **Load from Database** button - Quick button for database loading

2. **Select Output Directory**: Choose where to save the ZIP files:
   - Click **Select Output** button to browse for a folder
   - Or the tool will use the source folder if all files come from the same folder

3. **Run Batch Zip**: Click **Run batch zip** to start processing. Files with the same name (different extensions) will be grouped into one ZIP archive.

4. **Monitor Progress**: Watch the progress bars showing overall and file-level progress.

## Supported File Types

- `.psd` - Photoshop files
- `.ai` - Illustrator files
- `.eps` - EPS files
- `.png` - PNG images
- `.jpg` - JPEG images

## Main Buttons

| Button | Function |
|--------|----------|
| Select Output | Choose the output folder for ZIP archives |
| Open Output | Open the output folder after processing |
| Reset | Clear all added files and stats |
| Load from Database | Load supported files from the database |
| WhatsApp | Join the Desainia WhatsApp group |
| Run batch zip | Start the ZIP creation process |

## File Grouping Logic

Files are grouped by their base filename. For example:
- `file1.psd` + `file1.png` → `file1.zip`
- `file2.ai` + `file2.eps` + `file2.jpg` → `file2.zip`

Each ZIP file contains all files from the same group with the same base filename.

## Notes

- Ensure the output directory has sufficient disk space
- The tool automatically detects and skips duplicate files
- Use **Clear data** from the File menu to reset the tool state
