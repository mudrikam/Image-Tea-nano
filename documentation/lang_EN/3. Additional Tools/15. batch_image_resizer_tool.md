# Batch Image Resizer Tool

This tool resizes multiple images to specific dimensions in batch, perfect for preparing images for Envato Elements submissions or other platforms with specific size requirements.

## How It Works

1. **Source Selection**: Choose a folder of images or drop image files onto the input field
2. **Output Location**: Output folder is auto-generated as a "RESIZED" subfolder
3. **Resize Settings**: Set the target dimension (height or width) in pixels
4. **Batch Processing**: All images are resized proportionally while maintaining aspect ratio

## How to Use

### Step 1: Select Source Images

- Click **Browse** next to Source to select a folder, or
- Drag and drop image files/folders directly onto the source input field

### Step 2: Set Resize Parameters

- Choose **Height** or **Width** mode
- Enter the target size in pixels (e.g., 1500, 1820)
- Images will be resized proportionally to maintain aspect ratio

### Step 3: Process Images

- Click **RESIZE** to start the batch operation
- Progress bar shows current status
- When complete, you can choose to open the output folder

## Interface Elements

- **Source Input**: Folder path or file count for selected images
- **Output Input**: Destination folder (auto-generated as "RESIZED" subfolder)
- **File Table**: Lists all loaded images with filename and original size
- **Stats Bar**: Shows file count and processing progress
- **Resize Button**: Starts the batch resizing process

## Additional Options

- **Load Database**: Load previously processed images from the database
- **Clear Source**: Remove all files and reset source path
- **Clear All**: Stop processing and reset everything
- **Paste Buttons**: Quickly paste paths from clipboard
- **Open Buttons**: Open file locations in your system's file explorer

## Notes

- Supported formats: JPG, JPEG, PNG, BMP, TIFF, GIF, WEBP
- Output format is always PNG with high quality
- Original filenames are preserved in the output
- Aspect ratio is maintained during resizing
