# Imagen Generator Tool

This tool helps you automatically generate images from prompts in your database using the Imagen API.

## How to Use

1. **Select API Key**: Make sure you have selected a valid API key for Imagen in the top section of the dialog.

2. **Set Generation Options**:
   - **Model**: Choose the Imagen model to use.
   - **Number of Images**: Specify how many images to generate per prompt (1-4).
   - **Mode**: Choose "Generate All" to process all prompts, or "Continue from Stopped" to resume from interrupted generation.
   - **Aspect Ratio**: Select the image aspect ratio (such as 1:1 for square, 16:9 for horizontal).
   - **Resolution**: Choose explicit resolution (optional, for OpenRouter models).
   - **Image Size**: Select image size (1K or 2K).
   - **Output Format**: Choose output format (PNG or JPG).
   - **Delay Interval**: Set delay between batches (Random = 1-5 seconds, or custom value in seconds).
   - **Output Folder**: Select folder to save generated images. Click browse to choose folder or paste to insert path from clipboard.

3. **Click "Run Prompt"**: The tool will start generating images from available prompts. You can see progress in the progress bar and status in the bottom labels.

4. **Monitor Progress**: The table shows prompts with their individual status. The status column indicates if pending, generating, completed, or error.

## Additional Features

- **Configure Models**: Click the gear icon to configure available Imagen models.
- **Clear All**: Remove all generation status from the database.
- **Export CSV**: Save prompts with generation status to a CSV file.

## Table Interactions

- **Double-click**: Edit the selected prompt.
- **Right-click**: Open context menu for copy or edit options.

## Pagination

If there are many prompts, use the pagination controls below the table to navigate pages. You can change the number of prompts per page.

## Status and Progress

- **Stats**: View total prompts, completed, pending, generated images, remaining, and current status.
- **Progress Bar**: Shows generation progress.
- **Status Label**: Provides information about what's happening (such as "Ready to generate" or "Generating images...").

The tool will stop automatically if there's an error. Ensure your API key is valid, output folder exists, and internet connection is stable for best results.
