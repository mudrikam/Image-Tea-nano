# Folder Comparator

## Overview

The Folder Comparator tool allows you to compare two folders by filename and copy missing files from source to destination.

## Features

- **Folder Comparison**: Compare files by filename (with extension matching)
- **Smart Matching**: Uses stem matching to find files with same name but different extensions
- **Visual Indicators**: Green color for matching files, red for missing/different files
- **Copy Missing Files**: Copy files that exist in source but not in destination
- **Drag & Drop**: Drop folders directly onto the source or destination tables
- **Persistent Settings**: Remembers last source and destination folders

## How to Use

### 1. Loading Source Folder

- **Browse**: Click folder icon to browse and select source folder
- **Paste**: Paste folder path from clipboard
- **Drag & Drop**: Drop a folder onto the Source Files table

### 2. Loading Destination Folder

- **Browse**: Click folder icon to browse and select destination folder
- **Paste**: Paste folder path from clipboard
- **Drag & Drop**: Drop a folder onto the Destination Files table

### 3. Comparing

- Files are automatically compared when both folders are loaded
- **Missing count** shows how many files need to be copied
- Source files appear in green if they exist in destination, red if missing
- Destination files appear in green if they exist in source, red if extra

### 4. Copying Missing Files

- Click "COPY MISSING" to copy all missing files from source to destination
- Progress bar shows copy progress
- After completion, you can choose to open the destination folder

### 5. Rescanning

- Click "Rescan" to refresh both folder contents without clearing settings
- Useful when files have been added or removed externally

### 6. Clearing

- "Clear" button resets all fields and tables
- Individual "X" buttons clear just source or destination
