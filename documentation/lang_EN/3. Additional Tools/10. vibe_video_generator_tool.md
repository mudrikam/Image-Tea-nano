# Vibe Video Generator

Vibe Video Generator is an AI-powered tool that lets you create animated video scripts using TypeScript and React (powered by Remotion), generate them automatically from a text description, preview them inside the app, and render them to an actual video file — all in one place.

> **This tool requires a Member login.** You must be logged in to access it.

---

## Interface Overview

The window is divided into three main areas:

- **Menu bar** (top) — File menu for creating collections and scripts
- **Left panel** — Collections tree for organizing your scripts
- **Right panel** — Tabbed area with: TypeScript editor, Preview, Output, and Render Settings
- **Bottom bar** — Quick render controls and the Render Video button

---

## Collections Panel (Left)

This panel shows all your script collections in a tree structure. Think of collections as folders to organize your scripts.

- **Click a collection** to expand or collapse it and see its scripts
- **Click a script** to open it in the TypeScript editor
- **Right-click a collection** to get a context menu with:
  - *New Collection* — create a new top-level collection
  - *New Subfolder* — create a sub-collection inside the selected one
  - *New Script* — create a new script inside the selected collection
  - *Edit* — rename or change the collection's icon and color
  - *Delete* — permanently delete the collection and all its scripts
- **Right-click a script** to get:
  - *Edit* — open the script editor
  - *Delete* — permanently delete the script

---

## File Menu

Located in the menu bar at the top of the window.

- **New Collection** (`Ctrl+Shift+N`) — opens a dialog to create a new collection. You can set its name, description, icon, and color.
- **New Script** (`Ctrl+N`) — opens the New Script dialog for the currently selected collection. If no collection is selected, you will be prompted to select one first.

---

## New Script / Edit Script Dialog

This dialog opens when you create or edit a script. It has two tabs:

### Generate with AI tab

Use this tab to generate a script automatically from a text description.

1. **Description field** — type what you want the video to look like. Be as descriptive as you like. Examples:
   - *"A countdown from 10 to 0 with a glowing red background"*
   - *"The word SALE fades in with a bounce, then slides out to the right"*
2. **Refine Prompt** — if your description is rough, click this button. The AI will expand it into a detailed, well-structured prompt automatically.
3. **Generate Script** — sends your description to the AI and generates a TypeScript animation script. The result appears in the TypeScript tab automatically.

### TypeScript tab

Displays the generated or manually written TypeScript/React code. You can edit the code directly here before saving.

- **Script Name** — required. Becomes the file name when rendering.
- **Description** — optional short note about what the script does.
- **Save / Create** button — saves the script to the selected collection.

---

## TypeScript Tab (Main Editor)

Shows the code of the currently selected script with full syntax highlighting.

- To edit a script, right-click it in the left panel and choose **Edit**, or create a new one via the File menu.
- **Refine with AI** — a text field and button at the bottom of the editor. Type an instruction (e.g. *"make the text red"* or *"add a fade-out at the end"*) and click Refine. The AI will apply the change to the existing code using a minimal, targeted edit.

---

## Preview Tab

Lets you preview your animation directly inside the app using an embedded browser powered by Remotion Studio.

- **Start Preview** — starts a local preview server and loads the current script. This may take a few seconds on first launch.
- **Stop** — stops the preview server.
- **Reload** — refreshes the preview to reflect any code changes.
- **Open in Browser** — opens the Remotion Studio preview in your default web browser for a larger view.

> A script must be selected and loaded in the TypeScript editor before you can start a preview.

---

## Output Tab

Configure where and how the rendered video will be saved.

- **Filename** — the name of the output file (without extension). This auto-fills from the script name when you select a script.
- **Output** — the folder where the video will be saved. Use the **Browse** button to pick a folder, the **Paste** button to paste a path from clipboard, or the **Open** button to view the current folder in Explorer.
- **Format** — the output file format. Options: `mp4`, `webm`, `mov`, `gif`, `png`, `jpg`, `mp3`, `wav`, `aac`.
- **Overwrite existing file** — when checked, replaces any existing file with the same name.
- **Output as image sequence** — renders each frame as a separate image instead of a video file.
- **Mute audio** — renders the video without audio.
- **Enforce silent audio track** — forces an empty audio track to be included even if the script has no audio.

---

## Render Settings Tab

Fine-tune how the video is rendered.

### Preset

A quick-select dropdown to load a set of predefined settings:

| Preset | Resolution | FPS |
|---|---|---|
| 720p30 | 1280 × 720 | 30 |
| 1080p60 | 1920 × 1080 | 60 |
| 2K60 | 2560 × 1440 | 60 |
| 4K60 | 3840 × 2160 | 60 |

- **Save** — saves the current settings as a Custom preset.
- **Reset** — resets back to 1080p60.

### Video Settings

- **Width / Height** — output resolution in pixels.
- **FPS** — frames per second.
- **Duration** — total length of the video in seconds.
- **Codec** — video codec (e.g. `h264`, `h265`, `vp8`, `vp9`).
- **Pixel Format** — pixel encoding format (e.g. `yuv420p`).
- **Scale** — scale factor applied after rendering.
- **Image Format** — intermediate frame format used during rendering (`jpeg` or `png`).

### Audio Settings

- **Audio Codec** — codec used for audio encoding.
- **Audio Bitrate** — audio quality in kbps.

### Performance Settings

Controls how many CPU threads are used during rendering. Higher values are faster but use more resources.

---

## Bottom Bar (Quick Render Controls)

Located at the very bottom of the window. Mirrors some Output and Render Settings fields for convenience without switching tabs.

- **Preset** — quick switch between render presets.
- **Filename** — output filename. Stays in sync with the Output tab.
- **Output** — output folder path. Stays in sync with the Output tab.
- **Browse** button — pick the output folder.
- **Progress bar** — shows render progress and status messages.
- **Render Video** — starts the render. The script currently open in the TypeScript editor will be rendered using the configured output settings.

## Quick Tutorial: From Idea to Video

1. **Open the tool** from the Tools menu. Login is required.
2. **Create a collection** via File > New Collection (or `Ctrl+Shift+N`). Give it a name like *My Videos*.
3. **Create a script** via File > New Script (`Ctrl+N`) with the collection selected.
4. In the **Generate with AI** tab, type what you want — e.g. *"A glowing title card with the text HELLO WORLD, dark background, fade in effect"*.
5. Optionally click **Refine Prompt** to let AI improve your description.
6. Click **Generate Script**. The TypeScript code appears in the TypeScript tab.
7. Click **Save** or **Create** to save the script.
8. Select the script in the left panel. Switch to the **Preview** tab and click **Start Preview** to see it in action.
9. When satisfied, go to the **Output** tab and set the output folder and filename.
10. Click **Render Video** at the bottom. Watch the progress bar. When done, a dialog appears with an option to open the file location.

---

## AI Error Fixing

If a render fails due to a code error, a **Render Failed** dialog appears with the error details and a **Fix Errors** button. Clicking it sends the script and the error to the AI, which automatically patches the code. If the AI fix also fails, a retry option is offered.
