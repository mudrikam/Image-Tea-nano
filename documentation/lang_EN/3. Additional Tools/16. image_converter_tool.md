# Image Converter Tool

## Overview

The Image Converter tool allows you to convert multiple images between different formats including PNG, JPG, BMP, TIFF, and WEBP in batch.

## Features

- **Batch Conversion**: Convert multiple images at once
- **Format Support**: PNG, JPG, BMP, TIFF, WEBP input and output formats
- **Quality Control**: Adjust output quality for JPG format (1-100)
- **DPI Settings**: Set DPI for output images (1-1200)
- **Non-blocking**: Runs independently without blocking the main Image Tea interface
- **Database Integration**: Load images directly from Image Tea database

## How to Use

### 1. Loading Images

- **Load from Database**: Click "Load Database" to load all image files from the Image Tea database
- **Browse Folder**: Click the folder icon to select a folder containing images
- **Drag & Drop**: Drag and drop image files/folders directly onto the file table
- **Paste Path**: Paste a file or folder path from clipboard using the paste button

### 2. Setting Output

- **Output Folder**: Select or enter the output folder where converted images will be saved
- **Output Format**: Choose from PNG, JPG, BMP, TIFF, or WEBP using the dropdown
- **Quality Slider**: Adjust JPG quality (1-100). Only enabled when JPG format is selected
- **DPI Spinbox**: Set the DPI value for output images

### 3. Converting

- Click the "CONVERT" button to start conversion
- The progress bar shows conversion progress
- Files table displays the status of each file (Ready, Converting, Completed, Failed)
- Click "STOP" to cancel the conversion process

## Requirements

- **Source Files**: Must be image files with extensions: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff`, `.tif`, `.gif`, `.webp`, `.ico`, `.psd`
- **Python Imaging Library**: Requires Pillow (PIL) for image conversion
- No external tools required

## Notes

- For JPG/BMP output, images with transparency are flattened onto white background
- Original filenames are preserved in the output
- Output format extension is automatically applied to converted files
