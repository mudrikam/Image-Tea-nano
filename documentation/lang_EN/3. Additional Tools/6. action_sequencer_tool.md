# Action Sequencer Tool

This tool helps you run action sequences on files using Adobe Photoshop or Illustrator. You can create presets containing action steps, then apply them to single files or multiple files at once.

## How to Use

1. **Add Platform**: Add a platform to Action Sequencer by selecting the platform (e.g., Photoshop or Illustrator), set the **Exe Path** to the application's executable, optionally enter a note, then click the **+ Add** button in Action Settings.

	![Action Settings](res/images/action_sequencer_settings.png)

2. **Add Action Set**: Add an action set to Action Sequencer by selecting the **Action Sets** tab or the Presets area then click the **+ Add** button. **Before clicking** **+ Add**, make sure the selected **Platform** at the top of Action Sequencer matches the platform you added in Step 1 (Settings → Platform). Make sure the set **name** matches the Action Set name in your Photoshop actions so the sequencer can invoke the correct actions. You may enter a **Description** if needed, then click **Save**.

	![Action Sets](res/images/action_sequencer_adding_action_sets.png)

	*In the Action Sets list you can see existing sets; click **+ Add** to create a new set.*

	![Add New Action Set](res/images/action_sequencer_adding_action_sets_new_set.png)

	*The **Add New Action Set** dialog: enter **Set Name** (must match your Photoshop Action Set) and an optional **Description**, then click **Save**.*

	![Action Set in Photoshop](res/images/action_sequencer_adding_action_sets_on_photoshop.png)

	*Photoshop's Actions panel: verify the Action Set and action names exist so the sequencer can call them exactly by name.*

3. **Add Action**: Select the Action Set you created, then click the **Add New Action** area on the right. In the **Add New Action** dialog choose an appropriate **Type** (usually `Action`), then enter the **Name** (example: `makeSmartObject`) — make sure the name exactly matches the action name in Photoshop so the sequencer can call it. Set an **Icon** and **Color** to make actions easy to identify, and configure other options (Delay, Export format, etc.) if needed. When done, click **Save**.

	![Add Action](res/images/action_sequencer_adding_action.png)

	*Use the **Add New Action** area to add an action into the selected Action Set; this slot shows where the new action will appear.*

	![Add Action Example](res/images/action_sequencer_add_action_example.png)

	*In the **Add New Action** dialog: choose **Type**, enter **Name** (must match Photoshop action), pick **Icon** and **Color** for quick identification, and set **Delay** or **Export** options if required. Click **Save** to store the action.*

4. **Add Preset**: A *Preset* is a named sequence of action steps (a workflow) that you can run later. When creating a preset give it a descriptive **Preset Name**, choose the **Preset Type** (`Batch` if you will run it on many files, `Single` for the active document), and optionally add a **Description** so other users understand its purpose.

	![Presets list](res/images/action_sequencer_adding_presets.png)

	*The new preset appears in the Presets list — choose a clear name so the workflow is easy to find.*

	![Add New Preset](res/images/action_sequencer_add_new_preset.png)

	*In the **Add New Preset** dialog: enter **Preset Name**, pick **Preset Type** and add an optional **Description**, then click **Save**.*

5. **Add Steps to Preset**: Select a created preset from the Presets list to edit its workflow. On the right pane click **Select Action** (or the **+ Add** area) to open the **Select Action to Add** dialog, where you can pick actions from the Action Sets you added earlier. Choose one or more actions (for example `makeSmartObject`) and click **Add Action** to insert them into the preset's step list. The preset workflow will run actions in the order they appear — reorder or edit steps as needed.

	![Select Action to Add](res/images/action_sequencer_add_step_to_preset.png)

	*In the **Select Action to Add** dialog: pick actions from the left Action Sets list and click **Add Action** to include them in the selected preset workflow.*

6. **Load Files**:
   - Click "Load from Database" to load all files from the application database.
   - Or click "Select Source" to choose a folder containing files.
   - Or click "Select File" to choose a single file only.

7. **Set Output Path**: Click the folder icon on the right to select the folder where output results will be saved.

8. **Run Sequence**: Click the "Run Sequences" button to start the process. The tool will open the Adobe application and execute actions according to the selected preset.

## Processing Modes

- **Batch Mode**: Processes multiple files at once. Suitable for presets with "Batch" type.
- **Single Mode**: Processes one file only. Suitable for presets with "Single" type.

## Main Features

### Preset Management
- **Add Preset**: Create a new preset by clicking the "+" button in the Presets tab.
- **Edit Preset**: Right-click on a preset to edit name and settings.
- **Remove Preset**: Right-click on a preset to delete (will delete all steps within it).

### Step Management
- **Add Step**: Click the "+" button in the Steps tab to add actions to the preset.
- **Edit Step**: Right-click on a step to edit action settings.
- **Delete Step**: Right-click on a step to remove from preset.
- **Reorder Steps**: Drag and drop steps to change execution order.

### Action Management
- **Action Sets**: Manage action collections in the Actions tab.
- **Add Action**: Create new actions with specific parameters.
- **Edit Action**: Change settings of existing actions.

## Status and Progress

- **Files Count**: Shows the number of files to be processed.
- **Steps Count**: Shows the number of steps in the selected preset.
- **Progress Bar**: Indicates file processing progress.
- **Status Label**: Provides information about current process status.

## Process Controls

- **Run Sequences**: Start running action sequences.
- **Stop Process**: Stop the currently running process.
- **Continue Process**: Resume a stopped process (if in pause mode).
- **Reset Tool**: Clear all loaded data and return to initial state.

## Settings

Click the "Settings" button to configure:
- **Platform Paths**: Location of Photoshop/Illustrator executables.
- **Output Settings**: Prefix, suffix, and file watcher options.
- **Watch Timeout**: Wait time for detecting output files.

## Usage Tips

- Ensure Adobe application executable paths are configured correctly.
- Use file watcher to ensure all outputs are detected.
- For batch processing, ensure output folder has sufficient storage space.
- If process stops, you can continue from the last processed file.

The tool will automatically clean up temporary JSX files when closed. Ensure smooth connection with Adobe applications for best results.
