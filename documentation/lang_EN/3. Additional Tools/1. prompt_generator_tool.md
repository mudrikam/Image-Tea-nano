# Prompt Generator Tool

This tool automatically generates AI prompts either from reference images in your database/folder, or from a set of creative parameters you define. Generated prompts can be used to create new images or videos with AI.

## Interface Overview

The dialog is split into two panels:

- **Left panel**  generation settings, with two tabs: **By Reference** and **By Parameters**
- **Right panel**  results and logs, with three tabs: **Table**, **Logs**, and **Configure Instructions**

The **Generate** button at the bottom automatically adapts its label depending on which tab is active.

---

## By Reference Tab

Generates prompts by analyzing actual reference images.

- **Source**: Choose where to load reference images from:
  - *Load from Database*  uses images already imported into Image-Tea
  - *Loaded Folder*  uses images from a folder you select manually
- **Load Folder**: Appears when *Loaded Folder* is selected. Opens a folder picker starting from your home directory.
- **Type**: Type of prompt to generate (Image Generation or Video Generation).
- **Ratio**: Aspect ratio to include in the prompt (e.g. 16:9, 1:1, 9:16).
- **Length**: Target character length for each generated prompt.
- **Per File (max 20)**: Number of prompts to generate per reference image.
- **Variation**: How different each prompt should be from the last (1 = very similar, 10 = completely different).
- **Delay**: Pause between processing each image. *No Delay* = instant, *Random* = 15 seconds, or type a custom number of seconds.

---

## By Parameters Tab

Generates prompts purely from creative parameters  no reference image required.

- **Type**: Image Generation or Video Generation.
- **Language**: Output language for the generated prompts (default: English).
- **Ratio**: Aspect ratio.
- **Length**: Target character length per prompt.
- **Per Batch (max 20)**: How many prompts to generate in a single AI request.
- **Requests**: How many times to repeat the request. Total prompts = Per Batch  Requests.
- **Variation**: Variation level between prompts.
- **Mode**: Controls how Theme, Mood, Color, Art Style, and Background are applied:
  - *User Defined*  you pick the values manually; they stay fixed for every request.
  - *Random Parameters*  before each request, the tool automatically randomizes Theme, Mood, Color Palette, Art Style. With 4 requests you get 4 different parameter combinations, each randomized independently.
- **Theme**: Overall visual or narrative theme (e.g. Nature, Sci-Fi, Gothic). Editable  type a custom value.
- **Mood**: Emotional tone (e.g. Ethereal, Dramatic, Playful). Editable.
- **Color Palette**: Color scheme for the prompt (e.g. Warm tones, Neon, Duotone). Editable.
- **Art Style**: Visual style (e.g. Watercolor, Flat Vector, Pixel Art, 3D Render). Editable.
- **Background**: Scene background (e.g. Bokeh Blur, Marble Surface, Starry Night). Editable. Use the palette button to pick a custom HEX color.
- **Human Model**: Whether people appear in the image, and what type.
- **Custom Instruction**: Optional free-text instruction appended to every request.

All editable combos have a **+** button to permanently save the typed value to the list.

## Stats Bar

Displayed above the Generate button:

- **Type**  active generation mode
- **Generated**  total prompts currently in the database
- **Est. total**  estimated final count when generation completes
- **Elapsed**  time since generation started
- **ETA**  estimated time to finish
- **Remaining**  number of prompts still to be generated

---

## Table Tab

Displays all generated prompts with pagination.

- **Per Page**: Change how many rows are shown per page.
- **Prev / Next / Page Spinner**: Navigate pages.
- **Copy button** (each row): Copies the prompt and marks it as copied (highlighted).
- **Double-click**: Open inline editor to modify the prompt.
- **Middle-click**: Copy prompt to clipboard.
- **Ctrl+C**: Copy the selected prompt.
- **Right-click**: Context menu  Copy, Edit, or Delete the prompt.

### Toolbar Buttons

- **Refresh**: Reload the table from the database.
- **Clear All**: Delete all generated prompts.
- **Clear Copied**: Delete only prompts that have been marked as copied.
- **Export CSV**: Save all prompts to a CSV file.
- **Import CSV**: Import prompts from a CSV file.

---

## Logs Tab

Shows a timestamped log of every generation event, error, and progress update. Use **Clear** to empty the log.

---

## Configure Instructions Tab

Advanced: edit the AI instructions and requirements that are sent with every prompt generation request.

- **Instructions**: Edit the system-level instruction text for Image Generation and Video Generation separately.
- **Requirements**: Add, edit, or remove specific requirements for each type.
- **Variation Levels**: Edit the description for each variation level (110).
- Click **Save** to write changes back to the configuration file.

---

## Tips

- Use **Random Parameters** mode with a high **Requests** count to explore a wide variety of prompt styles in one run.
- The **Loaded Folder** source lets you use images from outside Image-Tea without importing them first.
- Prompts highlighted in the table have already been copied  use **Clear Copied** to keep your list clean.
- Ensure your API key is valid and your internet connection is stable for best results.
