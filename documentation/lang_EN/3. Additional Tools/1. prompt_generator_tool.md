# Prompt Generator Tool

This tool helps you automatically generate prompts based on images in your database. The generated prompts can be used to create new images or videos with AI.

## How to Use

1. **Select API Key**: Make sure you have selected a valid API key in the top section of the dialog. The tool uses this API key to access AI services.

2. **Set Generation Options**:
   - **Type**: Choose the type of prompt to generate (such as for images or videos).
   - **Ratio**: Select the aspect ratio for images (such as 16:9 for widescreen, 1:1 for square, or 9:16 for portrait).
   - **Length**: Set the maximum prompt length in tokens/words.
   - **Prompts per File**: Specify how many prompts to generate per image.
   - **Variation**: Control how different each prompt should be (1 = very similar, 10 = completely different).
   - **Delay**: Set the delay between processing images (No Delay = no delay, Random = random 1-5 seconds, or custom value in seconds).

3. **Click "Generate Prompts"**: The tool will process all images in the database and create prompts for each. You can see the progress in the progress bar and status in the bottom labels.

4. **View Results**: Generated prompts appear in the table. Each row shows the prompt text, character count, creation time, and copy button.

## Additional Features

- **Edit Prompt**: Click to modify the prompt generator configuration.
- **Refresh**: Update the prompts table.
- **Clear All**: Delete all generated prompts.
- **Clear Copied**: Delete prompts that have been copied.
- **Export CSV**: Save prompts to a CSV file.
- **Import CSV**: Import prompts from a CSV file.

## Table Interactions

- **Double-click**: Edit the selected prompt.
- **Middle-click**: Copy prompt to clipboard.
- **Ctrl+C**: Copy the selected prompt.
- **Right-click**: Open context menu for copy options.

## Pagination

If there are many prompts, use the pagination controls below the table to navigate pages. You can change the number of prompts per page.

## Status and Progress

- **Stats**: View the number of prompts, total files, and generation progress.
- **Progress Bar**: Shows processing progress.
- **Status Label**: Provides information about what's happening (such as "Ready to generate" or "Generating prompts...").

The tool will stop automatically if there's an error or you click stop. Ensure your API key is valid and internet connection is stable for best results.
