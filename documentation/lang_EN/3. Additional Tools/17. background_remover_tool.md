# Background Remover Tool

## Overview

Background Remover removes image backgrounds with AI using ONNX models through `rembg`. It processes multiple images in one run and produces transparent PNG output by default.

## Features

- **AI Background Removal**: Remove image backgrounds using ONNX models through rembg
- **Batch Processing**: Process multiple image files in one operation
- **Model Selection**: Use `isnet-general-use`, `u2net`, `u2netp`, `u2net_human_seg`, or `u2net_cloth_seg`
- **Mask Adjustment**: Adjust black, mid, and white levels to refine transparency
- **Auto Crop**: Automatically crop transparent edges around the subject
- **Optional Exports**: Save masks, create a solid-background JPG, or export a JPG copy

## How It Works

1. **Source Selection**: Load images from the Image Tea database, browse for files/folders, or drag and drop them into the file table
2. **Model Processing**: The selected ONNX model detects the foreground and generates transparency data
3. **Mask Enhancement**: Transparency levels are adjusted and the subject can be cropped automatically
4. **Output Generation**: A transparent PNG is saved, with optional mask and JPG outputs

## How to Use

### Step 1: Select Source Images

- Click **Load Database** to load image files from the Image Tea database
- Add files or folders by dragging them into the file table, or use the source browse controls
- Use **Clear Source**, **Clear All**, **Clear Completed**, or **Clear Failed** to manage the queue

### Step 2: Set Output and Model

- Choose the output folder. If it is left empty, the tool creates a `PNG` folder next to the source file
- Select a model. The default model is `isnet-general-use`; other available models include `u2net`, `u2netp`, `u2net_human_seg`, and `u2net_cloth_seg`
- Models are downloaded or prepared when needed

### Step 3: Adjust the Mask

- Use **Adjust Mask** and the black, mid, and white level handles to refine transparency
- Click **Reset Levels** to restore the default values of 20, 128, and 235

### Step 4: Process Images

- Configure the output options and click **START**
- Select **All** to process the full queue or **Failed Only** to retry failed files

## Interface Elements

- **Source**: Source folder or image file path
- **Output**: Destination folder for generated files
- **Model**: ONNX model used for background removal
- **Adjust Mask**: Enables mask preview and level adjustment
- **Auto Crop**: Crops transparent edges around the detected subject
- **Solid BG**: Creates an additional JPG with a selected solid background color
- **Save Mask**: Keeps the generated mask as a PNG
- **JPG Export**: Creates a JPG copy using the selected quality from 1 to 100
- **File Table**: Lists loaded files and their processing status
- **Progress Bar**: Shows current processing progress

## Additional Options

- **Margin**: Keeps extra pixels around the subject when auto-cropping
- **Mode**: Process all queued files or retry failed files only
- **Clear Completed**: Remove completed files from the queue
- **Clear Failed**: Remove failed files from the queue

## Requirements

- **Input Files**: `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tiff`, `.tif`, `.avif`, `.heic`, or `.heif`
- **Runtime**: rembg and ONNX Runtime dependencies installed through Image Tea Tools Manager
- **Model**: An ONNX model is prepared or downloaded when required

## Notes

- The main result is saved as a transparent PNG
- JPG cannot preserve transparency, so transparent areas are flattened
- ONNX Runtime uses an available GPU provider when possible and falls back to CPU
- The first run may take longer because the selected model must be prepared
- If model or runtime initialization fails, install or repair the Background Remover dependencies from the Image Tea Tools Manager, then retry the failed files
- Use clear, well-lit source images for better subject edges. Fine hair, glass, shadows, and low-contrast subjects may need mask level adjustment
