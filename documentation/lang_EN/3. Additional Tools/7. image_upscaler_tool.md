# Image Upscaler Tool

This tool helps you enhance image resolution using RealESRGAN. You can upscale images in batches with various AI models and quality settings.

## How to Use

1. **Load Images**: Choose the source images to upscale.
   - Click "Load Database" to load all images from the application database.
   - Click "Load Folder" to choose a folder containing images.
   - Click "Load File" to select a single image.

2. **Configure Settings**:
   - **Model**: Select the AI model to use for upscaling.
   - **Scale**: Choose the magnification factor (2x, 3x, or 4x).
   - **Batch**: Set the number of images processed simultaneously (higher = faster but needs more RAM).
   - **Format**: Choose output format (PNG, JPG, or WEBP).

3. **Set Output Folder**: Click the folder icon to select where to save upscaled results. If empty, results will be saved to the default folder.

4. **Run Upscaling**: Click the "RUN UPSCALE" button to start the process. The tool will process all images and show progress in the progress bar.

## Main Features

### Load and Manage Images
- **Load Database**: Load all images from the Image-Tea database.
- **Load Folder**: Choose a folder to load all images within it.
- **Load File**: Add a single image to the list.
- **Clear**: Remove all images from the list.

### Output Settings
- **Output Folder**: Specify folder to save results.
- **Browse**: Browse and select output folder.
- **Paste**: Paste folder path from clipboard.
- **Clear**: Clear output folder path.

### Model and Scale
- Models are automatically detected from the models folder.
- Scale is automatically locked if the model already includes a scale factor (e.g., model-x4).
- Batch size affects speed and memory usage.

## Status and Progress

- **Files**: Shows the number of loaded images.
- **Images**: Shows image processing progress (processed/total).
- **Elapsed**: Time elapsed since start.
- **ETA**: Estimated time to completion.
- **Remaining**: Number of images still to process.
- **Status**: Current process status (Idle/Running).

## Logs and Monitoring

- **Process Logs**: Shows detailed upscaling process, errors, and important information.
- **Progress Bar**: Indicates completion percentage.
- **Status Icons**: Check icon (green) for success, X icon (red) for failure.

## Process Controls

- **RUN UPSCALE**: Start the upscaling process.
- **STOP**: Stop the currently running process.

## Usage Tips

- Ensure RealESRGAN models folder is properly installed.
- Use batch size appropriate for your computer's RAM capacity.
- PNG provides best quality but larger file sizes.
- JPG is smaller but may have compression artifacts.
- WEBP provides balance between quality and file size.

The tool will automatically detect and use hardware acceleration if available. Ensure latest GPU drivers for optimal performance.</content>
