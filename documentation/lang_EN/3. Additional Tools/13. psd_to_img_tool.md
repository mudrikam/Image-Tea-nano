# PSD to IMG Converter

## Overview

The PSD to IMG Converter tool allows you to convert Photoshop PSD files to common image formats including JPG, PNG, BMP, TIFF, and WEBP.

## Features

- **PSD Conversion**: Convert Photoshop PSD files to multiple image formats
- **Batch Processing**: Convert multiple files at once
- **Quality Control**: Adjust output quality for JPG format (1-100)
- **Non-blocking**: Runs independently without blocking the main Image Tea interface
- **Database Integration**: Load PSD files directly from Image Tea database

## How to Use

### 1. Loading PSD Files

- **Load from Database**: Click "Load Database" to load all PSD files from the Image Tea database
- **Browse File**: Click the folder icon to browse and select a single PSD file
- **Paste Path**: Paste a file path from clipboard using the paste button

### 2. Setting Output

- **Output Folder**: Select or enter the output folder where converted images will be saved
- **Output Format**: Choose from PNG, JPG, BMP, TIFF, or WEBP using the dropdown
- **Quality Slider**: Adjust JPG quality (1-100). Only enabled when JPG format is selected

### 3. Converting

- Click the "CONVERT" button to start conversion
- The progress bar shows conversion progress
- Files table displays the status of each file (Ready, Converting, Completed, Failed)

## Requirements

- **Source Files**: Must be Photoshop PSD files (`.psd` extension)
- **Python Imaging Library**: Requires Pillow (PIL) for image conversion
- No external tools required

## Notes

- Non-PSD files will be rejected with a warning message
- The tool creates RGB versions of PSD files (flattened)
- Output files maintain the same base name as the source files
