# Batch Audio Remover Tool

This tool helps you remove audio from videos in batch. You can process multiple videos at once and save the results to a destination folder.

## How to Use

1. **Load Video Data**: Click "Load from Database" to get videos from the existing database, or "Select Source" to choose a folder containing videos.

2. **Select Destination Folder**: Click "Select Destination" to choose the folder for saving processed videos.

3. **Optional - Scan Destination**: Click "Scan Destination" to check for existing files in the destination folder.

4. **Optional - Check GPU**: Click "Check GPU" to check GPU compatibility for hardware acceleration.

5. **Start Process**: Click "Start Process" to begin removing audio from all videos. You can see progress in the progress bar and stats below.

6. **Monitor Progress**: The left table shows source files with status, the right table shows destination files with status. Stats show total, success, failed, etc.

## Main Buttons

- **Load from Database**: Get all videos from the application database.
- **Select Source**: Choose a folder containing videos to process.
- **Select Destination**: Choose a folder to save processed videos.
- **Scan Destination**: Scan destination folder to check for existing files.
- **Check GPU**: Check if GPU supports acceleration.
- **Clear All**: Reset tool and clear all data.

## File Tables

- **Source Files**: List of videos to be processed with their status.
- **Destination Files**: List of processed videos with their status.

## Stats and Progress

- **Total**: Total number of videos.
- **Success**: Videos processed successfully.
- **Failed**: Videos that failed processing.
- **Stopped**: Videos that were stopped.
- **Remaining**: Videos not yet processed.
- **Progress**: Progress percentage.
- **Elapsed**: Time elapsed.
- **ETA**: Estimated time to completion.
- **Speed**: Processing speed (files per second).

The tool will save audio-less videos to the destination folder with the same filenames. Ensure the destination folder has enough storage space.
