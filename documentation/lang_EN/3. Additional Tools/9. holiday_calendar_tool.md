# Microstock Holiday Calendar Tool

The Holiday Calendar tool lets you browse public holidays from countries around the world. It is useful for planning content around upcoming holidays and cultural events relevant to your target microstock markets.

## Getting Started

To use this tool, you need a Calendarific API key. There are two ways to get one:

**Option 1 - Become a Member (Recommended)**
If you are an Image Tea member, your API key is provided automatically by Desainia Studio. You do not need to configure anything. Simply log in as a member and open the tool.

**Option 2 - Use Your Own API Key**
Get a free API key at [calendarific.com](https://calendarific.com/account/dashboard), then paste it in the **Configuration** tab inside the tool.

If no API key is configured, the tool will show a dialog guiding you to either option above when you try to load holidays.

---

## Interface Overview

The dialog is divided into three areas:

- **Left sidebar** - year and month navigation
- **Center panel** - holiday list or calendar view, with a filter bar at the top
- **Right panel** - holiday detail panel (collapsible)

At the bottom there is a collapsible **Logs** panel that shows API requests and cache activity in real time.

The center panel has three tabs:

- **Holidays** - the main view for browsing and filtering holidays
- **Search** - search microstock platforms using holiday keywords
- **Configuration** - API key and cache settings

---

## Sidebar

The sidebar contains the year spinner and a list of months.

- **Year spinner** - change the year to browse holidays from a different year
- **Month list** - click a month to load holidays for that specific month. Each month shows a count badge indicating how many holidays it contains for the current country and year
- Click the same month again or press its button to refresh

---

## Filter Bar

Located at the top of the Holidays tab:

- **Country dropdown** - select the country whose holidays you want to see. The dropdown is populated from the Calendarific countries list after the first API call
- **Search field** - filter the holiday list by name in real time
- **View toggle** - switch between List view and Calendar view
- **Refresh button** - clears the cache for the current selection and re-fetches from the API

---

## Holiday List View

Displays holidays in a scrollable list. Each entry shows:

- Holiday name
- Date and day of week
- Holiday type (national, religious, observance, etc.)
- Country flag and state information if applicable

Click any holiday to open its details in the **Detail Panel** on the right.

---

## Calendar View

Shows the current month in a calendar grid. Days with holidays are highlighted. Click a date to see the holidays that fall on it in the Detail Panel.

---

## Detail Panel

Appears on the right side when you select a holiday. It shows:

- Full holiday name
- Date, day, and type
- Description
- States or regions where the holiday applies (if applicable)
- A **Search on Platform** button that takes the holiday name to the Search tab for microstock keyword research

---

## Search Tab

Used to research the selected holiday on microstock platforms. The holiday name is pre-filled as the keyword. Switch between available platforms using the tab buttons at the top.

---

## Configuration Tab

Manage your API key and cache settings here.

- **API Key** - paste your Calendarific API key. The eye button toggles visibility. If you are logged in as a member with a configured key, this field is disabled and a notice is shown instead
- **Base URL** - the Calendarific API endpoint. Leave as default unless you know what you are doing
- **Default Country** - the country loaded by default when the tool opens (e.g. `US`, `ID`, `WORLD`)
- **Cache Expiry** - how many days cached holiday data is kept before it is re-fetched from the API (default: 30 days)
- **Use SQLite cache** - keeps all fetched holiday data saved locally so it does not need to be re-fetched every time the tool opens. Recommended to keep this enabled to save API credits
- **Clear All Cache** - deletes all locally stored holiday data. Use this if data looks outdated
- **Save Configuration** - saves all settings above

---

## WORLD View

Selecting **WORLD** as the country fetches holidays from a set of major countries simultaneously and merges the results into one list. Because Calendarific charges per country per request, the WORLD view makes multiple API calls at once (one per country). Results are cached for 30 days by default, so subsequent views cost no additional API credits.

---

## Logs Panel

The collapsible panel at the bottom of the dialog shows real-time log entries:

- **INFO** - general activity
- **API** - outgoing API requests
- **CACHE** - hits and stores from the local cache
- **SUCCESS** - successful fetches
- **WARNING** - non-critical issues
- **ERROR** - failed requests or missing configuration

Click the **Logs** label to expand or collapse the panel.
