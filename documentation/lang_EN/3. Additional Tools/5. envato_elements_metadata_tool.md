# Envato Mockup Metadata Generator

This tool generates Envato Elements mockup metadata and can send the metadata and content files to the connected Envato browser extension.

## Requirements

- A valid Gemini API key configured in Image Tea.
- The Envato Elements browser extension installed and connected.
- An open Envato item submission page.
- A content source folder containing at least one PSD, one preview image (`.png`, `.jpg`, or `.jpeg`), and one cover image whose filename ends with `_cover`.
- A PDF guide file.

## Generate Metadata

1. Open the tool from Image Tea and select a valid Gemini API key in **Configuration**.
2. Load the mockup cover or source image by dragging it to the image area, clicking **Open**, or clicking **Paste**.
3. Click **Process Image** to generate metadata.
4. Review and edit the generated fields:
   - **Title**: 30-100 characters.
   - **Tagline**: Up to 100 characters.
   - **DPI, Width, Height**: Technical specifications.
   - **Tags**: Keywords, normally 15 tags.
   - **Items**: Number of mockup items.
   - **Description**: Full listing description.

## Prepare Content Files

1. Open the **Content Files** tab.
2. Drop or browse to the source folder.
3. Drop or browse to the PDF guide.
4. Check the four readiness indicators: **PSD**, **Preview**, **Cover**, and **PDF**.
5. Click **Process Files**. The tool creates `Main File.zip` in the source folder. If the archive already exists and all files are ready, it is not recreated.

The cover is detected recursively from an image filename ending in `_cover`, for example `1_cover.png`. Preview images are image files that do not use the `_cover` suffix.

## Send to Envato

1. Open the Envato item submission page in the browser and connect the extension.
2. Keep the Envato page active while sending files.
3. Return to Image Tea and verify that **Send Files** is enabled. The button remains disabled until the extension is connected and all four Content Files statuses are ready.
4. Click **Send Files** once.
5. The extension fills the metadata, selects `RGB` and `px`, and uploads the detected cover.
6. Preview images are uploaded one at a time. The extension waits until each preview appears in the Envato preview list and has finished loading before uploading the next one.
7. After all previews are ready, the extension shows a visible countdown before selecting `Main File.zip` through the ZIP file input.

Do not click **Send Files** again while the extension log is active. The upload order is intentional because Envato may fail when previews and the main ZIP are uploaded concurrently.

## Preview and JSON

- The **Results** panel shows the rendered listing without the source image.
- Markdown in the description is rendered as headings, paragraphs, lists, and notes.
- Use **Copy JSON Metadata** to copy `title`, `tagline`, `description`, and `tags` when browser automation is not needed.

## Troubleshooting

- If **Send Files** is disabled, complete the PSD, Preview, Cover, and PDF statuses and connect the extension.
- If the extension does not receive commands, open the extension side panel, click **Connect**, and keep the Envato submission tab active.
- If the browser extension was updated, reload it from the browser extensions page before trying again.
- Do not start another send while previews are still being uploaded. Wait for the countdown and ZIP selection log to finish.

## Additional Options

- **Always on Top** keeps the dialog above other windows.
- **Settings** changes configuration limits and defaults.
