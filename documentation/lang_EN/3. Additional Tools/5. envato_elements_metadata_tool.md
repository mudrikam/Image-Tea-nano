# Envato Elements Metadata Tool

This tool helps you automatically generate metadata for Envato Elements mockups. You can upload mockup images and the tool will generate titles, taglines, tags, and descriptions that meet Envato Elements standards.

## How to Use

1. **Select API Key**: In the API Configuration section, select a valid Gemini API key from the dropdown.

2. **Load Image**:
   - Drag & drop the mockup image to the "Drag & Drop Image Here" area.
   - Or click "Open" to select an image file.
   - Or click "Paste" to paste an image from clipboard.

3. **Process Image**: Click "Process Image" to start generating metadata. The tool will analyze the image using AI and automatically fill in the metadata fields.

4. **Edit Metadata**: Adjust the generated results in the following fields:
   - **Title**: Mockup title (30-100 characters).
   - **Tagline**: Short description (max 100 characters).
   - **DPI, Width, Height**: Technical image specifications.
   - **Tags**: Keywords (must be 15 tags).
   - **Items**: Number of items in the mockup.
   - **Description**: Full description.

5. **Copy Metadata**: Click the copy icon next to each field to copy to clipboard.

## Additional Options

- **Always on Top**: Check to keep the dialog above other windows.
- **Settings**: Click to change configuration limits and defaults.

## Status and Progress

- **Progress Bar**: Shows image processing progress.
- **Status Label**: Provides information about current status (Ready, Processing, etc.).

The tool uses AI to analyze images and generate relevant metadata. Ensure mockup images are high quality for best results.
