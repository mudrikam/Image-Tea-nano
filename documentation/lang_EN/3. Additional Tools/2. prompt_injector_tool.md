# Prompt Injector Tool

This tool helps you automate the process of repeatedly entering prompts into other applications. You can set up click points on the screen and sequence actions for pasting prompts, clicking buttons, and refreshing automatically.

## How to Use

1. **Set Up Click Points**: The tool will display 5 colored points on the screen. Drag these points to the correct positions in the target application:
   - **Point 1 (red)**: Location for pasting prompts (click, select all, paste).
   - **Point 2 (green)**: Location to click for submit or confirm.
   - **Point 3 (blue)**: Location to click for download or final action.
   - **Point 4 (orange)**: Optional extra action.
   - **Point 5 (magenta)**: Location to click for refresh, executed every N prompts.

2. **Set Delays**: Configure delay for each point in seconds. This is the wait time before the action at that point. You can also add random extra delay for variation.

3. **Load Data**: Click "Load CSV/TXT" to load prompt files from CSV or TXT, or "Load Prompt" to get prompts from the previously generated database.

4. **Run Automation**: Click "Run Action" to start. The tool will click points in sequence, paste prompts, and wait for set delays. Progress is shown in the progress bar.

5. **Control During Run**: Use "Pause" for temporary pause, "Stop" to stop completely, or "Reset Points" to reset point positions.

## Point Explanations

- **Point 1**: Move cursor here, click, do Ctrl+A, set clipboard to current prompt, then Ctrl+V to paste.
- **Point 2**: Move cursor here and click, typically used to confirm or advance the UI.
- **Point 3**: Move cursor here and click, often used for final actions like Download.
- **Point 4**: Extra action after Point 3.
- **Point 5**: Refresh trigger. Every N prompts, cursor moves here, clicks, waits for delay, then continues. Other points pause during refresh.

## Delay Options

- **Delay per Point**: Wait time before action at that point.
- **Random Extra Delay**: Additional random delay (0 to disable).
- **Trigger Point 5 Every**: How many prompts before Point 5 is triggered.

## Load Data

- **Load CSV/TXT**: Load files. TXT: each non-empty line becomes one prompt.
- **Load Prompt**: Get prompts from database.
- **Clear**: Remove loaded data.

## Progress and Status

- **Progress Bar**: Shows processed prompts vs total.
- **Label**: Shows current file and prompt position within file.
- **Countdown**: Shows wait time before next action.

The tool stays on top of other windows and can be dragged. Make sure the target application doesn't change position during automation.
