# Prompt Injector v2

**Prompt Injector v2** automates repetitive copy-paste and keyboard workflows across any application. You configure a list of *points* (screen positions), each with an assigned action type, and the tool executes them in sequence for every prompt you load.

---

## Quick Start

1. Click **Add New Point** to create your first point.
2. Fill in the name, type, icon, color, size, and delay, then click **OK**.
3. A colored circle marker appears on screen. Drag it to the target location in your other application.
4. Repeat for as many points as you need.
5. Load your prompts via **Load CSV/TXT** or **Load Prompt** (database).
6. Click **Run Action**.

---

## Points

Each point represents one step in the automation sequence. Points are saved to the database, so your configuration persists between sessions.

### Point Fields

| Field | Description |
|---|---|
| Name | A label for this point (e.g. "Paste Prompt", "Confirm Button"). |
| Type | The action to perform at this location (see *Point Types* below). |
| Icon | Visual icon shown on the screen marker. Chosen via the icon picker. |
| Color | Color of the screen marker and its tinted row in the list. |
| Size | Diameter of the screen marker in pixels (16–96 px). |
| Delay | Seconds to wait *before* executing this point's action. For **monitor** type, this is the maximum wait time. |
| Shortcut | Only shown for **key_action** type. The keyboard combination to fire, e.g. `ctrl+enter` or `ctrl+shift+z`. |
| Enabled | Uncheck to skip this point without deleting it. |

### Point Types

| Type | Behavior |
|---|---|
| **paste** | Moves the cursor to the point, clicks, selects all (Ctrl+A), then pastes the current prompt text (Ctrl+V). |
| **key_action** | Moves the cursor to the point, then executes the stored keyboard shortcut. |
| **move** | Moves the cursor to the point without clicking. |
| **click** | Moves the cursor to the point and performs a left-click. |
| **monitor** | Samples the pixel color at the point and waits until it changes before continuing. The **Delay** field sets the maximum wait time in seconds. |

---

## Positioning Markers

- Each enabled point displays a semi-transparent circle on your screen.
- **Drag** the circle to the exact target location. The icon switches to a crosshair while you drag.
- Position is saved to the database automatically when you release the mouse.
- Use **Reset Points** to move all markers back to the center of the primary screen.

---

## Enabling / Disabling Points

Toggle the checkbox on any point row to enable or disable it. Disabled points are hidden from the screen and skipped during automation. The change is saved to the database immediately.

---

## Loading Prompts

### Load CSV/TXT

Supports `.csv` and `.txt` files. TXT files: one prompt per non-empty line. You can load multiple files; their contents are concatenated in order.

You can also **drag and drop** CSV/TXT files directly onto the Prompt Injector v2 window.

### Load Prompt (Database)

Loads all prompts from the Image Tea database that have not yet been marked as copied.

---

## Run Controls

| Button | Action |
|---|---|
| **Run Action** | Starts automation. All enabled points execute in order for each loaded prompt. |
| **Pause** / **Resume** | Pauses or resumes the automation. Pressing **Esc** on your keyboard also toggles pause. |
| **Stop** | Stops automation immediately. |
| **Reset Points** | Moves all point markers to the center of the primary screen. |

---

## Random Extra Delay

The **Random extra delay (s)** field adds a random additional wait time on top of each point's base delay. Set to `0` to disable. This is useful for making automation look more natural and avoiding rate limits.

---

## Progress & Statistics

- The progress bar shows `completed / total` prompts.
- Statistics update every second: ETA, remaining time, elapsed time, progress percentage, and speed (prompts per minute).

---

## Settings

The following are saved automatically:

- Random extra delay value
- Last loaded CSV/TXT file paths (reloaded on next open if files still exist)

Point positions, delays, icons, types, and enabled state are all stored in the database.

---

## Notes

- Automation uses `pyautogui` for mouse/keyboard control. Ensure your target application is visible and accessible.
- Moving your mouse to the top-left corner of the screen triggers `pyautogui`'s fail-safe and stops automation.
- On macOS, screen recording permission may be required for `pyautogui` to work.
- The **monitor** point type requires the target pixel to be visible on screen when automation starts to capture the initial color.
