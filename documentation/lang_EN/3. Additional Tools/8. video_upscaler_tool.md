# Video Upscaler Tool

This tool helps you enhance video resolution using RealESRGAN. Videos are processed frame by frame for best results, then merged back into video format.

## How to Use

1. **Load Videos**: Choose the source videos to upscale.
   - Click "Load Database" to load all videos from the application database.
   - Click "Load Folder" to choose a folder containing videos.
   - Click "Load File" to select a single video.

2. **Configure Settings**:
   - **Model**: Select the AI model to use for upscaling.
   - **Scale**: Choose the magnification factor (2x, 3x, or 4x).
   - **Batch**: Set the number of frames processed simultaneously (higher = faster but needs more RAM).
   - **Encoder**: Choose video encoder for merging (CPU or GPU).
   - **Decoder**: Choose hardware acceleration for frame extraction.

3. **Set Output Folder**: Click the folder icon to select where to save upscaled results. If empty, results will be saved to the default folder.

4. **Run Upscaling**: Click the "RUN UPSCALE" button to start the process. The tool will extract frames, upscale each frame, then merge them back.

## Main Features

### Load and Manage Videos
- **Load Database**: Load all videos from the Image-Tea database.
- **Load Folder**: Choose a folder to load all videos within it.
- **Load File**: Add a single video to the list.
- **Clear**: Remove all videos from the list.

### Output Settings
- **Output Folder**: Specify folder to save results.
- **Browse**: Browse and select output folder.
- **Paste**: Paste folder path from clipboard.
- **Clear**: Clear output folder path.

### Encoder and Decoder
- **Encoder**: Choose hardware encoder for video output (NVIDIA NVENC, AMD AMF, Intel QSV, or CPU).
- **Decoder**: Choose hardware acceleration for frame extraction (CUDA, QSV, DirectX, or CPU).

### Model Manager
- Open the Model Manager with the **gear icon** next to the Model selector. It lists all available upscaling models and provides controls to add, edit, delete, export, and refresh models.
- Add / Import: Click **Add** or **Import** to open a dialog. You must provide a name, choose the type (NCNN / PTH / ONNX), set the scale (2x/3x/4x), optionally add a description, and select the required model files. NCNN uses a pair of files (parameters and weights); PTH and ONNX use a single model file. The dialog validates inputs before importing; successful imports copy the files into the app’s models folder and register the model for immediate use.
- Edit: Choose a model and click **Edit** to change editable properties (for example, scale and description). The dialog does not let you rename the model or change its type/files when editing an existing entry.
- Delete: Choose **Delete** and confirm; you will be asked whether to also delete the stored model files. Confirming removes the files as well as the model entry.
- Export: Select **Export** to copy a model out to a folder you choose.
- Refresh & Folder: Use **Refresh** to rescan models and update the list. **Open Models Folder** opens the folder used to store models in your file manager.
- Runtime dependencies: The manager shows whether PTH and ONNX runtime support are installed and offers install/uninstall actions. If you run the upscaler with a PTH/ONNX model and required runtimes are missing, the upscaler will prompt you and can run the installer before continuing.

## Upscaling Process

The tool works in 3 phases:

1. **PHASE 1: Extract Frames** - Extracts all video frames into PNG images.
2. **PHASE 2: Upscale Frames** - Processes each frame using RealESRGAN.
3. **PHASE 3: Merge to Video** - Combines upscaled frames back into video.

## Status and Progress

- **Files**: Shows the number of loaded videos.
- **Frames**: Shows frame processing progress (processed/total).
- **Elapsed**: Time elapsed since start.
- **ETA**: Estimated time to completion.
- **Remaining**: Number of frames still to process.
- **Status**: Current process status (Idle/Running).

## Logs and Monitoring

- **Process Logs**: Shows details of each process phase, errors, and important information.
- **Progress Bar**: Indicates overall completion percentage.
- **Status Icons**: Check icon (green) for success, X icon (red) for failure.

## Process Controls

- **RUN UPSCALE**: Start the video upscaling process.
- **STOP**: Stop the currently running process.

## Usage Tips

- Video upscaling takes a long time as it processes frame by frame.
- Ensure sufficient storage space for temporary frames.
- Use GPU encoder if available for faster merging.
- Hardware acceleration decoder speeds up frame extraction.
- Higher batch size speeds up processing but requires more VRAM.

The tool will automatically clean up temporary files after completion. Ensure FFmpeg and RealESRGAN are properly installed for optimal results.
