# Prompted Image Sorter Tool

This tool automatically sorts images into folders based on AI classification of how well each image matches your defined prompt criteria.

## How It Works

1. **Source Selection**: Select a folder containing images to be sorted
2. **Prompt Definition**: Define criteria in natural language (e.g., "images with people", "nature scenes", "blue colors")
3. **AI Classification**: The tool analyzes each image and classifies it as "Match" or "No Match" based on your prompt
4. **Auto-Sorting**: Images that match are moved to a subfolder, non-matching images stay in the original location

## How to Use

1. **Select Source Folder**: Click "Browse" to choose the folder containing images to sort

2. **Enter Prompt**: Type your sorting criteria in the prompt field. Examples:
   - "Images containing people or faces"
   - "Nature landscapes with trees"
   - "Images with blue sky"
   - "Product photos on white background"

3. **Output Folder**: Choose where to save matching images (defaults to a subfolder named after your prompt)

4. **Start Sorting**: Click "Run Sorter" to begin the sorting process

## Interface Elements

- **Source Folder**: Folder containing images to analyze
- **Prompt**: Your classification criteria in natural language
- **Output Folder**: Where matching images will be moved
- **Results Table**: Shows each image with its match status (Match/No Match)
- **Progress Bar**: Shows sorting progress

## Additional Options

- **Create New Folder**: Click the folder+ icon to create a new subfolder in your output location
- **Open Output**: Opens the output folder after sorting completes
- **Retry Failed**: Re-attempts classification for images that failed

## Notes

- Requires member login to use
- Images that match your prompt are moved to the output folder
- Images that don't match remain in the source folder
- The tool preserves the original filename when moving images
