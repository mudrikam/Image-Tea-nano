# Image Overlay Maker Tool

This tool applies PNG overlay images to multiple base images in batch, perfect for adding watermarks, textures, or design elements to your image collections.

## How It Works

1. **Source Selection**: Choose a folder of images or select individual image files
2. **Overlay Selection**: Select a PNG overlay image with transparency
3. **Output Folder**: Choose where to save the processed images
4. **Batch Processing**: The tool applies the overlay to all selected images automatically

## How to Use

### Step 1: Select Source Images
- Click **Browse** next to Source to select a folder, or
- Click **Files** to select individual images
- You can also drag and drop folders or files onto the input fields

### Step 2: Select Overlay Image
- Click **Browse** next to Overlay to select a PNG file with transparency
- The overlay will be resized to match each base image's dimensions

### Step 3: Choose Output Location
- The output folder is auto-generated as a subfolder named "OVERLAY_OUTPUT"
- You can customize this by clicking **Browse** next to Output

### Step 4: Process Images
- Click **Process Images** to start the batch operation
- A progress bar shows the current status
- When complete, you can choose to open the output folder

## Interface Elements

- **Source Input**: Folder path or file count for selected images
- **Overlay Input**: Path to the PNG overlay file
- **Output Input**: Destination folder for processed images
- **File Table**: Lists all loaded images with filename and path
- **Stats Bar**: Shows file count and processing status
- **Process Button**: Starts/pauses the batch processing

## Additional Options

- **Paste Buttons**: Quickly paste paths from clipboard
- **Open Buttons**: Open file locations in your system's file explorer
- **Clear Button**: Remove all files from the list
- **Drag & Drop**: Drop folders or files directly onto input fields

## Notes

- Overlay images should be PNG format with transparency for best results
- The overlay is stretched to match each base image's dimensions
- Processing uses alpha compositing for smooth blending
- Original image filenames are preserved in the output
