# About Image-Tea-nano

Image-Tea-nano is a lightweight, simple, and honest metadata generator application.  
The main focus of this app is ease of use and transparency in the metadata generation process, without unnecessary features.

This application was developed by Studio Desainia to meet the studio's internal needs and is shared openly in hopes that it will benefit many people.

This project is developed using Python with the PySide6 GUI framework and uses `qtawesome` for icons. Other runtime libraries and dependencies are listed in the project's `requirements.txt` file.

- Open source, community-driven, and easy to use.
- Does not store any personal user data.
- All processes run locally on your computer.

## Supported File Extensions

Image Tea supports the following file extensions (these are the common image and video formats supported by Image Tea):

- Images: .jpg, .jpeg, .png, .tiff, .webp, .eps, .svg, .pdf, .psd
- Videos: .mp4, .mpeg, .mov, .avi, .flv, .mpg, .webm, .wmv, .3gp, .3gpp

The UI prompt shown when there are no files is: "Drag and drop images or videos here".

## Supported Tools

Image Tea can make use of additional helper tools bundled in the `tools/` folder when available:

- `exiftool`: used for advanced metadata read/write operations.
- `ghostscript`: used for handling PostScript/PDF conversions and related raster operations.
- `cairo`: used for certain image rendering tasks on Windows builds.

These tools are optional but improve processing and compatibility for vector/document formats and some image workflows.
