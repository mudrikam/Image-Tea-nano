# How to Install Image-Tea-nano

Follow these steps to install Image-Tea-nano on Windows:

1. **Download Git**
   - Go to [https://git-scm.com/download/win](https://git-scm.com/download/win) and download Git for Windows.
   - Run the installer and complete the installation.

2. **Clone the Repository**
   - Open Command Prompt or PowerShell.
   - Navigate to the folder where you want to save the project, for example:  
     `cd D:\Project`  
     or to Desktop:  
     `cd %USERPROFILE%\Desktop`
   - Run:  
     `git clone https://github.com/mudrikam/Image-Tea-nano.git`
   - After cloning, go to the cloned folder:  
     `cd Image-Tea-nano`

## Alternative Installation Methods

### Method 1: Using Installer (Recommended for Beginners)

1. **Download the Installer**
   - Go to the releases page of the installer repository: [https://github.com/mudrikam/Image-Tea-Installer/releases](https://github.com/mudrikam/Image-Tea-Installer/releases)
   - Choose and download the installer that matches your operating system and architecture (e.g., Windows x64, Windows x86, macOS, or Linux). Check the release's "Assets" section to find the appropriate file.

2. **Prepare Installation Folder"
   - Create a new folder, for example "Image Tea", in a location of your choice (preferably not on drive C: to avoid potential permission issues in the future, e.g., on another drive).
   - Move the downloaded installer file for your platform to this folder (for example, `Image_Tea_Installer_x64.exe` for Windows x64).

3. **Run the Installer**
   - Double-click the downloaded installer file for your platform in the "Image Tea" folder (on Windows this will be a .exe file).
   - Follow the installation wizard to complete the setup.

4. **Run the Application**
   - Open the folder where you ran the installer (for example, the "Image Tea" folder).
   - Find `Image Tea.exe` and double-click it to run the application.
   - (Optional) Right-click `Image Tea.exe` → Send to → Desktop to create a shortcut for easier access.
   - Note: The app runs from the folder where the installer was placed — it does not install itself into the system Start Menu.

### Method 2: Download ZIP

1. **Download the ZIP File**
   - Go to the GitHub repository: [https://github.com/mudrikam/Image-Tea-nano](https://github.com/mudrikam/Image-Tea-nano)
   - Click the green **Code** button.
   - Select **Download ZIP**.

2. **Extract the ZIP**
   - Extract the downloaded ZIP file to a folder of your choice.

3. **Run the Application**

![Run Image Tea](res/images/image_tea_exe.png)

   - Navigate to the extracted folder.
   - Double-click **Image Tea.exe** to start the application.
   - The application will automatically download and install all required dependencies on first run.

4. **Done**
   - After the process is complete, the application is ready to use.
   - If you encounter any issues, make sure your internet connection is stable.

**Important — Internet connection required & retry instructions:**
- **Internet required:** The installer and the application need an active, stable internet connection because they download important runtime dependencies on first run. If the download of dependencies fails or is interrupted, the application will not run correctly.
- **Ensure stability:** Use a reliable network (avoid mobile hotspots with unstable signal). Pause other heavy downloads during installation to reduce the chance of failures.
- **If installation fails:** Close the installer, then fully remove the installation folder (the folder named `Image Tea` where you ran the installer). After the folder is cleaned, run the installer again from the beginning. You must repeat the install process from the start — do not try to resume a partially failed install.
- **Why retry fully:** Partial installs can leave incomplete dependencies; starting with a clean `Image Tea` folder ensures the installer can download and install all required files afresh.

**Notes:**
- You do not need to install Python or any libraries manually; just run Image Tea.exe.
- To update the application, use the in‑app Update function (toolbar or **Help** menu). If an update fails, see the Update and Troubleshooting pages for retry steps.
