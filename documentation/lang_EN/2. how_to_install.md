
# How to Install Image-Tea-nano (All Operating Systems)

Follow these steps to install and run Image-Tea-nano on Windows, Linux, or macOS:

## 1. Download Git (optional, for cloning repo)
- Go to [https://git-scm.com/downloads](https://git-scm.com/downloads) and download Git for your operating system.
- Install Git following the instructions on the website.

## 2. Get Image-Tea-nano

You can choose one of the following methods:

### Method A: Clone the Repository (for intermediate/advanced users)
1. Open your terminal (Command Prompt/PowerShell on Windows, Terminal on Linux/macOS).
2. Navigate to your target folder, for example:
   - Windows: `cd D:\Project` or `cd %USERPROFILE%\Desktop`
   - Linux/macOS: `cd ~/Project` or `cd ~/Desktop`
3. Run:
   `git clone https://github.com/mudrikam/Image-Tea-nano.git`
4. Enter the cloned folder:
   `cd Image-Tea-nano`

### Method B: Download ZIP/Installer/Portable (Recommended for all users)
1. Go to [https://github.com/mudrikam/Image-Tea-nano](https://github.com/mudrikam/Image-Tea-nano) or the installer releases page: [https://github.com/mudrikam/Image-Tea-Installer/releases](https://github.com/mudrikam/Image-Tea-Installer/releases)
2. Choose and download the ZIP, installer, or portable file that matches your operating system (Windows, Linux, or macOS). Check the release's *Assets* section for the correct file.
3. Extract the ZIP file (or run the installer/portable) to a folder of your choice (for Windows, avoid drive C:; for Linux/macOS, use your home directory or another folder you have write access to).

## 3. Run the Application

### Windows
- Open the extracted or installed folder.
- Run `Launcher.bat` by double-clicking it, or from Command Prompt:
  `Launcher.bat`

### Linux/macOS
- Open a terminal and navigate to the extracted/installed folder:
  `cd /path/to/Image-Tea-nano`
- Make sure `Launcher.sh` is executable. If not, run:
  `chmod +x Launcher.sh`
- Start the application with:
  `./Launcher.sh`

### Important Notes
- On first run, the application will automatically download and install required dependencies (make sure your internet connection is stable).
- If installation/dependency setup fails, delete the entire installation folder and repeat the process from scratch with a new folder.
- You do not need to install Python or any libraries manually.
- To update the application, use the Update feature in the app menu. If the update fails, repeat the installation process from scratch.

## Troubleshooting & Help
- Make sure your internet connection is stable during installation and first use.
- If you encounter issues, delete the installation folder and repeat the process from scratch.
- For help, join the Desainia Group community: [Desainia Group](https://chat.whatsapp.com/CMQvDxpCfP647kBBA6dRn3)

This guide applies to Windows, Linux, and macOS.
