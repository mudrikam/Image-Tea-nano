# How to Update Image-Tea-nano

![Update Image Tea](res/images/update_app_toolbar.png)

To update Image-Tea-nano to the latest version, follow these steps:

1. **Open the Application**
   - Start Image Tea.exe as usual.

2. **Check for Update Notification**
   - If an update is available, a notification will appear in the application's statusbar.
   - You can also select the **Update** option from the toolbar or from the **Help** menu in the menu bar.

3. **Perform the Update**
   - Click the update notification in the statusbar, or choose the **Update** menu option.
   - Follow the instructions shown in the application to complete the update process.

When a new release is available the app automatically checks the repository and shows a brief notification in the bottom-right corner for quick updates. You can press `Update Now` directly from that notification to start a quick update.

To view full release details and options open the Update Notice dialog. The dialog typically appears automatically after the check completes, or can be opened from **Help → Version**. The dialog includes:

 - The latest release label (for example: "Latest: v1.0.31").
 - The current installed version.
 - A "Checked at" timestamp showing when the app last polled for updates.
 - A Release notes area showing the changelog for the release.
 - Action buttons: `Update Now` to download and install the update immediately, `Remind Me Later` to postpone the reminder, and a `Skip this version` option to ignore that particular release.
 - Extra links/buttons such as `Found a Bug` and `Community` to report issues or open community resources.

Example Update Notice dialog:

![Update Notice](res/images/update_app_notice.png)

In the Update Notice dialog, click `Update Now` to begin the automatic update sequence (the updater will be downloaded/executed). `Remind Me Later` postpones the notification according to the app's reminder settings. `Skip this version` silences notices for the specific release until a new one appears.

### Manual update (using Updater executable)

- You can also update the app manually by running `Image Tea Updater.exe`.
- Locate `Image Tea Updater.exe` in the same folder where `Image Tea.exe` or the installer is located.
- Double-click `Image Tea Updater.exe` and follow the on-screen prompts to download and install the latest version.
- If you run into permission issues, right-click the updater and choose **Run as administrator**.

   ![Updater executable](res/images/image_tea_updater_exe.png)

4. **Wait for the Process to Finish**
   - The application will automatically download and install the update.
   - Once finished, the application will be ready to use with the latest version.

**Important Notes:**
- Backup your API key and important data before updating if needed.
- If the update fails, make sure your internet connection is stable.
- For help, ask in the community WhatsApp group.

This guide is for Windows only. For other operating systems, please ask in the WhatsApp community group.
