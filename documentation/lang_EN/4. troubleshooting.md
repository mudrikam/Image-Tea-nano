 # Troubleshooting — Image-Tea-nano

 This page lists common problems and suggested solutions. If a step requires deleting files or changing permissions, follow instructions carefully.

 ## Common Issues & Fixes

 1. Image Tea does not start after running the installer / app hangs on startup
    - Possible cause: some required dependency failed to install completely.
    - Solution: Close the app. In the folder where you placed or ran the installer, delete all files and folders except the installer file you downloaded for your platform.
      Re-run the installer you downloaded (on Windows, double-click the .exe file) to attempt reinstalling missing dependencies.
    - If the installer still fails, try running the installer as administrator (right-click → "Run as administrator"). If the app fails to update, use the in‑app Update option (toolbar or **Help** menu) to retry; restart the app and try again, or run the app as administrator. If problems persist, open an issue on the GitHub repo and include logs and the steps you tried.

 2. Update fails or updater does nothing
    - Solution: Use the in‑app Update option (toolbar or **Help** menu) to retry the update. If that doesn't work, restart the application and try again; if permission errors occur, run the app as administrator and retry. If updates still fail, open an issue on the GitHub repository and include the error message or logs and the steps you already tried.

 3. App shows errors about missing Python packages
    - Solution: Check `requirements.txt` in the project root for the required packages. If you installed manually, install missing packages using pip in the Python environment the app uses.

 4. Antivirus or Windows Defender blocks the app or installer
    - Solution: Temporarily allow or whitelist the installer and `Image Tea.exe` in your antivirus program. Re-run the installer.

 5. Slow startup or long dependency download
    - Solution: Ensure you have a stable internet connection. Large model files or dependencies may take time to download on first run.

 6. Other errors / logs
    - Solution: If the app shows an error dialog, note the exact message and search the project documentation or open an issue on the GitHub repo with the error text. Include screenshots if possible.

 ## When to ask for help
 - If the steps above do not fix the problem, open an issue on the GitHub repository and include:
   - The operating system details (Windows version)
   - The exact error message or a screenshot
   - Steps you already tried (for example: re-run installer, run as admin, whitelist in antivirus)

 These troubleshooting steps are intended to help most users recover from common setup issues. Use caution when deleting files and always keep a copy of important data such as API keys.
