# Customizing the Prompt

Image‑Tea‑nano lets you edit the prompt templates used when generating metadata. The editor is tabbed so you can define rules and guidance separately for titles, descriptions, keywords, and more.

![Edit Prompt](res/images/edit_prompts.png)

How to use the prompt editor:

1. Open the editor from the main menu (**Edit Prompt**) or via the toolbar (**Prompt**). The `Edit Prompt` dialog contains these tabs: **Title**, **Description**, **Keywords**, **General Guides**, **Strict Don'ts**, and **Negative Prompt**.

	![Edit Prompt](res/images/prompt_editor.png)

2. Enter the requirements or template text in the appropriate tab. The editor fields are plain text and support line breaks for structured instructions.

3. Use **Title** to define title requirements (clarity, required elements, length constraints); **Description** for description rules; **Keywords** for keyword-related rules and counts.

4. **General Guides** and **Strict Don'ts** let you add broader guidance and absolute restrictions the AI should follow. Use **Negative Prompt** to specify content to avoid.

5. Click **Save** to persist changes to `configs/ai_config.json`. Click **Cancel** to discard edits.


Prompt Placeholders
The editor supports placeholders that are substituted automatically when generating metadata:

- `_MIN_LEN_`: Minimum title length
- `_MAX_LEN_`: Maximum title length
- `_MAX_DESC_LEN_`: Maximum description length
- `_TAGS_COUNT_`: Required number of tags
- `_TIMESTAMP_`: Unique timestamp for each request
- `_TOKEN_`: Unique token for each request

Notes:

- Edited prompts are saved to the application's config file and will be used by the metadata generator.
- Write clear, concise instructions in the **Title** and **Description** tabs (the dialog shows an example of title requirements in the UI).
- Fields are stored as plain text—avoid adding formatting markup.

Customizing prompts gives you direct control over the style, length, and structure of generated metadata so the AI output better matches your needs.

## Custom Prompt (per-request rules)

![Edit Prompt](res/images/custom_prompt.png)
- Access: open **Prompt → Custom Prompt** from the main menu, or click the **Custom Prompt** button on the toolbar.
- Purpose: use the Custom Prompt when you want to add temporary or request-specific instructions for the model without editing the main prompt templates.
- Behavior: enter the special rules in the textbox and click **Save**. The value is persisted to `configs/ai_config.json` under `prompt.custom_prompt`.
- Effect: when set, the AI helpers include the custom prompt as a mandatory instruction for generation; it augments the templates but does not replace or modify them.
- To remove or stop using the custom rules, clear the textbox and save (or leave unchanged by clicking **Cancel**).
