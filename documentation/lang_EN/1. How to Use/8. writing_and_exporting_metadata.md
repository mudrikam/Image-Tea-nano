# Writing and Exporting Metadata

You can write metadata to your images or videos, or export metadata to CSV files for microstock platforms in Image-Tea-nano.

There are several ways to access these features:

![Write and Export Toolbar](res/images/writing_metadata_menu.png)

- Use the **Metadata** menu and select **Write Metadata to Images**, **Write Metadata to Videos**, or **Export Metadata to CSV**.
- Use the toolbar buttons: 

![Write and Export Toolbar](res/images/writing_metadata.png)

To write metadata:
- Choose **Write Metadata to Images** to save metadata into your image files.
- Choose **Write Metadata to Videos** to save metadata into your video files.
- The metadata will be written directly to the original files.
- Writing uses a chunking system (batch processing) to prevent crashes when handling large numbers of files.

To configure chunk size:
- Select **Chunk Size Settings** from the Metadata menu to open the settings dialog.
- Chunk size determines how many files are processed in each batch.
- Smaller chunks (10-20): More stable, less memory usage, slower overall.
- Medium chunks (30-50): Balanced performance and stability (recommended).
- Larger chunks (60-100): Faster processing, more memory usage.

To export metadata to CSV:

![Write and Export Toolbar](res/images/writing_metadata_csv.png)

1. Click **Export Metadata to CSV** from the menu or toolbar to open the export dialog.

2. Use the checkboxes to select the platforms you want to export. The `Check All` / `Uncheck All` buttons make bulk selection easy.

3. Each selected platform shows a base filename field you can edit. The base name will receive an index suffix and extension (for example `_001.CSV`).

	- The default base name is generated automatically, for example `Freepik_Image_Tea_Metadata_2025_December_12_` (platform + `Image_Tea_Metadata` + current date).
	- The `_001.CSV` suffix is shown next to the field and indicates the output filename format.
	- Avoid illegal filename characters: `/\\:*?"<>|`.

4. Choose the output folder by pasting a path (Paste button) or clicking `Select Output` to pick a directory.

5. Use the `Open folder on export` checkbox if you want the output folder to open automatically after export finishes.

6. The **Export** button becomes enabled only when:

	- At least one platform is selected,
	- The output path is valid and accessible,
	- All base filenames are non-empty and do not contain illegal characters.

7. A progress dialog appears during export. One CSV file is generated per selected platform containing the metadata formatted for that platform.

8. When complete, the CSV files are saved to the chosen output folder. You may rename files manually afterward if desired.

Notes:

- Platform selection is persisted in the config and will be reloaded the next time you open the dialog.
- Export uses metadata currently stored in the application's database (all indexed files). Export time depends on the number of files.

This dialog provides controlled CSV export for preparing metadata uploads to multiple microstock platforms, with filename preview, validation, and output options.
