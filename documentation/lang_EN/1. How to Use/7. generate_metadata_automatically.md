# Generating Metadata Automatically

To generate metadata automatically for imported files in Image-Tea-nano, make sure you have already added your API key.

Follow these steps:

![Generate Metadata](generate_metadata_button.png)

1. Click the **Generate Metadata** button.  
   The button will change to **Stop Processes**, indicating that Image-Tea-nano is working and sending your files to the API for analysis.  
   Note: Image-Tea-nano does not generate metadata locally; all processing is done via the API.

2. While processing, items in the main table will turn **yellow** to indicate they are being processed.  
   Once finished, successful items will turn **green**.  
   If generation fails, the item will turn **red**.  
   Don't worry if some files fail during the process—you can retry generating metadata for failed files after the process completes.

3. Above the **Generate Metadata** button, there is a dropdown with options:  
   - **Generate All**: Generate metadata for **all files** in the table, without exception. This is useful when you want to process your entire imported collection for the first time.
   - **Failed Only**: Generate metadata **only for files that previously failed** during the last generation process. This mode helps you quickly retry only problematic files without reprocessing successful ones.
   - **Selected Only**: Generate metadata **only for the files you have selected** in the table. This is ideal if you want to process specific files, for example, for testing or special needs.
   - **Draft Only**: Generate metadata **starting from the first file with draft status** and continue for the rest. This is useful if you want to process files that have never had metadata generated (status draft), without repeating files that already succeeded or failed.
   - **Resume Stopped**: Generate metadata **starting from the first file with stopped status**. This is helpful if you previously stopped the generation process, so you can resume from where you left off without starting over.
   - **Rolling APIs**: Generate metadata by **automatically trying all available API keys**. If one API key fails (for example, due to quota limits or errors), the system will automatically switch to the next available API key and continue the process. This feature is useful if you have multiple API keys and want to ensure the generation process continues even if one key encounters a problem.
   
   Use these options to efficiently retry or target specific files, including failed, draft, or stopped files, or to continue a previously interrupted process.

After the process is complete, the generated metadata is saved only in the Image-Tea-nano database.  
It is **not yet written to the original files**—so if you clear or reset the database, the metadata will be lost.  
To permanently save metadata to your files, use the write metadata feature.
