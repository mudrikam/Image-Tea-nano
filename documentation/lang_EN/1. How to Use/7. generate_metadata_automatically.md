# Generating Metadata Automatically

To generate metadata automatically for imported files in Image-Tea-nano, make sure you have already added your API key.

Follow these steps:

![Generate Metadata](generate_metadata_button.png)

1. Click the **Generate Metadata** button. The button will change to **Stop Processes**, indicating that Image-Tea-nano is working and sending your files to the API for analysis. Note: Image-Tea-nano does not generate metadata locally; all processing is done via the API.

2. While processing, items in the main table will turn **yellow** to indicate they are being processed. Once finished, successful items will turn **green**. If generation fails, the item will turn **red**. Don't worry if some files fail during the process—you can retry generating metadata for failed files after the process completes.

3. Above the **Generate Metadata** button, there is a dropdown with options:  

   ![Generate metadata options](res/images/generate_metadata_options.png)

- **Generate All Files**: Generate metadata for all files in the table. Use this when you want to process your entire imported collection.
- **Generate Selected Only**: Generate metadata only for the files you have selected in the table. Useful for testing or specific subsets.
- **Generate Failed Only**: Generate metadata only for files that previously failed during the last generation process. Handy for retrying problematic files.
- **Generate Drafts Only**: Start generating metadata from the first file with draft status and continue onwards. Use this to process files that have never been generated.
- **Resume Generation From Stopped**: Resume generation starting from the first file that has a stopped status. Use this to continue an interrupted run without reprocessing earlier files.
- **Generate All With Rolling API Keys**: Try all available API keys automatically; if one key fails, the system switches to the next available key and continues. Useful when you have multiple API keys and want the process to continue despite key errors or limits.
- **Generate Failed Only With Rolling API Keys**: Retry only files that previously failed, but cycle through available API keys automatically when a key fails so failures can be retried using other keys.
- **Generate Selected Only With Rolling API Keys**: Process only the files you selected and automatically switch API keys if the current key fails, so the selected set is retried with other keys as needed.
- **Generate Drafts Only With Rolling API Keys**: Start from the first draft file and continue onwards while using rolling API keys to recover from key failures during processing.

   Use these options to target specific files, retry failures, resume interrupted runs, or run large batches while leveraging multiple API keys.

After the process is complete, the generated metadata is saved only in the Image-Tea-nano database.  
It is **not yet written to the original files**—so if you clear or reset the database, the metadata will be lost.  
To permanently save metadata to your files, use the write metadata feature.
