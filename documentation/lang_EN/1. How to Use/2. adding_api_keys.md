# Adding an API Key

![Add API Key dialog](res/images/adding_api_key.png)

Image‑Tea‑nano needs an API key to use AI features. The steps below describe how to add, test, and manage API keys using the in‑app dialog.

1. Open **API** → **Add API Key**, or click the API Key button on the toolbar. The **Add API Key** dialog opens.
2. Choose the **Service** (e.g. `OpenAI` or `Gemini`).
3. Use the **Model** dropdown to pick a model. To add custom or OpenRouter model ids, click the gear icon beside the dropdown to open **Model Manager**.

	![Selecting model](res/images/adding_api_key_selecting_model.png)

4. In **Model Manager** click `+` to add a model id (for OpenRouter, use `openai/<model-id>`, e.g. `openai/gpt-4.1-nano` or `openai/gpt-5.2`). Enter the model name and click `Save`.

	Note: In **Model Manager** first select the `OpenAI` service (left column) before clicking `+` and pasting an OpenRouter model id. This ensures the model id is registered under the OpenAI-compatible service in Image‑Tea‑nano.

	![Model Manager](res/images/adding_api_model_manager.png)

	![Add Model](res/images/adding_api_model.png)

5. Back in **Add API Key**, paste the API key into the **API Key** field (or use the paste button). Use **Note** to store an optional description.
6. Click **Test and Save** to validate the key and save it if the test succeeds. Additional controls in the dialog:

 - **Test All**: run tests for all stored keys.
 - **Export CSV** / **Import CSV**: export or import key lists.
 - Per-row **▶** button: test a single API key.
 - Per-row **Delete** button: remove a saved key.

OpenRouter specifics (OpenAI‑compatible):

 - Add the OpenRouter model id in **Model Manager** using the `openai/<model-id>` format.
 - Select `OpenAI` as the Service, pick that model, then paste the OpenRouter API key.

Once saved and verified, the API key is available for use in Image‑Tea‑nano.

OpenRouter — choosing the right model

When using OpenRouter to provide an OpenAI‑compatible model, pick the model id exactly as shown on the OpenRouter model page and confirm the model supports the input types you need:

- Go to the OpenRouter Models page and search for the model you want. Look for the model id under the model name (for example: `google/gemini-2.5-flash`).

- Models you add in **Model Manager** appear in the **Model** dropdown inside Image‑Tea‑nano — select the desired model from that list.
	![Selecting model](res/images/adding_api_key_selecting_model.png)

	![OpenRouter model list](res/images/openrouter_model_page.png)

- Confirm the model's Input Modalities include `Image` (and `Video` if you plan to send videos). If Image/Video are not listed, the model won't accept those inputs.
- Check the price information shown on the model card — OpenRouter shows per‑M token prices for input/output tokens. Prices vary per model; note them before using the model (example shown on the page: `$0.30/M input tokens`, `$2.50/M output tokens`).

- To copy the model id, click the copy icon next to the model id on the model page and paste that exact id into Model Manager.

	![OpenRouter model id and copy button](res/images/openrouter_model_name.png)

Example workflow (short):

1. Search or browse OpenRouter and choose a model that lists `Image` (and `Video` if needed) in Input Modalities.
2. Check the per‑M token pricing on the model card and note it for cost estimates.
3. Click the copy button to copy the model id (e.g. `google/gemini-2.5-flash`).
4. In Image‑Tea‑nano open **Model Manager**, select the `OpenAI` service, click `+`, paste the copied model id and `Save`.
5. In the **Add API Key** dialog select `OpenAI` as Service and choose the model you added; paste your OpenRouter API key and click **Test and Save**.

Following these steps avoids selecting a model that doesn't accept image/video input and ensures you are aware of the token pricing for the chosen model.

Disclaimer — costs and model selection

- Choosing the wrong model (for example, one that does not support `Image`/`Video`) or using a model with higher per‑M token prices can lead to unexpected costs. Always verify the model's Input Modalities and pricing before running large requests.
- Token usage and billing are determined by the model and the service provider — Image‑Tea‑nano's developers are not responsible for any charges incurred by using third‑party models or keys. Test with small requests and monitor usage to avoid surprises.
