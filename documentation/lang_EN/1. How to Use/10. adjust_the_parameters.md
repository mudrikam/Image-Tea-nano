# Adjusting the Parameters

Use the toolbar controls to set generation parameters. Changes are saved immediately to the application configuration and take effect for subsequent generation requests.

![Adjust Parameters](res/images/adjust_parameter.png)

Definite behavior of each parameter:

- **Min Title**: Requests the model to produce titles with at least this many characters.
- **Max Title**: Requests the model to produce titles with at most this many characters.
- **Max Desc**: Requests the model to produce descriptions with at most this many characters.
- **Tag Count**: Requests the model to generate exactly this number of keywords/tags for each file.
- **Batch Size**: Sets how many files are sent in a single API batch request. The maximum allowed value is 20.
- **Compression**: Sets the image cache quality (1–100) for files sent to the API.
  - `100` = original quality (no compression).
  - Lower values produce smaller cache files and reduce data usage; higher values preserve more image detail.
  - Recommended: `70–80`.
  - Important clarification: this setting only affects the size and visual detail of the image files sent to the AI service. Compression **does not** change the number of tokens counted by the API for text prompts or responses. Token usage is determined by the textual content (prompt + response) and the model's tokenizer, not by image file size. Very high compression can reduce visual detail, which will change what the model sees and can change the generated text, but it still does not alter token counts used by the request.
- **Delay (s)**: Sets the pause between batches.
  - `No Delay` = 0 seconds.
  - `Random` = random interval between 1 and 5 seconds.
  - A numeric value is treated as seconds between batches.

Storage and validation:

- Parameter changes are persisted to `configs/ai_config.json` immediately.
- Controls enforce valid ranges (e.g., `Batch Size` ≤ 20; `Compression` between 1 and 100) to prevent invalid input.

These parameters control the length, quantity, batching, and data usage of metadata generation. Set them to produce titles, descriptions, and tags that meet your platform requirements and workflow needs. Changes apply to the next generation run.
