# Checking Your Usage Limit

Each member account has a usage limit, which is the number of files you can process using the membership API. Once this limit is reached, AI generation will be paused for your account.

## How to Check Your Usage

1. Make sure you are logged in as a member.
2. Click the **Member** menu in the menu bar.
3. Click **Check Limit**.

A dialog will appear showing:

- **Used** - How many files you have processed so far
- **Limit** - Your total allowed quota (shows "Unlimited" if no limit is set)

## What Happens When the Limit is Reached?

When your usage reaches the limit, a warning dialog will appear before Image Tea processes any files. Generation using the membership API will be blocked until your quota is renewed by the admin.

You will see a message informing you that your limit has been reached.

## What Can You Do When the Limit is Reached?

- **Contact the admin** to request a quota renewal or top-up
- **Use your own API Key** if you have one registered in Image Tea. Your personal API Key is independent of the membership limit

## After a Top-Up

Once the admin has renewed your quota, you do not need to log out and log back in. Image Tea will automatically re-check your updated quota the next time you attempt to generate.
