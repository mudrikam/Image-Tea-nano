# How to Log Out

If you want to log out of your member account, you can do so at any time.

## Steps to Log Out

1. Click the **Member** menu in the menu bar.
2. Click **Logout**.

You will be logged out immediately. The Member menu will return to showing only the **Login** option.

## When Should You Log Out?

- If you are on a shared computer and want to protect your account
- If you want to switch to a different member account
- If you are done using membership features and want to use only your personal API Key

## After Logging Out

- Membership-based generation will no longer be available
- If you have your own API Key configured in Image Tea, it will continue to work normally
- You can log back in at any time by clicking **Member** and then **Login**
