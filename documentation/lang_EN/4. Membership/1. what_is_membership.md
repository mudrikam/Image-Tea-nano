# What is Image Tea Membership?

Image Tea Membership is a subscription-based access system that allows you to use Image Tea's AI generation features without needing your own API Key.

When you are a member, Image Tea uses a shared AI API provided by the admin. This means you can start generating metadata right away without going through the process of obtaining and managing your own API Key.

## Who is Membership For?

Membership is ideal for users who:

- Do not want to deal with the technical process of obtaining an API Key
- Prefer a managed service where the AI access is handled for them
- Want a ready-to-use experience out of the box

## What Does Membership Include?

- Access to Image Tea's AI metadata generation using a provided API
- A file usage limit (quota) that defines how many files you can process
- The ability to continue using your own API Key independently of your membership status

## Usage Limit

Each member account has a usage limit, which is the total number of files you are allowed to process using the membership API. Once your limit is reached, generation will stop until your quota is renewed by the admin.

You can check your current usage at any time via the **Member** menu in the menu bar.

## Device Lock

Each license key is locked to a single device. Once you log in on a device, that license is bound to it. If you try to log in on a different device using the same license key, login will be blocked.

If you need to use your account on a different device, contact the admin to request a device reset.

## Non-Member Usage

If you have your own API Key, you can always use it regardless of your membership status. Membership and personal API Keys are completely independent of each other.
