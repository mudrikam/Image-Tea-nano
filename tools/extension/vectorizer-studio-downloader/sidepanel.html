Cara Penggunaan
  1. Buka halaman vectorizer.studio (klik tombol di bawah jika belum).
  2. Drag & drop gambar ke area unggah, atau klik Load Files / Load Folder.
  3. Klik sebuah file di daftar untuk melihat pratinjau.
  4. Klik ikon petir di tiap baris untuk memproses satu file.
  5. Atau klik Run Batch untuk memproses semua file yang Pending/Gagal berurutan dengan jeda (cooldown).
  6. Setelah status menjadi Done, klik ikon unduh untuk menyimpan SVG-nya.
  7. Gunakan Download All untuk mengunduh semua file yang sudah selesai sekaligus.
  8. File SVG diunduh ke folder Downloads browser Anda.

Blob URL dari vectorizer.studio bersifat sementara. Simpan SVG segera setelah diproses.
