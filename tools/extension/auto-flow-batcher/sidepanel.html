How to Update / Cara Update

English

  1. The ZIP file is downloading now (full repository).
  2. Extract the ZIP file to any folder.
  3. Navigate to: Image-Tea-nano-main/tools/extension/auto-flow-batcher/
  4. Copy the entire file inside the auto-flow-batcher folder.
  5. Replace your old extension folder with this new one.
  6. Open chrome://extensions in your browser.
  7. Find "Auto Flow Batcher" and click the reload button (circular arrow icon).
  8. Done! The extension is now updated.
