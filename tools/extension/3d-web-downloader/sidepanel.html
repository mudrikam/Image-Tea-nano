    How to use

    • Open any web page that embeds or links to a GLB, glTF, or USDZ file.
    • The extension automatically scans the page on load and as you interact.
    • Each detected asset appears in the list with format, host, and source hint.
    • Switch to the Preview tab to interact with GLB/glTF models (click + drag to orbit).
    • Click Download to save the file into your configured subfolder.
    • USDZ previews are not supported in Chrome — the file will be downloaded instead.
