Desainia Prompt Injector Tool - Documentation

Overview

Automate prompt injection and content download for AI image generation websites. Perfect for tools like ChatGPT Image Generation, Whisk, Midjourney web, and similar AI generators.

Key Features:

  • Smart auto-download with content verification
  • Per-website settings storage (auto-switches when you change sites)
  • Monitoring mode with 60-second timeout for slow generations
  • Auto-continue to skip delays after successful downloads
  • Activity logs for debugging and monitoring

Per-Website Settings

Settings are automatically saved per website domain:

  • When you switch to a different site, settings for that site are loaded
  • Selectors, prompts, and all configurations are stored separately
  • No limit on number of sites - settings persist in browser storage
  • Settings auto-save on every change

Points System

Point 1 (Orange - Paste):

The input field where your prompt will be pasted. The tool will:

  • Focus the element
  • Select all existing content
  • Insert the new prompt text
  • Trigger input/change events
Additional Points (Click):

Buttons or elements to click after pasting. Examples:

  • Generate/Submit button
  • Send message button
  • Any action buttons in sequence

Each point has its own delay setting.

Auto Download Content

Automatically download generated images/videos:

  • Item count (1-4): Required number of items per prompt. Automation stops if not met.
  • Wait time: Used for Fixed Wait mode countdown
  • Auto monitoring: Scans every 500ms for new content (min 60s timeout)
  • URL pattern: Only download URLs starting with this prefix (e.g., blob:https:// or https://cdn.)
  • Extension: Force file extension (jpg, png, webp, mp4)
  • Prefix: Filename prefix (default: Generated_Content)
Smart Detection:

The tool tracks existing content before each prompt and only downloads NEW items that appear after. This prevents re-downloading old content.

Strict Count Enforcement:

If the required item count is not reached (e.g., 4 items requested but only 3 found), automation stops with an error. This ensures complete downloads before continuing.

Monitoring vs Fixed Wait Mode

Fixed Wait Mode (checkbox OFF):
  • Waits exactly N seconds (from Wait field)
  • Shows countdown: "Waiting Xs before scanning..."
  • Scans once after countdown completes
  • Good for predictable generation times
Monitoring Mode (checkbox ON):
  • Scans every 500ms for new content
  • Minimum 60-second timeout (or Wait field if higher)
  • Shows: "Monitoring: X/Y found (scan #N)"
  • Stops early when target count reached
  • Best for variable generation times

Auto Continue

When enabled (checkbox in Delay section):

  • Skips delay between prompts after successful downloads
  • Only triggers if all required items were downloaded
  • Disables the "Delay between prompts" input
  • Maximizes throughput for batch operations

Delay Settings

  • Point delay: Wait time before each point action (prevents too-fast clicking)
  • Random extra delay: Adds random 0-N seconds to point delays
  • Delay between prompts: Wait after completing all points (disabled by Auto Continue)

How to Select Elements

Method 1: Element Picker (Recommended)
  1. Click the pencil icon button
  2. Page dims and you can hover over elements
  3. Orange highlight shows current selection
  4. Click to confirm selection
  5. Press ESC to cancel
Method 2: HTML to Selector
  1. Open DevTools (F12)
  2. Right-click element in Elements panel
  3. Copy → Copy element
  4. Click the code icon in the extension
  5. Paste the HTML
Method 3: Manual CSS Selector

Type directly in the input field:

  • #submit-btn - by ID
  • .generate-button - by class
  • [data-testid="send"] - by attribute
  • button[type="submit"] - combined

Loading Files

  • CSV: Each row becomes one prompt
  • TXT: Each non-empty line becomes one prompt
  • Drag & drop files into the Prompts tab drop zone
  • Multiple files can be loaded and combined
  • Prompts are saved per-website automatically

Logs Tab

The Logs tab shows real-time activity:

  • Blue - Info messages
  • Green - Success/download complete
  • Orange - Status updates
  • Red - Errors

Use logs to debug issues and monitor progress.

Troubleshooting

"First prompt failed" error:
  • Increase Wait time or enable Monitoring mode
  • Check URL pattern matches the generated content
  • Verify the website actually generates the expected content
  • Check Logs tab for detailed error info
Picker not working:
  • Refresh the target page first
  • Cannot work on chrome:// or extension pages
  • Wait for page to fully load
Downloads not appearing:
  • Check browser download folder
  • URL pattern may be too restrictive
  • Generated content may be smaller than 500px
  • CORS restrictions may block canvas export
Settings not saving:
  • Browser storage may be full
  • Try clearing browser cache
  • Ensure extension has storage permission

Filename Format

Downloaded files are named:

{prefix}_{first-5-words}_{timestamp}.{ext}

Example: Generated_Content_beautiful_sunset_over_the_mountains_1707580234567.jpg
