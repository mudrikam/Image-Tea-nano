Help & Usage Guide

What is Mockup Preview Prompt?

Mockup Preview Prompt is an AI-powered design prompt generator that analyzes your reference images and creates professional 2D graphic design prompts for marketplace mockup previews. It extracts visual DNA (colors, typography, composition) and translates it into detailed image generation prompts.

Quick Start (3 Steps)

  1. Upload Reference: Drop or paste an image (logo, design, or visual reference) into the drop zone at the top.
  2. Configure Parameters: Enter your main title, subtitle, select visual style, colors, and typography preferences in the Parameter tab.
  3. Generate: Click "Generate Prompts" to create AI-powered design prompts based on your reference and settings.

Parameter Tab Explained

  • Main Title / Context: The primary text that will appear as visible typography in the design (quoted automatically in prompts).
  • Sub-Title / Slogan: Secondary text element, also rendered as visible text.
  • Additional Context / Brief: Extra creative direction (e.g., "Make it futuristic", "Add stars"). This guides the AI's stylistic choices.
  • Prompt Quantity: Number of prompt variations to generate (1-10).
  • Visual Style: Choose a predefined aesthetic (Elegant, Minimalist, Playful, etc.) or select "Custom" for your own description.
  • Typography: Font style selection. "Auto/Mimic Reference" extracts typography from your image. Use "Custom Description" to specify your own requirements.
  • Font / Typography Reference: Optional second image showing desired font style. The AI will replicate its typography characteristics.
  • Color Palette (60-30-10): Three colors for primary (60%), secondary (30%), and accent (10%) distribution. Toggle "Strict" to enforce exact distribution or allow creative liberty.
  • Detail Level: Controls prompt length: Short (concise), Medium (descriptive), Long (elaborate).

Automation Settings: Flow Mode

  • Aspect Ratio: Output frame shape (16:9, 4:3, 1:1, 3:4, 9:16).
  • Download Quality: Desired output resolution (Default, 2K, 4K).
  • Batch Count: Number of variations to generate per cycle (x1 to x4).
  • Auto Submit: When enabled, automatically submits prompts to compatible AI generators after generation.

Automation Settings: Universal Prompt Injector

This mode automates pasting prompts into external AI image generators (like ChatGPT, Claude, etc.) and downloading the results.

  • Current Page: Shows which website you're on. Settings are saved per-site.
  • Entry Prompt: CSS selector for the text input field where prompts should be pasted. Click "Pick" and then click the input on the active page to auto-detect.
  • Submit Button: CSS selector for the generate/submit button. Click "Pick" and select the button on the page.
  • Auto Download Content: Enable automatic downloading of generated images/videos.
  • Download Count: How many items to download per batch (1-4).
  • Wait: Delay (in seconds) before starting download after generation completes.
  • Auto Monitoring: Continuously scans the page every 1.5s for new content matching the URL pattern.
  • URL Pattern: Pattern to identify which images to download (e.g., `https://lh3.googleusercontent.com/`). Click "Pick" on an image to auto-extract.
  • File Extension: Target file type (JPG, PNG, WEBP, MP4).
  • File Prefix: Prefix for downloaded filenames (default: "Mockup_Preview").

Prompts Tab

View generated prompts with analysis text. Each prompt has status indicators:

  • Pending: Not yet used.
  • Inserting: Currently being injected.
  • Monitoring: Watching for new content.
  • Downloaded: Successfully saved.
  • Failed: Error occurred.

Use "Copy All" to copy all prompts, or individual "Copy" buttons per prompt.

Logs Tab

Real-time system log showing all extension activities, errors, and status updates. Use the copy button to export logs or the clear button to reset the log.

Tips & Best Practices

  • Use clear reference images: Higher quality and clarity yields better DNA extraction.
  • Be specific with Additional Context: "Modern tech logo with neon glow" produces better results than "make it cool".
  • Mockup previews work best: With full-bleed edge-to-edge designs. The AI is instructed to avoid whitespace/margins.
  • For Universal Injector: Save selectors per-site. The extension remembers settings for each domain automatically.
  • URL Pattern picking: Click "Pick" on an image you want to download; the extension extracts a cleaned pattern that matches similar URLs.

Troubleshooting

  • "No page detected": The injector only works on regular HTTP/HTTPS pages (not chrome:// or extension pages).
  • Picker won't start: Ensure you've clicked the pick button first, then click the target element on the active tab.
  • Selectors not saving: Make sure you switch away from the Injector mode and back, or the settings are saved per-site automatically when changed.
  • Images not downloading: Verify the URL pattern matches the image URLs. Use browser DevTools (Network tab) to inspect actual image URLs.
  • API errors: Check your API key, endpoint URL, and model name in API Settings. Ensure the provider is correct (Gemini vs OpenAI-compatible).
